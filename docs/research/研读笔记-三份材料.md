## 1. MediaTone —— 把「媒体基调」做成可回归的金融解释变量

### 1.1 提出的问题

跨境资产价格（股票、债券、汇率、原油）能否被新闻/媒体的「语调」预测？媒体基调目前是人工印象，必须变成**可量化、可复现、可回测**的日频变量。

### 1.2 方法（两条并行路径）

| 路径 | 做法 | 产出 |
|---|---|---|
| (a) 现成 API 基线 | Google Cloud Natural Language 等情绪 API 直接取分 | 情绪分 |
| (b) 自建词典法 | 「爬取相关新闻、政策等文本数据，词典法等建模测度媒体基调（正向 & 负向，具体数值）」 | 三个指标：**Media Tone / Positive Tone / Negative Tone** |

### 1.3 数据收集（关键词驱动）

9 组关键词：Transcript / finance risk / cross-border finance / capital flow / climate risk / offshore market / cross-border market / offshore finance / cross-border + capital flow。

- 中文源：中国政府网、巨潮资讯网、人民日报、光明日报、中国经济网、证券时报、21 世纪报道
- 英文源：IMF、Bloomberg、Refinitiv Real-time News、Google Cloud
- 语音侧：英为财情电话会议文字记录、2017 年标普500 季度盈利电话会议
- 采集技术：Playwright / 正则 / 八爪鱼级别
- 原文记录的实际抓取量：Transcript 1872、finance risk 1421、cross-border finance 1093、capital flow 834、climate risk 503、offshore market 319、cross-border market 291、offshore finance 86、cross-border+capital flow 13

### 1.4 建模框架（可直接产品化的研究设计）

| 维度 | 内容 |
|---|---|
| 目标资产 | 跨境金融资产 = 股票、债券、汇率、原油指数 |
| 模型三类 | 计量经济学（`Y = ΣbᵢXᵢ`，强调可解释与因果）· 机器学习（NN、LSTM、决策树及集成、RF、SVM 等数十种）· LLM（Bie et al. 2025 路线） |
| **模态消融 7 组** | Numeric / Text / Audio / Numeric+Text / Numeric+Audio / Text+Audio / Text+Audio+Numeric（引自 Cao et al. 2025，RiskLabs） |
| 评估 | MSE、RMSE、R²；滚动窗口 `windows=3, step=1`，共 300 个窗口；短期 / 中期 / 长期分别评 |
| **增量信息检验** | §5.6「媒体基调是否提供增量信息」——相对数值变量的嵌套模型对比 |
| 样本外 | §5.7 |
| 可解释性 | SHAP / LIME / PDP（机器学习与 LLM 是黑箱） |
| 备用 | §6.1 替代模型、§6.2 季节性模式 |

### 2.4 原理说明（`（新）2 原理说明文档.docx`，扩充版）

**MM-LLM 五件套**：模态编码器 → 输入投影器 → LLM 骨干 → 输出投影器 → 模态生成器。
- 训练期 encoder / LLMBackbone / generator 一般冻结，**只训 projector**，可训参数约占 2%
- 投影器实现：MLP / Cross-Attention / Q-Former / P-Former
- PEFT：Prefix-tuning、Adapter、LoRA（「希望更少的参数可以被训练，甚至少于 0.1%」）
- 三阶段：预训练（训 Projector 做模态对齐）→ 多模态微调（MM IT = SFT + RLHF）→ 指令对齐
- 26 个 SOTA MM-LLM 对比表（Flamingo / BLIP-2 / LLaVA / MiniGPT-4 / mPLUG-Owl / X-LLM / VideoChat / PandaGPT / PaLI-X / Video-LLaMA / Video-ChatGPT / Shikra / DLP / BuboGPT / ChatSpot / Qwen-VL / NExT-GPT / MiniGPT-5 / LLaVA-1.5 / CogVLM / DRESS / X-InstructBLIP / CoDI-2 / VILA …）

**金融领域 9 种跨模态组合**（第 3 章，含可直接改写的实现细节）：
- **文本+时序**：预训练 LM（RuBERT / Qwen）编码新闻 → LSTM 处理股票时序 → 向量拼接或交叉注意力融合 → Accuracy / MSE / MAPE
- **视频+文本**（原文现成案例是 Twitter/TikTok + 加密货币，可直接改写成境内+境外舆情版）：Meta-Llama-3-8B 做文本情感，mLLM 处理视频音频/视觉/字幕，融合后喂 **MOMENT** 时序预测，**DCC-GARCH** 做动态连通性 → 结论「TikTok 情感信号对短期市场趋势影响较强，Twitter 情感信号更能反映长期市场动态」
- **语音+文本**：声谱 → BLSTM → 与文本自注意力融合 → 自回归解码（BLEU / WER）
- **图像+音频**：加法融合 / 张量融合（Zadeh 外积）+ trace norm 正则
- **图像+时序**：ResNet-50 视觉 640 维 + 语音 1280 维 → 拼接 1920 维 → LSTM → CCC 损失（RECOLA）

**应用领域四条**：风险管理 / 智能投顾 / 欺诈检测 / 市场情绪分析。
