# R1 · MediaTone 文献结论与实现方案（2026-11-25）

> 上游：`ref/MediaTone/`（2 docx + 9 篇 PDF，逐篇已读）+ `ref/数据汇总统计表-简化版(1).xlsx`。
> 用途：把 R1 从「研究域设计」推进到「可排期实现方案」。本文件只写**方法结论与实现**，不含任何实验结果数值。
> 约束：纯客户端、无 GPU、无模型训练；LLM 仅 DeepSeek/JEV API；缺失 ≠ 零值；结论必须绑证据。

## 1. 三条测量路线怎么选（Q1）

| 路线 | 可复现性 | 成本 | 可审计性 | 结论 |
|---|---|---|---|---|
| **词典法**（自建中文金融情绪词表） | **最高**：词表版本化 + sha256 + 逐词回指，可离线重算 | 近似 0（本地字符串匹配） | **最高**：命中词、否定作用域、情感单元可逐条追溯 | **主轨 / 基线**（唯一满足「结论绑证据」的路线） |
| **LLM 打分**（DeepSeek API） | 中：需固定 model + prompt 版本 + temperature=0 + 响应缓存；供应商模型漂移不可控 | 按 token 计费，可缓存（内容寻址） | 中：必须输出 evidence_spans 并由 JEV 核验，否则不可用 | **增强轨**：捕捉词典法抓不到的语境（否定、转折、反讽），与词典轨并列 |
| **Google Cloud Natural Language** | 低：外部托管黑盒，模型版本与配额不受我们控制 | 按字符计费 + 需 GCP 账号密钥 + 境外网络可达性（纯客户端在国内不可靠） | 低：只有黑盒分数，**docx 表 3-1 的「Media Tone / Positive Tone / Negative Tone」在 GC 口径下三列全空，本质需要我们自建映射（F5_cloud）** | **可选对照轨，默认关闭**：仅在用户自带凭证且网络可达时启用，作为第三方锚点，不做主轨 |

组合方式（与 R1 §3.2 公式集一致）：`F1/F2/F3/F4`（词典轨）为主，`F5_cloud`（GC，可选）为外部锚，`LlmScorer` 轨作为上下文轨。**三轨并列输出、互不覆盖**；任一轨不可用时单独报告并标注（基线 §4 零 Mock）。

依据：姜富伟 2024（LLM 样本外 R²_OS 9.97% vs 词典 3.85%；下行期 17.19% vs 2.18%）说明 LLM 轨确有增量价值，但也说明词典轨在**极端/下行期几乎失效**；姜富伟 2021（通用词典 73.8% 的负面词在金融语境下不再负面）说明词典轨必须做金融语境改造；Lehkonen 2025（RMI 词典 700 万篇语料 + 3 人盲评 80% 准确率准入）说明「词典 + 人工校验」是国际同行标准做法。

## 3. 领先期（lead time）证据（Q3）

| 来源 | 领先期 | 具体数值 | 出处 |
|---|---|---|---|
| 英文新闻（词典/算法口径，RMI） | **月度，峰值 t+2 月，6 月后衰减，t+7~t+12 失效** | 样本外 R²_OOS(vs 随机游走带漂移)：t+1 4.38%**、t+2 5.39%**、(t+1,t+3) 10.08%**、(t+4,t+6) 6.53%**，(t+7,t+12) −1.63（不显著）；1 sd 基调 → 次月 TW 美元收益 +0.21% | Lehkonen 2025 JBF |
| 中文新闻情绪 | **月度 t−1 → t（约 20 个交易日）**；极端事件日度回归领先期降为 **1 个交易日** | 月度样本外 R²_OS 9.97%（LLM）/3.85%（词典）；2007 股灾日度 β=0.014**、R²=2.18% | 姜富伟 2024《管理世界》 |
| 中文新闻情绪（词典口径） | **月度 1 个月** | 样本外 R²_OS 1.18% / 1.51%；双变量后 R² 提升至 3–7%（PMI 7.09%） | 姜富伟 2021 |
| 财报电话会议（语言风格） | **无前瞻期**：CAR 事件窗 [0,1]，同期 | W_Tone 0.014***、W_Linguistic 0.018***；问答环节 C_Wordsn −0.036***、C_Wordsp 0.017 不显著 | 张光利 2022 |
| 政策文本 | 事件驱动，无稳定领先期 | 官方语态稳定 → 适合做基准线而非领先指标 | 媒体基调 docx 表 2 |
| 投资者评论 / 社交媒体 | **分钟—日级即时**，噪声大 | Li 2025 用新闻前后 5 分钟窗口度量成交量-波动弹性 | Li 2025 RAS |
| 新闻→企业违约 | τ = 1 / 3 / 12 / 36 月，**1 月最强、36 月最弱** | 增量 pseudo-R² 0.18→0.32（+77.8%）、AUC 0.92→0.96；12 月仅 0.15→0.23 | Bie 2025 JFM |
| LLM 多模态波动率/VaR | 3 / 7 / 15 / 30 日 | MSE 0.324/0.585/0.317/0.233/0.171 | Cao 2025（position paper，数值仅作方向参照） |

**结论**：对跨境资产最有用、领先期最长的是 **月度频率的英文全球财经新闻（3–6 个月，峰值 t+2 月）** 与 **中文新闻情绪（1 个月）**；政策文本与官方语态适合做基准线与事件触发，不适合做长领先期指标；电话会议语言风格在**同期**有信息量（成交量-弹性式即时响应），不应包装成领先指标；社交/评论即时但噪声最高。

## 4. 增量信息怎么证（Q4）

| 文献的对照组设计 | 指标 | CBR-MAW 上可执行的最小实验 |
|---|---|---|
| Framework §5.4：Numeric / Text / Audio / Numeric+Text / Numeric+Audio / Text+Audio / 全模态（7 组） | MSE / RMSE / R²；滚动 windows=3 step=1 | Audio 轨本代只做转写文本化，声学特征留插件位；不可跑组标「未运行」而非「无差异」 |
| Cao 2025：仅 3 组模块消融（Audio+Text → +LLM 分析 → +VIX） | 仅 MSE；**无 SHAP/LIME/PDP、无显著性检验** | 不可把其数值当预期值；只借鉴「逐模块加，看 MSE 变化」的思路 |
| Bie 2025：财务基线 logit vs +LLM 情绪 vs +FinBERT vs +LM 词典 | pseudo-R²、AUC、十分位破产率 | 借鉴「**同一基线 + 不同情绪轨**」的对照结构 |
| 姜富伟 2021/2024：情绪 + 宏观变量双变量 vs 单变量 | R²、样本外 R²_OS、DM/资产配置 CER | 借鉴「加控制变量后系数仍显著才算增量」 |
| Li 2025：安慰剂对照（Placebo / Corr(Vol,Vol) / Volume / Volatility） | Fama-MacBeth t、H−L、FFC4 alpha | 必须做**安慰剂组**：随机打乱 tone 序列，检验伪增量 |

**最小实验设计（CBR-MAW 版）**

1. **被解释变量**：`future_h_log_return`，h ∈ {1, 5, 20} 个交易日；标的 = USDCNH、USDCNY、中债 10Y、沪深300、VIX（公开可取）+ 中资离岸债 OAS（需授权则标「需授权」）。
2. **数值基线 Numeric-only**：`market_daily` 27 序列的真实版（pit_real.duckdb）+ 结构化数据北向/南向日频 + 公开 FRED/Cboe/中债/外汇局；模型 = 岭回归/AR（确定性、可复现，Dart/Rust 手写）。
3. **文本轨**：`Numeric + Tone`（词典轨）、`Numeric + Tone(LLM)`、`Numeric + Tone(双轨共识)`，tone 为 null 的日子**不插值、不填 0**，直接从样本剔除并记录剔除率。
4. **样本外**：扩展窗口，训练样本截止 t−h；标准化参数只在训练期估计冻结。
5. **显著性**：ΔR²_OS + Diebold–Mariano（内核 `dm.test` 已在规划）+ 嵌套 F 检验 + Holm 校正；预注册主终点（USDCNH、h=5）。
6. **压力窗口事件检验**：2018 贸易摩擦、2020-03 美元流动性、2022-10、2023-03 SVB、2024-08 日元套息，窗口 ±10 交易日；检验压力期 tone 显著更负（H6），与平静期对照。
7. **可解释性**：SHAP（线性/树模型精确值）+ PDP 单调性；LLM 轨用置换近似。
8. **诚实边界**：`data/samples/*` 是 SYNTHETIC，只能做管线自检，**不得用于任何结论**；结论只允许基于 pit_real.duckdb 与结构化数据的真实段。

## 5. 四篇中文/跨境文献要点（Q5）

| 文献 | 对产品的要点 |
|---|---|
| **姜富伟《媒体文本情绪与股票回报预测》(2021)** | 中文金融情绪词典的可复现构建法（LM 中译 + 通用词典 + word2vec 扩充）；情感单元 + 否定词 (−1)^n + 程度权重；**词典法在控制宏观变量后仍显著**（PMI 双变量 R²=7.09%）；**风险补偿渠道被否证**（LVOL 系数不显著）→ 产品里不要把 tone 叙事成「风险溢价」机制，应叙成「信心/流动性/资金流」渠道；作者自陈局限：只二分不赋权、样本止于 2016、日频仅初步探索 |
| **姜富伟《大语言模型、文本情绪与金融市场》(2024)** | LLM 轨（bert-base-chinese 进一步预训练 + 市场回报做标签微调）**全面优于词典法**：样本外 R²_OS 9.97% vs 3.85%，下行期 17.19% vs 2.18%，控制宏观变量后词典法几乎全不显著而 LLM 几乎全显著；短文本（标题）也能用；**领先期 = 月度 t−1，极端事件日度仅 1 天** → CBR-MAW 的 LLM 轨最该投在「月度聚合 + 压力事件日频」两处 |
| **高尚《系统性金融风险 LLM 视角》(2025)** | 传统测度短板：PCA/熵权综合指数**忽视风险来源结构与网络关联**、单一 CoVaR 类度量；LLM 三条适配性（非结构化多模态、文本信息抽取与情感分析、跨领域知识整合 + 工具）；降幻觉手段 ALM / RAG / RAU；**LLM 三大局限：幻觉、预测黑箱不可解释、语料时效滞后** → 直接对应 CBR-MAW 的证据链、JEV 裁判与 PIT 机制；该文**未涉及**多智能体/证据链/时点库，本产品的「多智能体 + 证据链 + PIT」是原创延伸，也因此责任更重 |
| **张光利《电话会议高管语言风格》(2022)** | 可在**转录文本**上算的只有 3 个语气变量：高管乐观情绪、**正面词语使用量 Wordsp**、**不确定性词语使用量 Wordsn**；分陈述(S_)/问答(C_)环节；**问答环节 Wordsn 显著负向、C_Wordsp 不显著**；陈述环节语气变量全不显著；声学 8 特征需音频资产 + 人工听评（成本高、样本 39/44、内生性未处理）→ 本代**只做文本侧 3 变量，声学留插件位** |
| **Lehkonen《Media tone is a priced risk factor in currency markets》(2025)** | 与跨境场景最相关：RMI 词典/算法口径（2000 媒体 + 800 社媒平台、700 万篇、日→月均值）；领先期 3–6 月、峰值 t+2；**传导渠道唯一是分析师预期**（Attention / 不确定性 / 分歧均被否证）；单一来源只有 NYT 与 Economist 有预测力（→ 提示「来源集中度」是稳健性风险）；数据专有不可复现 → **CBR-MAW 必须走自建可审计词典轨，这是我们相对 RMI 的差异化而非劣势** |
| 补充：Li 2025 RAS / Bie 2025 JFM / Cao 2025 / Zhang 2024 | Li：情绪 ≠ 分歧（成交量-波动弹性），RavenPack ESS 被作者明确排除，说明**情绪文本不能替代分歧度量**；Bie：GPT-4o mini + Batch API + 单段 prompt（情绪分+3 关键词+多期限概率），并自陈新闻可得性选择偏差（924→509 家破产公司）；Cao：无 SHAP/LIME、无显著性检验，只能借思路；Zhang：**明言「训练与推理无需 GPU」但依赖 GPT-4/GPT-4V API**，且消融显示加工具在 ETH 上 −21% → 工具不是越多越好，须做工具消融 |

## 7. 风险与反例（Q7）与披露方式

| 风险 | 具体表现 | 披露/缓解（产品内显式，不藏） |
|---|---|---|
| 媒体覆盖偏差 | 只覆盖大市值股；单一来源（Lehkonen 仅 NYT/Economist 有效）；来源集中度过高 → tone 退化为「媒体注意力代理」 | 每条 tone 带 `doc_count`、来源分布熵；`tone_source_entropy` 低时 UI 标「来源集中，结论仅对当期有效」 |
| 幸存者/可得性偏差 | Bie：924 家破产公司合并后仅剩 509 家有新闻；离线股/退市股缺文本 | 覆盖率面板列出「有数值无文本」的资产占比；增量结论按覆盖子集单独报告 |
| 文本源限流/不可达 | 35 行台账里 T3/T4 共 15 条（Bloomberg/LSEG/Wind/雪球/X） | 台账显式「需授权 / 不可达」，绝不降级为 0；双轨任一不可用时另一轨单独报告 |
| 口语 vs 书面语 | 电话会议转录口语化、无标点、含填充词；张光利用人工听评，成本不可承受 | 文本侧 3 变量单独报告；声学变量明确标「本代未实现」，不暗示已做 |
| 中文财经文本歧义 | 通用词典 73.8% 负面词在金融语境下不再负面（姜富伟 2021）；「负债/爆雷/去杠杆/缩表」反义 | 金融语境词表 + 语境权重 + 否定/反讽规则；人工标注集抽检准确率；错判样本入库供复盘 |
| 词典法迁移性差 | 需随突发事件更新；选词主观 | 词表版本化 + diff + 哈希；改版不回溯重算，需显式 `recompute(range, from_version)` 并产生新 run_id |
| 时点泄漏 | 政策顺延、媒体 15:00 切点、LLM 知识截止（Bie 用 GPT-4o mini，知识截止 2023-10） | 所有 tone 行带 `as_of` 与 `scorer_version`；LLM 轨在 prompt 中固定「不得使用外部知识/未来信息」并在证据核验时检查时间戳 ≤ as_of |
| 因果误读 | 姜富伟 2021 否证风险补偿渠道；Lehkonen 指出传导渠道唯一是分析师预期；Bie 明确不建立因果 | 所有 tone 结论附「相关、非因果」声明；机制叙事只写「信心/流动性/资金流/分析师预期」四种候选并标为待检验假设 |
| 基准不可复现 | Lehkonen 用 RMI 专有数据（论文明言不可共享）；Bie 用 GPT-4o mini | 我们的答案必须是自建可审计词典 + 公开可复现数据；报告中不引用他人数值作为本项目预期值 |
| 数字语料是合成的 | `data/samples/*` 与 `pit.duckdb` 均标注 SYNTHETIC | 增量实验只用真实段；SYNTHETIC 仅用于管线自检，UI 不呈现 |
