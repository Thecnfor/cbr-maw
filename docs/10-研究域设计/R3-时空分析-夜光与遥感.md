## 研究问题

### 精确表述

本研究域有**两个半体**，各自独立可回答：

> **(a) 时空内核（继承并重写）**：把「股票/债券/信用/汇率/跨境资金/全球」六维压力状态向量，经 Gaussian HMM 提炼为**离散风险状态机**；用**事件语法**把压力期形式化为可机器判定的事件；用**四视图历史类比 + 反例对照**回答"当前像不像过去某次危机"；用**类比加权局部投影（AW-LP）**给出条件分位预测路径。与"无条件分位基线"相比，条件路径的 CRPS 是否显著更低、PIT 是否校准？
>
> **(b) 夜光/遥感空间代理（新增）**：企业**经营地的夜间灯光强度与变化率**（空间外生信号）能否在**地理 + 时点双约束**下，对跨境金融风险与跨境资产价格提供**超出文本与数值模态**的增量信息？境外经营地夜光的异常收缩，是否是跨境企业外部冲击的有效代理？

### 为什么对跨境金融风险重要

1. **状态优于点**：跨境风险不是"某天很高"，而是"进入了某种状态"。状态机把连续的六维压力压成 K 个可命名、可解释、可复用的阶段（低/中/高压力），这是 Agent 做"我们正处于类似 2015 汇改还是 2018 贸易摩擦"这类判断的前提。
2. **事件语法让"叙事"可判定**：源系统已把事件形式化为 `触发 → 传导 → 结果` 三段式（`events.py`），把"2015 汇改"这类历史叙事变成可复跑的规则，而不是散文。
3. **类比 + 反例给出"为什么这次没爆"**：四视图检索不仅给出"像 2015"，还给出"最像但没爆"的反例及其鉴别特征 —— 这是**可证伪**的推理，而不是事后归因。
4. **夜光是"文本之外的实体活动"**：财务报表与新闻都是**低频、自报、可能被修饰**的信号；夜光记录的是**物理活动**。它对"境外经营地突然停摆/复产/扩产"这类冲击的观测时点，可能早于任何披露 —— 这正是跨境风险最需要的**前瞻性**。

> 旧项目为 Python/FastAPI/NumPy 栈，基线 §2 已定「**不使用 Python**，只迁移语义」。因此下列语义必须**在 Dart 侧重写并逐项对齐**。

#### A1. `src/cbr/temporal/regimes.py` —— 状态识别（Gaussian HMM）

| 语义 | 旧实现细节（逐条） |
|---|---|
| 模型 | `GaussianHMM(n_states=3, full_cov=False, n_restarts=8, max_iter=100, tol=1e-5, seed=42, sticky=30.0)` |
| 初始化 | KMeans（`n_init=1`）取均值；协方差按簇样本 `np.cov`；`pi` 均匀；`A = 1 + sticky·I + U(0,0.05)` 后归一 |
| 发射 | 高斯对数密度 `-0.5·(D·log2π + logdet + maha)`；对角或满协方差 |
| 训练 | 对数域 Baum-Welch（`logsumexp` 稳定），多随机重启取对数似然最高 |
| sticky 伪计数 | 转移计数 `A_num = Σ_t exp(...) + sticky·I`（**这是旧系统特有的"状态黏性"设计**，Dart 侧必须保留） |
| 选阶 | `select_regimes(k_range=range(2,5))`；`BIC = -2·LL + n_params·log(T)`；`AIC = -2·LL + 2·n_params`；`n_params = K(K-1)+(K-1) + K·D (+ K·D(D+1)/2 满协方差)` |
| 判据 | 主判据 **BIC**；同时报告**后验熵** `-(γ log γ).sum(1).mean()`（越小越确定）、平均/中位持续期 |
| 推理 | `viterbi()` 硬路径；`posterior()` 软后验 γ |
| 危险率 | `hazard_by_duration(path, covars, max_duration_bin=10)`：按"已持续 d 天"分箱统计退出率；另用**离散时间 logit**（特征 = 截断的持续天数 [+ 协变量]）给系数；`baseline` = 总体退出率；输出 `n_episodes` / `n_exits` |
| 命名 | 按**状态的平均 CFSI 排名**命名：K=2 → 低/高压力状态；K=3 → 低/中/高；K=4 → 低/中低/中高/高；K>4 → 压力层级 i+1 |

#### A3. `src/cbr/temporal/analogy.py` —— 四视图类比 + 反例对照

| 语义 | 旧实现细节 |
|---|---|
| 视图 | **数值**（标准化特征窗口，分段 DTW）/ **结构**（滚动相关矩阵上三角，欧氏）/ **叙事**（日度文本嵌入，余弦）/ **事件**（窗口内事件类型集合，Jaccard 距离） |
| 默认权重 | `numeric 0.5 / structure 0.2 / narrative 0.2 / event 0.1` |
| 预注册 | `metric_id = "mv-dtw-corr-tfidfsvd-eventset-v1"` ← **口径必须预注册**的既有范式 |
| 其它超参 | `window=20`、`prefilter_top=200`、`k=20`、`k_control=20`、`min_separation=20`、`band=6` |
| 检索 | 两步：**预筛**（展平窗口欧氏距离取 top-M）→ **精确重排**（逐列带状 DTW + 结构欧氏 + 叙事余弦 + 事件 Jaccard 加权） |

| 反例对照 | `counterfactual_analysis`：top-`k` 中命中事件者为 **A_k（类比）**，其后紧邻的 `k_control` 个为 **C_k（反例环）**；`p_A = mean(event\|top-k)`、`p_C = mean(event\|ring)`、`p_base` 由调用方给定、`lift = p_A / p_base` |
| 鉴别特征 | `_discriminators`：比较 A_k 与 C_k 在每一维的均值差（合并标准差归一），取 \|z\| 最大的 10 维，标注 `higher_in_analogue` / `lower_in_analogue` → 回答"**为何这次爆 / 为何这次没爆**" |

#### A4. `src/cbr/temporal/forecast.py` —— 条件分位预测与评价

| 语义 | 旧实现细节 |
|---|---|
| 分位集 | `QUANTILES = (0.1, 0.25, 0.5, 0.75, 0.9)` |
| Pinball | `pinball_loss(y, q, τ) = τ·(y−q) if y≥q else (τ−1)·(y−q)` |
| CRPS | `crps_from_quantiles = 2 × mean(pinball over τ)`（由分位近似） |
| PIT | `pit_values`：真实值在分位序列中的位置比例；默认填充 `len(τ)/(len(τ)+1)` |
| DM 检验 | `diebold_mariano(loss_a, loss_b, lag=5)`：差分序列的 **Newey-West（Bartlett 核）**长期方差 → `stat = mean(d)/sqrt(var/n)`，双侧正态 p 值；返回 `better`（"a"/"b"） |
| AW-LP | `aw_lp_path`：权重 `w = exp(-0.5·(d/bw)²)`（高斯核），`bw` 由调用方给（`study.py` 用 top-k 距离的中位数）；**两种口径**：`anchor=None`（水平口径）与 `anchor=y_t`（**增量锚定**，与无条件基线同口径 → CRPS 可比） |
| 无条件基线 | `unconditional_path`：`ŷ_{n+h} = y_n + Quantile_τ({ y_{s+h} − y_s })`，近端窗口 `window=250` |

### 3.1 (a-1) 状态观测向量与 CFSI（继承 `labels.py` 语义）

**Dart 类**：`CfsiCnBuilder`（六维分位 → PCA 第一主成分 → `cfsi` / `percentile` / `threshold` / `high_stress` / `y_{h}`）

| 特征名 | 定义 | 口径 |
|---|---|---|
| `dim_equity` … `dim_global` | 六维的滚动经验分位（维度内等权） | `window=1250`、`min_periods=252` |
| `cfsi_percentile` | 训练期经验 CDF 映射 | 载荷冻结 |
| `cfsi` | `cfsi_percentile × 100` | 0–100 |
| `threshold` | 训练期 q90（冻结） | `threshold_mode=frozen` |
| `high_stress` | `cfsi ≥ threshold` | 0/1，缺失为 NaN（**不填 0**） |
| `y_5` / `y_10` / `y_20` | `max_{s=1..h} high_stress_{t+s}`（B1） | 仅标签侧 |

**PIT 纪律**：滚动分位、winsorize 边界、PCA 载荷、阈值 **只在训练期估计并冻结**；测试期一律复用。

**热身期剔除**：丢弃 `cfsi` 为 NaN 的前 ~256 日（与旧系统一致），理由必须写入论文：**否则 NaN 被填成训练均值会形成一个伪"缺失状态"**。

### 3.2 (a-2) Gaussian HMM 与状态机（继承 `regimes.py`）

**Dart 类**：`GaussianHmm`（`fit` / `viterbi` / `posterior` / `bic` / `aic` / `meanEntropy` / `nParams`）、`RegimeSelector`、`HazardCurve`、`StateNamer`

**保留旧系统语义的要点（重写时不可省）**：

| 要点 | 旧语义 | Dart 侧 |
|---|---|---|
| 初始转移矩阵 | `A = 1 + sticky·I + U(0,0.05)`，归一化 | `sticky=30.0`（配置项） |
| M 步 sticky 伪计数 | `A_num += sticky·I` | 同 |
| 发射 | 对角/满协方差高斯；`+ε·I` 正则（ε=1e-8） | 同 |
| 数值稳定 | 对数域 `logsumexp` | 同 |
| 多重启 | `n_restarts`，取对数似然最高 | 同 |
| 参数计数 | `K(K−1)+(K−1) + K·D (+ K·D(D+1)/2)` | 同（否则 BIC 不可比） |
| 选阶 | BIC 主判据 + 报告 AIC / 后验熵 / 平均持续 / 中位持续 | 同 + **多准则分歧时显式标注**（见下） |

**多准则选阶（本设计新增，回应"分歧时怎么办"）**：

| 准则 | 偏好方向 |
|---|---|
| BIC | 越小越好（主判据） |
| AIC | 越小越好 |
| 后验熵均值 | 越小越好（识别可信度） |
| 平均/中位持续期 | **不能太短**（<5 交易日视为噪声态） |

**规则**：以 BIC 最优为 `K*`；若 AIC 最优的 `K` 与 `K*` 相差 1，且后验熵更低且平均持续期 ≥ 5 日 → 取 AIC 的 `K` 并在产物中记录**"选阶存在分歧，已按规则 X 裁决"**；否则用 `K*`。全部裁决写进 `RegimeSelection.decision_note`。

**状态命名**（继承 `_name_states`）：按状态内 `cfsi` 均值排名 → `低压力状态` / `中压力状态` / `高压力状态` / `中低压力状态` / `中高压力状态` / `压力层级{i}`。命名**不依赖阈值**，因此 K 变化时不失真。

**退出危险率**（继承 `hazard_by_duration`）：分箱（1–10 日，超出并入最后一箱）+ 离散时间 logit 系数 + `baseline_exit_rate` + `n_episodes` / `n_exits`。

### 3.4 (a-4) 类比检索与反例对照（继承 `analogy.py`，新增空间视图）

**Dart 类**：`AnalogyConfig` / `AnalogyIndex` / `CounterfactualAnalyzer` / `DiscriminatorCalculator` / `DtwDistance` / `DailyTextEmbeddingBuilder`

| 视图 | 旧权重 | 内容 | 距离 |
|---|---|---|---|
| `numeric` | 0.50 | 标准化特征窗口 | 分段带状 DTW（`band=6`） |
| `structure` | 0.20 | 60 日滚动相关矩阵上三角 | 欧氏 |
| `narrative` | 0.20 | 日度文本嵌入（TF-IDF + SVD，dim=32） | 余弦（1−cos） |
| `event` | 0.10 | 窗口内事件类型集合 | Jaccard 距离 |
| **`spatial`**（新增） | **0.00 → 可配** | 实体绑定区域的夜光特征向量（多地点） | 欧氏 / 余弦 |

**新增空间视图的纪律**：权重必须**预注册**并写进 `metric_id`（旧系统已有 `metric_id` 机制）。首版**默认权重设为 0**（即 `numeric 0.5 / structure 0.2 / narrative 0.2 / event 0.1 / spatial 0.0`），只有在空间特征**通过增量检验**后才允许非零进入主口径 —— 避免"先用后验"。

**检索协议（逐条继承）**：
1. 预筛：展平窗口欧氏距离，取 top-`prefilter_top`（旧系统 `study.py` 用 60，`AnalogyConfig` 默认 200 —— **两处不同，以 `study.py` 的 60 为实验口径**，差异记入缺口）。
2. 精确重排：逐列 DTW + 结构 + 叙事 + 事件 + 空间，加权求和。
3. 排除：`|p − query_pos| < min_separation`（防自身泄漏）。
4. **扩展窗口**：查询点 `t` 的可用池 `{p : p + h ≤ t}`；可用池不足 100 时跳过该点。

**反例对照**：top-`k` 为 **A_k**；其后紧邻 `k_control` 为 **C_k**（距离衰减安慰剂）。
`p_A = mean(event|top-k)`、`p_C = mean(event|ring)`、`p_base = mean(event|可用池)`、`lift = p_A / p_base`。
**鉴别特征**：A_k vs C_k 的逐维均值差（合并标准差归一）取 \|z\| 最大 10 维 → 回答"为何这次爆 / 为何这次没爆"。

### 3.8 (a-5) 条件分位预测（继承 `forecast.py`）

**Dart 类**：`AwLpForecaster` / `UnconditionalBaseline` / `PinballLoss` / `Crps` / `PitCalibrator` / `DieboldMarianoTest`

**双口径**（继承 `study.py` 的做法）：
- **水平口径**：`anchor = null` → 直接加权 `y_{s+h}`；
- **增量锚定口径**：`anchor = y_t` → 加权 `y_{s+h} − y_s` 后加回 `y_t` → 与无条件基线同口径 → **CRPS 可比**。

**基线**：`ŷ_{n+h} = y_n + Quantile_τ({ y_{s+h} − y_s : s ∈ [n−250−h, n−h) })`。

**评价**：
- `crps_aw_lp_level` / `crps_aw_lp_change` / `crps_unconditional`
- `dm_level_vs_uncond` / `dm_change_vs_uncond`（Newey-West，lag=5）
- `pit_mean_level` / `pit_mean_change`（良好校准应接近 0.5）与 **PIT 直方图**（Dart 侧新增可视化）

**nowcast**：序列末端做"过去 → 未来"条件外推（当前 CFSI、当前状态名、分位路径中位/q10/q90、各期限 `p_A`/`p_base`/`lift`、最相似历史日期）。

1. 在旧 Python 侧跑 `CBR_CONFIG=configs/app.real.yaml python scripts/run_temporal_study.py --query-step 3`，产物落 `artifacts/temporal/<run_id>/`；

### 5.4 用户实际做什么

1. **看状态机**：打开「风险状态机」，一眼看到当前处于哪个压力状态、这个状态通常持续多久、后验有多确定。
2. **查状态细节**：看转移矩阵（下一步最可能去哪）与危险率（已经待了 12 天，退出概率多大）。
3. **找历史类比**：在「历史类比检索」输入今天，系统给出最像的 15 个历史日 + 15 个"像但没爆"的反例 + 鉴别特征。
4. **看条件路径**：在「条件分位路径」看未来 5/10/20 日的 CFSI 分位扇形，与无条件基线叠加，并看 PIT 是否校准。
5. **用空间代理**：在「空间代理地图」选定一个跨境发行人，看其境外经营地的夜光变化曲线与收缩标记，再与 R1 的 Negative Tone 并排。
6. **管数据**：在「数据管线」看哪些格网还没下载、缓存占用多少、哪些数据因产品滞后被排除。

| 假设 | 表述 | 证伪条件 |
|---|---|---|
| **H1 状态机有效** | 六维压力可分解为 K 个稳定状态 | 选阶在多个切分下不稳定，或后验熵长期接近 log K（无区分度）→ 判为"状态机不成立" |
| **H2 事件可判定** | 事件语法能稳定命中历史压力期 | `stress_episode` 片段与已知历史压力期（如 2015、2018、2020）**无法对应**（人工核对）→ 判为"事件口径需重定义" |
| **H3 类比有判别力** | 类比条件概率显著高于基础率 | `mean_lift ≤ 1` 或 DM 检验 `p ≥ 0.05` → 判为"类比无判别力" |
| **H4 反例有信息量** | A_k 与 C_k 在可观测维度上可区分 | 鉴别特征 Top-10 的 \|z\| 普遍 < 0.2，或 `p_A ≈ p_C` → 判为"反例对照无信息量" |
| **H5 条件路径优于基线** | AW-LP 条件分位优于无条件分位 | `dm_change_vs_uncond` 的 `p ≥ 0.05` → 判为"条件预测无增益" |
| **H6 PIT 校准** | 条件分位路径校准良好 | PIT 均值显著偏离 0.5（如 \|mean−0.5\| > 0.1）→ 判为"校准失败"，路径不可作概率解读 |
| **H7 状态命名稳定** | 按平均 CFSI 排名的命名跨切分稳定 | 换切分后同一状态的平均 CFSI 排名反转 → 判为"命名不稳定"，必须改为按阈值命名并显式说明 |
| **H8 夜光有增量** | 夜光特征相对数值+文本提供增量预测力 | 加入夜光后样本外 PR-AUC 提升的 95% CI 覆盖 0，或 DM `p ≥ 0.05` → 判为"夜光无增量" |
| **H9 夜光交互互补** | 夜光 × tone 交互项显著 | 交互项系数不显著或符号不稳 → 判为"物理与语言信号不互补" |
| **H10 空间视图有判别力** | 加入空间视图后类比检索的 lift 提升 | `spatial` 权重 > 0 时 lift 未提升 → 判为"空间视图无效"，权重永久置 0 |
| **H11 重写等价** | Dart 重写与旧 Python 语义一致 | golden test 出现不可解释的字段差异 → **暂停新功能，先修对齐** |

> 全部假设跑批前写入 `artifacts/research/R3/<run_id>/prereg.md`。**不显著不得写成显著；仿真数据结论不得写成真实市场结论**（AGENTS.md §8）。

## 里程碑与验收

| 阶段 | 内容 | 验收标准 | 依赖 |
|---|---|---|---|
| **M0 口径拍板** | 确认 (a) 部分的 K 裁决规则、视图权重预注册口径、`metric_id` 扩展方案；(b) 部分的夜光产品绑定、地理粒度、绑定来源优先级 | ① 选阶规则文本化；② `metric_id` 新版本号确定；③ 至少 1 个夜光产品完成 `lag_days` 核实（否则该产品数据不进特征） | 用户拍板 + 产品核实 |
| **M1 标签与状态机重写** | `CfsiCnBuilder` + `GaussianHmm` + `RegimeSelector` + `HazardCurve` + `StateNamer` | ① **golden test 通过**：K 表 / 时间线 / 转移矩阵 / 后验熵 / 危险率 与旧系统逐字段对齐（容差 1e-6）；② `parity.md` 记录全部差异与解释；③ 训练期阈值与 PCA 载荷冻结并落库 | 真实数据可用 |
| **M2 事件与类比重写** | `EventSpec` / `ThresholdEpisodeDetector` / `AnalogyIndex` / `DtwDistance` / `CounterfactualAnalyzer` | ① 事件目录与旧系统 `episodes.csv` 对齐；② `p_A`/`p_C`/`p_base`/`lift` 与 `analogy_eval.csv` 对齐；③ 扩展窗口约束有自动化测试（`p+h≤t`） | M1 |
| **M3 条件分位预测重写** | `AwLpForecaster` / `UnconditionalBaseline` / `Crps` / `PitCalibrator` / `DieboldMarianoTest` | ① CRPS / DM / PIT 与旧系统 `forecast` 段对齐；② nowcast 对齐；③ PIT 直方图可视化 | M2 |
| **M4 空间代理落地** | `NightlightCatalog` / `Downloader` / `Preprocessor` / `Cache` / `GeoBindingRegistry` / `NightlightFeatureBuilder` | ① **原始影像零内嵌**（安装包与 `data/` 中无 GB 级文件，有自动化检查）；② 按需下载可跑通并支持断点续传 + 校验和；③ 格网聚合表产出并给出实测体积；④ 缺测/未下载/滞后在 UI 显式标注 | 账号与许可确认 |
| **M5 空间增量与联动** | E19–E23 实验 + 与 R1 的 `xborder.tone_neg_x_nl` 交互 | ① 增量检验给 ΔR²/DM/Holm；② 结论带"有/无增量"明确判定；③ 若无增量，如实写"无增量"并把 `spatial` 权重置 0 | M4 + R1 |
| **M6 产品化收口** | 8 个屏 + Agent + 工具 + trace | ① 每次下载与降级在 trace 可查；② 结论 100% 可回指证据；③ 缓存配额与清理可用 | M5 |

**明确不做**：不在 Dart 侧训练深度学习模型；不内嵌任何原始遥感/夜光影像；不实现真实的人脸/个体级空间识别；不把夜光结论表述为因果结论。
