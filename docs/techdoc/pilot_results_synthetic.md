# CBR-MAW 试点实验结果（SYNTHETIC 仿真数据）

> 用途：验证系统 pipeline 的**判别能力、消融机制与工程可复现性**，不构成任何真实市场结论。
> 数据：确定性仿真 DGP（`data/samples`，seed=0，2018-01-02 ~ 2025-09-30；27 序列 / 41,367 观测 / 2,207 篇文档）。
> 快照：`dataset_snapshot_id=ds_1beab3f3ffd9e31a4c5b`，`corpus_hash=corpus_7ac20be6ce7d622c8308`（`data/pit_manifest.json`）。
> 运行环境：Mock LLM（无 API key 的确定性模式），Python 3.12，`fusion-xgb-v1` 滚动快照（79 个，retrain_every=20）。
> 复现命令：`python scripts/run_experiment.py --kind p1 --p1-max-days 240`、`--kind p2 --p2-dates 4`、`--kind p3 --p3-dates 6`；产物在 `artifacts/runs/`。

## 1. P1 多模态信息增益（2024-10 ~ 2025-09，240 个交易日）

| 期限 | 正例率 | PR-AUC 数值-only | PR-AUC 数值+文本 | Δ（fusion−numeric） | 95% CI | p 值 | Recall@10%（fusion） |
|---|---|---|---|---|---|---|---|
| h=5 | 0.149 | 0.478 | 0.504 | +0.0259 | [−0.0056, +0.0677] | 0.112 | 0.429 |
| h=10 | 0.196 | 0.428 | 0.451 | +0.0227 | [−0.0018, +0.0499] | 0.088 | 0.333 |
| h=20 | 0.255 | 0.351 | 0.354 | +0.0033 | [−0.0155, +0.0237] | 0.653 | 0.143 |

**解读（须谨慎）**：融合方向为正但**均不显著**（95%CI 跨 0），h20 增量接近 0；合成 DGP 中文本模态平均贡献约 0.10（数值 ≈0.90）。该结果只验证“模态消融可执行、指标可计算”，**不得写成文本模态显著提升预警表现**；真实数据下需重跑 P1 并做统计检验。
**预警提前期**：在“前 10% 概率日”预警口径下，评估窗口内未出现“事件前 30 日内的提前预警”，提前期记为“—”（提示合成 DGP 的预警更集中于事件同期，需在真实数据与阈值调优后评估）。

|---|---|---|

| tokens | 11,799 | 7,469 |
| 任务完成率 | 1.00 | 0.00 |
| 核验通过 | 1.00 | 0.00 |
| 证据准确率 | 1.00 | 1.00 |
| 数值错误率 | 0.00 | 0.00 |

**解读**：禁用工具与知识库后，数值主张无法生成、任务完成率与核验通过率降为 0，方向符合 P2 设计（能力消融）。Mock LLM 的数值全部抄自证据，故 full 模式数值错误率恒为 0；**真实幻觉风险需 DeepSeek 等真实模型验证**。`no_tools_no_kb` 的权限拦截为消融设计导致（角色工具权限清空后仍需工具的操作被阻断），不计为系统错误。

**解读**：三模式在同一代码路径、同每角色预算下均可产出完整决策卡；collaborative 产生并解决冲突（平均 4.0 个），single/independent 无共享与协调（冲突数为 0），机制对照成立。当前 Mock 模式下主体决策损失估计相同、协同增益尚未在“决策损失”维度体现；**P3 的正式检验需真实 LLM + 真实数据**，并报告成本调整后的 J=L+μC。

## 4. 结论与待办

1. 试点验证了：P1 模态消融、P2 工具/知识消融、P3 三模式对照的**全流程可运行、可复现、产物齐全**；
2. 不代表真实市场结论：文本增量不显著、提前期为“—”、P2 数值错误率在 Mock 下恒 0，均需真实数据/真实模型复核；
3. 下一步按 `docs/techdoc/open_issues.md` 优先级：接入用户自建数据 → 配置 DeepSeek key → 重跑 P1/P2/P3 与 E3–E12 消融矩阵 → 生成论文 5.x/6.x 结果表。
