# 真实数据试点结果（P1 / P2 / P3）

> 数据：用户提供真实金融数据 + 飞书 Base 资金流 + 飞书文本语料 + 公开接口补齐；
> 快照 `dataset_snapshot_id=ds_94c8b84b60cd1248dd57`，2015-01-05 ~ 2025-09-30，
> 2,615 个交易日 / 27 条规范序列 / 57,421 条观测 / 9,758 篇文本。
> LLM：DeepSeek `deepseek-chat`（真实 API，非 Mock）。本报告与
> `pilot_results_synthetic.md` / `pilot_results_real_llm.md` 严格分开。

## 1. 数据与实验设置

| 项 | 设置 |
|---|---|
| 数据 profile | `configs/app.real.yaml`：`dataset=custom`、`synthetic_fallback=false`、`paths.artifacts=artifacts_real` |
| PIT | `release_time` 严格过滤；中国日频 18:00、全球因子 t-1 收盘、月频按发布日 |
| 标签 | `stress_pca_q90`（训练截止 2021-12-31，阈值 τ=91.51，高压力占比 12.7%） |
| 特征 | 48 数值 + 11 文本 = 59 列（2,615 × 59） |
| 真实数据模型 | `fusion-xgb-v1@20250904`，58 个滚动快照（每 40 交易日重训） |
| P1 评估期 | 2021-01-01 ~ 2025-09-30，1,152 个交易日 |
| P2/P3 评估日 | 2021-01-04 / 2022-03-15 / 2023-05-23 / 2024-07-29（等距抽样 4 个） |

## 2. 真实数据模型样本外评估（build_dataset）

测试期 425 个交易日（2022–2025），模型 `fusion-xgb-v1@20250904`：

| 期限 | PR-AUC | ROC-AUC | Brier | Recall@Top10% | 正例率 |
|---|---|---|---|---|---|
| h=5 | 0.187 | 0.798 | 0.072 | 0.323 | 7.4% |
| h=10 | 0.143 | 0.530 | 0.141 | 0.089 | 13.5% |
| h=20 | 0.229 | 0.519 | 0.257 | 0.031 | 24.0% |

解读：h=5 的判别力明显高于随机基线（正例率 7.4%，PR-AUC 0.187），ROC-AUC 0.798；
h=10 / h=20 的 PR-AUC 接近或低于正例率、ROC-AUC 接近 0.5，说明**中期/长期压力预测
在真实数据上仍很弱**，不能过度解读。真实数据规模小（2,615 日）、标签分布不均衡、
部分序列为代理口径，是主要原因。该结果与 P1 的 1,152 日回测（h5 0.695 等）不可直接比较：
P1 使用滚动快照逐日预测与更长评估期，口径不同。

## 3. P1 多模态信息增益（数值 vs 数值+文本）

评估区间 2021-01-01 ~ 2025-09-30，1,152 个交易日，配对自助法 1,000 次：

| 期限 | 数值-only PR-AUC | 融合 PR-AUC | Δ（融合−数值） | 95% CI | p 值 |
|---|---|---|---|---|---|
| h=5 | 0.695 | 0.684 | **−0.011** | [−0.026, +0.005] | 0.172 |
| h=10 | 0.632 | 0.639 | +0.007 | [−0.006, +0.019] | 0.342 |
| h=20 | 0.612 | 0.617 | +0.005 | [−0.002, +0.013] | 0.214 |

结论：**文本模态未带来统计显著增益**；h=5 略负、h=10/20 略正，方向不一致，p 均 >0.17。
可能原因：① 文本语料时段不均衡（2017–2020 主要靠光明日报，2021+ 才有政策媒体），
文本特征在部分年份稀疏；② 当前文本表征为词典/情绪特征，信息增益有限；③ 真实标签由
市场压力复合指标构造，数值因子本身已捕获大部分可预测信息。**不能据此宣称多模态融合
在真实市场有效**，需补语料与更强文本表征后再检验。

## 4. P2 金融知识与专业工具增强消融（真实 DeepSeek）

4 个评估日，full（7 工具 + 29 篇知识库） vs no_tools_no_kb：

| 指标 | full | no_tools_no_kb |
|---|---|---|
| claims 数 | 18.0 | 7.5 |
| 工具调用次数 | 17.25 | 0 |
| 工具越权尝试被阻断 | 0 | 17 |
| 冲突数 / 已解决 | 4.75 / 4.75 | 0 / 0 |
| task_completion | 1.0 | 1.0 |
| task_completion_tool_evidence_gated | **1.0** | **0.0** |
| 被拒 claim（草稿级） | — | 7.5 |
| decision_loss（越低越好） | **1.325** | 1.360 |
| 延迟（ms） | 15,062 | 10,987 |
| 实际 tokens/运行 | 18,783 | 12,771 |

结论：工具与知识库显著增加可核验主张与工具调用，并使「工具证据门槛版任务完成率」
从 0 升至 1；无工具变体的 17 次越权尝试全部被 `default_deny` 阻断（设计性现象，非
系统错误），且 7.5 条无工具证据的 claim 在草稿级被拒。终卡 `numeric_error_rate` /
`unsupported_claim_rate` 仍为 0（自检回填 + 证据过滤后的饱和值，见真实 LLM 报告），
因此以草稿级指标与 decision_loss 作为主要证据。

## 5. P3 多智能体协同对照（真实 DeepSeek）

4 个评估日（2021-01-04 / 2022-03-15 / 2023-05-23 / 2024-07-29）× 三模式：

| 指标 | single | independent | collaborative |
|---|---|---|---|
| 任务完成率 | 1.00 | 1.00 | 1.00 |
| 工具证据门槛完成率 | 1.00 | 1.00 | 1.00 |
| claims 数 | 17.5 | 18.0 | 18.0 |
| 其中数值 claim | 10.5 | 11.0 | 11.0 |
| 工具调用次数 | 18.0 | 14.0 | 16.5 |
| 冲突数 / 已解决 | 0 / 0 | 0 / 0 | **4.25 / 4.25** |
| decision_loss（越低越好） | 1.325 | 1.325 | 1.325 |
| 核验通过 | 1.00 | 1.00 | 1.00 |
| 数值错误率 | 0.00 | 0.00 | 0.00 |
| 延迟（ms） | 13,758 | 11,991 | 11,664 |
| 实际 tokens/运行 | 19,612 | 18,782 | 18,773 |
| 成本（统一单位） | 0.168 | 0.146 | 0.145 |
| trace 事件数 | 60.8 | 58.8 | 94.5 |

结论：协同模式是**唯一产生并解决冲突**的模式（平均 4.25 个，全部解决），审计事件也
最多（94.5 条 vs 60 左右），说明证据共享/交叉验证/仲裁机制按设计运行；但三模式的
`decision_loss` 完全相同（1.325），即本试点中**协同没有带来可测量的决策损失改善**——
决策损失由共享风险信号主导，与合成数据 P3 的限制一致。真实数据 + 真实 LLM 下仍
未观察到协同增益，需要更细的决策任务/损失口径（如按主体分别计损失）再验证。

**P3 结论（pilot 级）**：协同机制可运行、可审计、可消解冲突，但决策收益未显现；
不能据此宣称协同优于单智能体。该结论与 P2 的「工具/知识提升可核验性与证据门槛」
一起，构成本轮真实数据试点的诚实边界。

## 6. 结论与限制

1. 真实数据上**数值信号在 5 日尺度有可用判别力**（P1 h5 PR-AUC 0.695、ROC-AUC 0.798），
   但 10/20 日尺度弱；P1 文本增益不显著。
2. P2 表明工具/知识库的价值主要体现在**可核验性与证据门槛**，而非终卡数值错误率
   （后者在自检回填后饱和）。
3. P3 表明协同模式能产生并解决冲突、审计更完整，但 `decision_loss` 与单智能体相同，
   **协同的决策收益未显现**；不能写成"协同优于单智能体"。
4. 真实数据存在代理口径（SHIBOR 1W→7 天回购、AAA→AA 利差、累计净流入→北向持仓、
   滚动增量→社融存量同比）与披露缺口（北向 2024-08-16 停披露、CPI 2015–2020 缺失），
   结论需在更完整数据上复核。
5. P2/P3 仅 4 个评估日，LLM 输出存在随机性；结论为 pilot 级，不构成正式论文结果。
6. 所有结果均为研究性原型输出，不构成投资或监管建议。
