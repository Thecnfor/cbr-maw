## 1. 结论摘要

1. **C − D 的增量不显著**：Δlift = **+0.021**（1.714 vs 1.693），Δprecision = +0.008，McNemar p = **0.729**（n=1196，不一致对 208）。两个新工具在整体判别上**没有可证明的增益**。
2. **`capital_linkage` 的 headline 不稳健**：单一切分 lift **2.0828×**，逐年 walk-forward 平均 **0.7288×**（8 年平均，仅 4 年 >1）；2024–2026 的 0 触发是**北向数据 2024-08-16 停更**，不是信号失效。
3. **`dimension_dispersion` 是唯一跨期稳健的指标**：headline **1.7084×**，逐年平均 **1.97×**，8/8 年 >1。但它**同期型**（lead_profile 峰值 h=0），不是领先指标。
4. **A 组未验证：DeepSeek 401**（2026-11-27 实测）。JEV 裁判可跑，但它是确定性裁判、**不是 A 组**，不能替代 LLM 直答结论。
5. **最重要的负面结果：标签循环性**。`high_stress := (CFSI > τ)`，且 y_20 含当日 → `P(y=1 | hs_t=1) = 1.000`。所有 CFSI 派生臂的高 lift 有相当部分来自"当日在压力区"的同义反复；换严格未来标签（不含当日）后 CFSI 规则 lift 从 1.693 降到 1.626。

### 5.4 结构类指标

| 指标 | 结果 | 判定 |
|---|---|---|
| `dominant_dim` 命中率 | **3/18 = 0.167**（随机 1/6 = 0.167） | **与随机猜维度无差异** |
| 阶段信号（离散度高 + 信用缓解 → 20 日内信用转差） | 条件率 0.965（n=141）vs 无条件 0.904（n=908） | lift 1.067，binom p=0.006 |

**结构判读的两个诚实结论**：
1. "用当日最强维度预测压力窗内最恶化维度"**不成立**——命中率恰好等于随机。docs/20 §2.1 的"跨境资金先行"是**窗口前 40 日的均值差**，不是"当日最强维度能预测谁最恶化"。
2. 阶段信号**有微弱增量**（+6.7 个百分点，p=0.006），但绝对差异小（0.965 vs 0.904），且"信用维 20 日内至少升一次"本身就是高基线事件（90%），**不宜作为强告警**。

### 5.5 标签循环性诊断（本轮新增）

| 项 | 值 |
|---|---|
| `P(y_20=1 \| hs_t=1)` | **1.000**（定义使然：y_20 含当日） |
| `P(y_20=1 \| hs_t=0)` | 0.286 |
| `P(y_strict=1 \| hs_t=1)` | 0.919 |
| CFSI 规则 lift（y_20，含当日） | 1.693 |
| CFSI 规则 lift（y_strict，不含当日） | **1.626** |

`y_strict = max(high_stress[t+1..t+20])`，尾部 20 行丢弃（n=1176）。**这是本报告最重要的方法学限制**：`high_stress` 的定义就是 `cfsi > τ`，所以任何 CFSI 派生信号在预测一个含当日的标签时，本质是在**重建标签**而非预测。严格未来标签下 lift 仍 >1.6，说明信号**并非完全循环**，但 headline 数字必须打折理解。

## 6. 失败与负结果（必填）

1. **A 组无法执行**：DeepSeek 密钥 401。→ 阻塞：需有效密钥。**没有用任何替代输出伪造 LLM 结果。**
2. **C 组不是完整 CBR-MAW**：LLM 生成侧不可用 → 四角色 R0–R5、冲突三分类（fact/directional/preference）**全部 BLOCKED**。本报告的 C 只是确定性工具链，**不支持"多智能体优于单模型"的任何主张**。
3. **`traceability_rate` / `numeric_consistency` / `cross_role_disagreement` 全部 BLOCKED**：前者的 1.000 只是确定性工具 evidence_id 可重算，**不是** LLM claim→evidence 的溯源率。
4. **C − D 增量不显著**（p=0.729）：两个新工具在整体判别上没有可证明的增益，且 `capital_linkage` 的留一贡献为负（+0.038 去掉更好）。
5. **`capital_linkage` headline 与 walk-forward 严重背离**（2.083 vs 0.729）：81 个 TP 集中在 2022–2023，2024 后因数据停更 0 触发。docs/18 §7 与 ADR-009 已据此降级。
6. **`dominant_dim` 命中率 = 随机**（3/18 vs 1/6）：结构判读的"预测下一阶段主导维度"用法被证伪。
7. **B 臂 2026 年 0 触发**（lift=0.0）：该年基准 22.5%，模型阈值 0.35 未触发任何信号——是**模型保守**而非数据缺失（csi300/vix/sp500 均新鲜）。8. **`dimension_dispersion` 是同期指标**（lead_profile 峰值 h=0），不能表述为"提前预警"。
9. **2025 年基准发生率骤降到 9.2%**（4 个高压日、1 段窗口），该年 lift 的数字对少数事件高度敏感，**不作强主张**。

## 7. 局限

- **样本量**：样本外 1196 天、20 段压力窗口。窗口级统计（提前量 20 段）n<30，**不作显著性主张**；`dominant_dim` 18 段同理。
- **标签循环性**（§5.5）：所有 CFSI 派生臂的 headline lift 含"当日在压力区"的同义成分，严格未来标签下应打折约 4%。
- **数据源**：北向 2024-08-16 停更、南向/信用/回购/USDCNY 2025-09-30 停更。依赖它们的指标**只能做历史回测**。
- **A/C 组缺失**：不支持任何"多智能体协同优于单模型"的结论，需补密钥后重跑。
- **JEV 裁判的 n=80**（80 次请求全部成功）：precision 95% CI [0.383, 0.655]，宽到无法区分 0.5 与 0.65。它的 1.30× 只说明"裁判能读懂压力摘要"，不是能力对比；且同一输入重跑结果会变（模型非确定性——三次重跑 precision 分别为 0.521/0.556/0.522），**不可作为回归断言**。
- **相关性非因果**：所有结构/联动指标均为相关度量。
- **SYNTHETIC 严格隔离**：`data/samples/` 与合成库**未参与**本报告任何数字；`self_check.dart` 的合成用例只用于验证指标实现，已显式标注。
