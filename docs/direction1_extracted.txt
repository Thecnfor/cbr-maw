[Normal] 跨境资本流动与系统性金融风险：影响机制与前瞻预警
[Normal] 论文研究框架
[Normal] 摘要（待补充）：拟利用沪深港通逐股日度跨境资金数据，分析资本流动与系统性金融风险的关系及作用机制，并检验其对未来高风险状态的增量预警信息；待实际估计完成后补充数据、方法、主要发现和政策含义，不预设结果方向。
[Normal] 关键词：跨境资本流动；系统性金融风险；沪深港通；风险作用机制；前瞻预警
[Normal] 研究对象说明：题目中的跨境资本流动主要指沪深港通股票跨境投资活动；若数据仅为逐股持仓变化，不应直接表述为实际净交易额。系统性风险须明确区分个股对市场的尾部风险贡献与市场整体风险。
[Heading 1] 一、引言
[Normal] 本节拟解决：提出研究的现实意义、理论问题与相对于现有文献的边际贡献。
[Heading 2] 1.1 研究背景与问题提出（最终成文无需该二级标题）
[Normal] 在金融市场互联互通背景下，跨境资金的个股配置调整可能与市场尾部风险形成及传播相联系；本文依次回答资金流动是否影响系统性风险、通过何种机制作用，以及是否具有前瞻预警信息。
[Heading 2] 1.2 研究思路与边际贡献（最终成文无需该二级标题）
[Normal] 已有研究关注互联互通开放的系统性风险效应（Li等，2023）及金融市场跨市场传染（周开国等，2021）。本文拟转向逐股日度资金流动，重点检验资金集中与同步调整的风险机制，并以严格的样本外预测考察流动规模和配置结构的增量预警信息，三方面均须由实证结果支持。
[Heading 1] 二、文献综述与研究假设提出（以下二级标题及有关内容结合实际修改，下同）
[Normal] 本节拟解决：围绕风险效应、经济机制与前瞻预测三个层次，分析研究现状，揭示研究不足，进而提出具有经济学可检验含义的研究假设。
[Heading 2] 2.1 跨境资本流动与系统性金融风险
[Normal] 梳理金融开放、资本流动和系统性风险贡献的已有证据，区分制度开放效应与实际资金配置效应，据此提出基准风险关系假设。
[Normal] H1：跨境资本流动（即本文的跨境股票资金的净卖出=inflow-outflow）对个股的系统性风险贡献具有显著正向影响。（4.1&4.2）
[Heading 2] 2.2 跨境资本流动的风险作用机制
[Normal] 从市场流动性约束和跨股票同步交易两个可观测渠道推导风险作用机制，提出资金流入、流出及压力状态可能存在差异化影响的假设。
[Normal] H2：跨境资本流动通过降低股票市场流动性增加个股的系统性风险贡献，且该效应在跨境资金同步撤离程度较高时更加显著。（4.3&4.4部分）
[Heading 2] 2.3 跨境资本流动的风险预警信息
[Normal] 基于信息交易与共同风险暴露的逻辑，提出资金流动的方向、异常程度和配置结构可能具有额外预测信息的待检验假设。
[Normal] H3：跨境异常资本流动（即跨境股票资金的异常净卖出）与同步撤离对系统性金融风险具有显著正向预测作用，并能够提供传统金融风险指标之外的增量预警信息。（5.1-5.3部分）
[Heading 1] 三、制度背景、数据与研究设计
[Normal] 本节拟解决：明确沪深港通的制度边界、数据口径、风险测度和实证识别基础，保证研究问题与指标一致。
[Heading 2] 3.1 沪深港通制度与数据来源
[Normal] 界定北向与南向股票范围、交易日及原始字段，并核实逐股买入卖出额与持仓变化的区别；考虑2024年8月19日之后北向公开持仓披露口径调整和南北向数据覆盖差异。
[Heading 2] 3.2 跨境资本流动的特征事实
[Normal] 描述逐股资金流动或持仓调整的规模、方向、异常程度、行业集中度和同步性，并分别呈现北向与南向样本的分布特征。
[Heading 2] 3.3 系统性金融风险测度与变量构建
[Normal] 以个股对剔除自身市场组合的尾部风险贡献（如ΔCoVaR）作为微观被解释变量，并设置独立的市场整体尾部风险或金融压力指标用于预警；避免把个股价格波动等同于系统性金融风险。
[Heading 2] 3.4 计量模型与识别策略
[Normal] 建立个股与时间固定效应的基准模型，说明资金流动的时间顺序及反向因果问题；市场共同同步性指标采用市场时间序列或与个股暴露的交互识别，避免被时间固定效应吸收。
[Heading 1] 四、跨境资本流动对系统性金融风险的影响及机制检验
[Normal] 本节拟解决：在风险关系的基础上，检验非对称性、作用渠道及条件差异，不把统计关联直接解释为因果机制。
[Heading 2] 4.1 基准回归分析
[Normal] 检验跨境股票资金净卖出对个股系统性风险贡献的影响，分析其方向、显著性及经济量级，对应H1。
[Heading 2] 4.2 风险效应的非对称性与异质性
[Normal] 比较跨境资金流入、流出及异常撤离的风险效应，考察南北向资金、企业特征和市场压力状态下的差异，对应H1的拓展检验。
[Heading 2] 4.3 市场流动性传导机制
[Normal] 检验跨境资金净卖出是否通过降低股票市场流动性增加个股系统性风险贡献，对应H2的机制检验。
[Heading 2] 4.4 同步交易的风险共振机制
[Normal] 利用个股横截面信息构建资金流动同步性、集中度等指标，检验跨境资金同步撤离是否强化资金净卖出对系统性风险贡献的影响，对应H2的调节效应检验。
[Heading 2] 4.5 南北向市场差异与异质性分析
[Normal] 比较南北向资金流动的风险效应，进一步考察企业规模、跨境投资者持股暴露及金融压力状态下的差异，揭示H1、H2的适用条件与边界。
[Heading 1] 五、跨境资本流动与系统性金融风险的前瞻预警
[Normal] 本节拟解决：将跨境资金流动及其配置结构转化为前瞻性风险信号，检验其对未来系统性金融风险的增量预测能力和极端风险预警效果。
[Heading 2] 5.1 预警目标与模型设定
[Normal] 构建系统性金融风险预警指标与高风险状态标签，明确预测期限（如未来5、10、20个交易日等）、基准模型和滚动样本外检验方案，对应H3的研究设计。
[Heading 2] 5.2 跨境资本流动的增量预测信息
[Normal] 在传统金融风险、市场与宏观指标基础上逐步加入跨境资金异常净卖出、集中度和同步性指标，检验其对未来系统性金融风险的增量预测能力，对应H3的核心检验。
[Heading 2] 5.3 极端风险预警效果与经济价值
[Normal] 检验跨境资金流动信息对极端风险的提前识别能力（如利用PR-AUC、召回率等指标），并评价预警提前期、误报漏报及风险管理的经济价值，对应H3的拓展检验。
[Heading 1] 六、稳健性检验
[Normal] 本节拟解决：考察核心风险关系、机制证据与样本外预警结论是否依赖特定变量口径和模型设定。
[Heading 2] 6.1 风险测度与资本流动指标替换
[Normal] 比较替代系统性风险测度、流动规模标准化方式、净交易与持仓调整口径以及不同样本区间，报告同口径可比结果。
[Heading 2] 6.2 内生性与识别检验
[Normal] 考虑市场风险反向驱动资金流动、股票入选资格和全球共同冲击，通过滞后与领先检验、强化控制或可信外生变动开展识别补充，限定因果表述。
[Heading 2] 6.3 预警模型稳健性
[Normal] 更换预测模型、滚动或扩展训练窗口、高风险阈值与信息集，检查增量预测结果能否在不同时段及压力状态下稳定成立。
[Heading 1] 七、研究结论
[Normal] 本节拟解决：按“风险效应—作用机制—前瞻预警”的次序归纳实际证据及其适用范围。
[Heading 2] 7.1 主要研究结论
[Normal] 分别概括跨境资金流动的风险关系、机制检验与样本外预警表现，明确哪些假设获得支持、哪些未获支持，并如实说明识别局限。
[Heading 2] 7.2 政策启示
[Normal] 围绕逐股跨境资金异常变动和同步性监测提出审慎的预警应用启示，区分统计风险信号与需要监管干预的因果证据。

[Normal] 原第4.1—4.4节关于数据来源、变量构建、ΔCoVaR测度及描述性统计的内容，可改造后用于本文第三章，但需将原金融机构周度面板调整为沪深港通南北向逐股日度数据，核实资金净交易与持仓调整的口径差异，并重新界定个股系统性风险贡献与市场整体风险指标。
[Normal] 原第4.5—4.7节关于基准回归、异常及极端资本流动、局部投影模型的设计，以及第5.1—5.3节的实证结果分析，可迁入本文第三章3.4和第四章4.1—4.2，重点服务H1的基准效应、非对称性及动态检验。原第4.8—4.9节和第5.4—5.5节关于DY跨市场风险连通性及CNY/CNH联动的研究，可选择性保留为市场压力控制、拓展分析或稳健性检验，但不能直接替代本文第四章4.3—4.4的市场流动性传导与同步交易机制，后者需新增逐股流动性、资金同步性及集中度指标，重点验证H2。

[Normal] 原第6.1—6.5节中有关风险测度替换、资本流动指标替换、极端阈值及预测窗口调整的内容，可筛选并入本文第六章。原第4.10.3—4.10.4节及第5.7—5.8节涉及的数值语义化、多模态融合、RAG和LLM-Agent智能预警内容，原则上保留给方向2研究，不作为本文的核心方法与创新贡献。
[Normal] 需要注意的是，原稿以金融机构周度数据和跨境暴露度交互项为主要研究基础，而方向1侧重沪深港通逐股资金流动及其系统性风险效应。因此，原稿的计量方法、风险测度和预测思路可以借鉴，但核心变量、回归模型及机制检验必须根据新的研究对象重新设计，不能直接沿用原有实证结果。
