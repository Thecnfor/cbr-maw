# 17 · 文本维实证检验（真实数据）

> 日期：2026-11-25 · 状态：**已实跑**（脚本与中间产物可复现）
> 目的：在动手实现"媒体基调"能力之前，先用**真实数据**验证"文本能否提前于数值发出预警"这一产品假设。
> 结论摘要：**关键词文本特征在本语料上只有同期相关，没有领先性；增量体现在风险词强度与文档计数对"未来 20 日进入高压力"的预测改善上，但绝对预测力仍弱。** 因此产品叙事必须从"领先预警"改为"同期交叉验证 + 原因归因"，并把 **LLM 打分轨**（MT-02）提为 P0。

## 4. 领先性的双向核验（避免自欺的两个陷阱）

### 4.1 双向相关曲线

| 文本特征 | 领先方向 corr(text(t), cfsi(t+h)) | 滞后方向 corr(text(t), cfsi(t−h)) |
|---|---|---|
| text_risk_intensity_5d | h=0: 0.074 / h=5: 0.063 / h=20: 0.072 | h=1: 0.080 / **h=5: 0.110** / h=20: 0.077 |
| text_sentiment_5d | h=0: −0.053 / h=5: −0.042 | h=0: −0.053 / h=20: +0.011 / **h=40: +0.133** |
| text_doc_count_5d | h=0: −0.023 | h=40: +0.045 |

### 4.2 峰值时间差

每个压力窗内 CFSI 峰值日与文本强度峰值日之差（交易日）：**中位数 −4、均值 −2.5、仅 42.1% 的窗口文本更晚**。

**结论**：文本与数值压力**基本同期**（文本峰值略早 2–4 天，量级在噪声范围内）。既**不是**领先指标，也**不是**明显的滞后报道。此前"文本是事后追认"的猜测**不成立**，已撤回。

### 4.3 方法论陷阱（本次踩中，记录下来）

用「文本分位 − 数值分位」构造"跨模态背离度"再与 CFSI 求相关，会得到 **−0.467** 的强负相关。**这是构造性负相关的伪结果**：被减项（数值综合分）本身就是 CFSI 的输入，任何差值都会与它负相关。

**规则**：
- 不得用「A − B」构造背离指标后与 A 的下游量求相关；
- 背离/一致性度量必须用**秩相关或互信息**等**对称**统计量，或先对两侧做**标准化后再比较**（如 z 分数之差再对标准化后的两侧无关的标量求相关）；
- 任何"跨模态背离有预测力"的结论，必须先跑**安慰剂检验**（把两侧随机打乱后指标必须失效）。

本项目已按此规则重做：文本-数值背离在**对称口径**下样本外 precision 0.300、相对基准提升 **0.79×**（低于基准 38.13%）→ **背离指标无预测力**，不予实现。

## 5. 结论（对设计的强制修正）

5.1 **不能宣称"媒体基调领先预警"。** 在本真实中文政策新闻语料上，关键词文本特征**没有可用的领先性**，只有弱同期相关。文献里的 3–6 个月领先期（Lehkonen 2025）、1 个月领先（姜富伟 2024）依赖的是**英文财经新闻 + LLM 打分**，不是关键词法 + 中文政策新闻。
5.2 **文本维的真实价值是"同期交叉验证 + 归因"**：数值说"压力上来了"，文本说"因为资本管制/外部冲击/流动性收紧"——这正是多智能体 + 证据链 + 冲突三分类的产品形态能变现的地方。
5.3 **词典情感轨必须重做**（`text_sentiment_5d` 显著为负）。词典轨（MT-01）只作基线与可审计对照，**LLM 打分轨（MT-02）提为 P0**。
5.4 **增量检验工具（MT-07）与领先期工具（MT-08）必须先于任何新特征上线**——否则无法证伪自欺。这两个工具同时就是 bench 的度量协议。**必须内置两条防自欺规则**：①「跨模态背离/一致性」只能用**对称统计量**（秩相关、互信息、标准化后比较），禁止用 A−B 差值构造（见 §4.3）；②任何「某特征有预测力」的结论必须附**安慰剂检验**（打乱后必须失效）。
5.5 **数据覆盖是主因之一**：当前语料 9798 篇、以政策为主、金融媒体与英文全球新闻缺失（`cross-border capital flow` 关键词组仅 13 篇）。补源（MT-06）比换模型更可能带来领先性。
