## 状态约定

- `🟡 提议` —— 已写但未获产品负责人确认，实现前必须确认。
- `✅ 采纳` —— 已确认，实现必须遵循；变更需新 ADR。
- `⛔ 否决` —— 记录以避免重复讨论。
- `♻️ 被取代` —— 保留原文并在顶部标注取代它的 ADR。
