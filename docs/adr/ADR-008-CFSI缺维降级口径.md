# ADR-008 · CFSI 缺维降级口径

- 日期：2026-11-27 · 状态：**✅ 采纳** · 决策人：项目负责人
- 相关：[docs/00 §4](../00-设计基线.md) · [docs/20](../20-角色分歧与风险来源结构.md) · [ADR-009](ADR-009-研究增强准入标准与当前裁决.md)

## 背景

CFSI-CN 由六维构造（股票 / 债券 / 信用 / 汇率 / 跨境资金 / 全球）。但真实数据现状是：

| 维度 | 覆盖情况 |
|---|---|
| 股票、债券、全球 | 完整（到 2026-10） |
| 汇率、跨境资金、信用 | **停在 2025-09-30 之前**；北向净流入 **2024-08-16 停更** |

也就是说：**六维注定不全**，且缺的是不同维度、不同时段。

旧版实现（`stress_pca_q90`）用训练期冻结的 PCA 载荷与 q90 阈值 τ。缺维时如果继续用冻结口径，会把「维度缺失」错误地表达成「压力下降」。

## 决策

### 1. 缺席维度不参与，且**禁止填充**

- 缺席维度**不进** PCA / 等权合成；
- **禁止**用 0、均值、前值填充（`docs/02` F4-8「缺失 ≠ 零值」）；
- 结果结构**强制**追加 `missing_dims` 与 `limitations`（复用 F2-18 系统追加机制）。

### 2. τ 与载荷在缺维时**不冻结**

- `stress_pca_q90` 的 τ 与 PCA 载荷按**实际可用维度**重新估计，并在数据卡标注口径变化；
- 六维齐备后**恢复冻结口径**；
- 口径变更记录在本 ADR 与 `label_version` 中，**换口径 = 换实验结论**，必须重跑并标注。

### 3. 可用维度阈值

- 可用维度 < 2 → CFSI 不可计算，返回 `E_DATA_MISSING`（不返回 0 或 null 值冒充）。
- 可用维度 < 4 → **结构类指标**（`dimension_dispersion`）返回 `insufficient_data`，不给出结构判读。

### 4. 数据新鲜度必须随结论披露

`sources.health` 对每个来源依赖的序列给出 `latest_available` / `nan_rate` / `freshness`：

| freshness | 判定 | 产品含义 |
|---|---|---|
| `fresh` | 最新观测距 now ≤ 30 交易日 | 可用于实时研判 |
| `stale` | 31–60 | 可用但需标注滞后 |
| `dead` | > 60 | **不得用于实时预警叙事**，只能做历史回测 |
| `unknown` | 无数据 | 显式「不可达」 |

## 后果

### 正面
- 缺失不会被误读成"压力下降"。
- 用户能看到"哪一维没算进去、为什么"，而不是看到一个不可解释的数字。

### 负面 / 必须接受
- 缺维期间 CFSI 的绝对水平**不可与历史口径直接比较**（已用 `label_version` + limitations 标注）。
- 结构判读在缺维时会失效（`insufficient_data`），风险卡的六维分解会显示「未计入」而非数字——这是**正确的诚实**，但用户体验上有"空洞"。
- 补源优先级高于任何算法改进（见 `docs/18 §7.3`）。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 缺维用均值/0 填充以保持六维齐全 | 直接违反「缺失 ≠ 零值」，且会把缺失伪装成"压力正常" |
| 缺维时继续用冻结的 τ | 冻结阈值是按六维分布估的，缺维后分布改变，会系统性低估 |
| 缺维时不出结论 | 过度保守：四维以上仍可给出可辩护的结论 + 显式局限 |
