# ADR-004：数据抓取原则 —— 来源台账驱动、绝不内嵌、绝不 mock

- 日期：2026-11-25 · 状态：✅ 采纳 · 决策人：产品负责人
- 相关：[docs/00-设计基线.md §4](../00-设计基线.md) · [docs/05-数据抓取与时点设计.md](../05-数据抓取与时点设计.md)

## 背景

`ref/数据汇总统计表-简化版(1).xlsx`（工作表 `数据来源汇总`）登记了 **35 个数据来源**，横跨 5 个模态：

- **文本**：中国人民银行、美国联邦储备系统、IMF、Bloomberg News、LSEG/Refinitiv、WSJ、雪球、X、香港交易所披露易、Bloomberg Intelligence
- **语音**：Wind 3C 会议数据库、Bloomberg TV、美联储发布会、ECB 发布会、OPEC
- **图像**：上市公司年报图表、行业研究白皮书、Wind 终端 K 线、中科院地球大数据科学数据中心（遥感）、NASA Earthdata（夜间灯光）
- **视频**：Bloomberg TV 访谈、企业路演、美联储/ECB 发布会、业绩说明会
- **数值**：Wind 终端（北向资金）、Bloomberg Terminal（中资离岸债、跨境企业、跨境债券发行）、LSEG（外汇利率）、CSMAR、FRED、World Bank、国家外汇管理局、Cboe

其中相当一部分是**持牌付费终端**（Bloomberg Terminal / Wind / CSMAR / LSEG / Wind 3C），本机无法直接抓取。另有旧项目 `data/raw/`、`data/结构化数据/`（4.3 GB）等真实数据。

> **档位判定原则**：**档位由具体数据集与端点决定，不由机构名决定。** 例如 Cboe 的 VIX 官方历史 CSV 已在旧项目验证可用，属「公开可取」；同一机构若某个数据集需终端或商业授权，则该数据集单列为「需授权」。35 行逐条判定见 [docs/05-数据抓取与时点设计.md §2.3](../05-数据抓取与时点设计.md)。

用户原话：「那边是从这里来源获取的数据，都需要一并打包过去，但是这些数据不能内嵌！不能专门写个关于他们的 mock！这很无聊」「实时数据获取就是需要从那里自动检测了」。

## 决策

1. **绝对禁止内嵌来源数据**：不在安装包、不在仓库、不在任何静态资源中携带这 35 个来源的真实数据。
2. **绝对禁止为任何来源写 mock / 假数据 / 占位行情**。界面永不出现伪造数值。
3. **来源台账驱动**：35 个来源全部登记为结构化台账（模态、细分类型、采集对象、来源、时间范围、频率、数量单位、核心指标、增量信息、访问方式、授权状态、可达性状态、最后成功时间、陈旧阈值）。
4. **三档处理**：
   - 公开可取源 → 真实抓取，落本地 PIT 库，带真实时间戳与来源证据；
   - 持牌付费源 → 用户提供凭证的适配器；无凭证时 UI **显式标注「需授权」**；
   - 不可达源 → 在台账中写明原因（需登录 / 反爬严 / 仅本机终端 / 需商业授权 / 不合规）。
5. **运行模型**：抓取发生在 App 运行时；Windows 支持托盘常驻 + 开机自启；Android 前台定时 + 手动触发。
6. **无 mock 的技术保证**（不靠约定，靠代码）：
   - 任何数值进入特征与信号计算前，必须携带 `sourceEvidence`（HTTP 状态、响应哈希、请求 URL、抓取时间）；
   - 数据集必须带 `synthetic` 标记，仿真数据在 UI 上有醒目标识；
   - 测试夹具必须显式标注 `synthetic`，且产品代码不得读取夹具目录作为产品数据。
7. **采集礼仪**：遵守 robots 或按白名单豁免并记录；带可识别 UA；低频串行；遵守 `Retry-After`；不做压测式抓取。
8. **时点纪律不变**：`release_time ≠ obs_date`；境内当日 18:00、隔夜海外次日 09:00、月频 7–12 天；缺失 ≠ 零值。

## 后果

**正面**
- 产品的数据主张是诚实的：界面上每个数字都能追到「哪个来源、什么时候抓的、响应是什么」。
- 与 ADR-001（无服务器）一致：数据获取是**客户端行为**，用户自己有权访问什么就抓什么。
- 台账本身是一份有价值的**数据可得性情报**（哪些源公开、哪些要授权、哪些不可达）。

**负面 / 必须接受**
- **首版能看到的数据远少于 35 个源**。这是真实约束，不通过造假掩盖。
- 持牌源的接入成本高（终端本机 API、出口 IP、配额），本代只交付适配器接口。
- 抓取质量受外部站点变化影响 → 需要可达性探测 + 来源健康面板 + 失败隔离。
- 旧项目 `data/raw/`、`data/结构化数据/` 等真实数据**不迁移到本仓库**（体积、来源授权、再分发风险）。

## 迁移处理

| 旧路径 | 处理 |
|---|---|
| `data/samples/`（SYNTHETIC） | **仅作测试夹具**；产品 UI 不得呈现为真实数据；带 `synthetic` 标记（待复核，见基线 Q4） |
| `data/knowledge/`（语料 + 索引） | 语料保留，索引重建 |
| `data/raw/`、`data/结构化数据/`、`data/custom/` | **不迁移**（用户真实数据、体积大、来源授权不明） |
| `configs/sources.yaml`（13 个源） | 迁入新台账，作为已验证可达的子集 |
| 增量投递箱清洗规则 | **完整继承**（旧项目的产品护城河） |
