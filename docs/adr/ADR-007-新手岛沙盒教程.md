# ADR-007 · 新手岛沙盒教程

- 日期：2026-11-27 · 状态：**✅ 采纳**（v2 交付） · 决策人：项目负责人
- 相关：[docs/11 §9](../11-实施设计.md) · [docs/22](../22-五分钟上手与首次体验.md) · [ADR-009](ADR-009-研究增强准入标准与当前裁决.md)

## 背景

新用户面对的是一个「需要自己投喂数据才能用」的工作台。第一次使用时既没有数据，也不知道该问什么。需要一个**可跳过、可重看**的引导，且不能污染真实数据。

同时有一条硬红线：**绝不内嵌来源数据、绝不为任何来源写 mock**。因此教程数据必须显式标注 SYNTHETIC，且**不得进入风险定级与对外结论**。

## 决策

### 1. 新手岛是独立模块，不是"演示模式"

- 位置：`apps/desktop/lib/features/onboarding/`（状态机 + 进度清单 + 高亮 overlay + 本地埋点，埋点不上传）。
- **高亮 overlay 不进 A2UI catalog**——避免扩大 Agent 可渲染面。
- 七步流程（对应 docs/22 的首次体验）：填密钥 → 选数据模式 → 投喂 → 看清洗结果 → 第一次提问 → 读风险卡六维 → 打开证据详情。

### 2. 复用真实代码路径，不另写演示逻辑

教程数据通过**预制合成 Excel/CSV 投入教程工作区的 inbox**，走真实的
`inbox.ingest` → `pit.ingest` → 特征 → 工具 → Agent 链路。

**禁止**：另写演示逻辑；在 collector/kernel 里加「教学模式」开关。

### 3. 合成数据的边界

| 项 | 规定 |
|---|---|
| 数据位置 | `data/tutorial/`，`MANIFEST.json` 声明 `synthetic=true` |
| 可见性 | 进入教程后**全局** SYNTHETIC 标记（顶部条 + 图表角标 + **导出物水印**） |
| 可用范围 | 仅教程工作区；**不得**进入真实工作区、不得参与风险定级、不得出现在对外结论中 |
| 生成 | `tools/gen_tutorial_data.dart`（v2 交付），固定随机种子，可复现 |
| 与 v1 验收的关系 | **v1 的 M1–M3 验收不得使用合成数据**（docs/11 D6）；教程是 v2 交付 |

### 4. 可跳过、可重看

首启可跳过（进入只读模式），设置页可随时重看；进度存在本地，不联网。

## 后果

### 正面
- 新用户 5 分钟内能看到一条完整证据链，而不需要先有真实数据。
- 因为走真实链路，教程本身即是端到端回归测试（合成数据 → 全链路）。

### 负面 / 必须接受
- 需要维护一套合成数据集与生成脚本。
- SYNTHETIC 标记必须在**所有出口**（UI、导出、报告）一致，任何一处漏标都是红线违规。

## 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 内置「演示模式」开关，走独立假数据路径 | 会产生第二套代码路径，长期与真实链路漂移；且容易演变成"用假数据冒充真结论" |
| 教程直接用 `data/samples/` | 该目录是**测试夹具**，语义不同；混用会让「产品数据 vs 测试数据」的边界消失 |
