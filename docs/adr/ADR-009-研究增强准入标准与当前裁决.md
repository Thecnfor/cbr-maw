# ADR-009 · 研究增强的准入标准与当前裁决

- 日期：2026-11-25 · 状态：**✅ 采纳** · 决策人：项目负责人（委托 Lead 依实证裁决）
- 相关：[docs/18](../18-北向资金联动性领先信号.md) · [docs/20](../20-角色分歧与风险来源结构.md) · [docs/23](../23-基准测试协议.md) · [docs/10-研究域设计/R1](../10-研究域设计/R1-MediaTone-文献结论与实现方案.md)

## 背景

文献深挖给出 25 条候选增强（R1 的 MT-01…MT-12、R2 的 A1…A13）。这些建议来自论文，但**文献里的有效性不等于在本项目真实数据上有效**。本轮已用统一协议在真实数据上复核，结果大量为负。

若不立准入标准，后续会把"论文说有效"当成"我们能做"，最终做出一个指标很多但没有一个真的有用的产品。

## 决策

### 1. 新指标/新工具的准入门槛（四条全过才准进产品）

| # | 门槛 | 判定方式 |
|---|---|---|
| G1 | **walk-forward 稳健**：逐年（每年只用该年之前的数据估参数）至少 **60% 的年份 lift > 1.2** | `data/seed/score_signals.py` 逐年输出 |
| G2 | **数据新鲜**：依赖的每个序列最新可用日期距今 ≤ 30 个交易日；否则只能进"历史回测/情景分析"模式 | 数据新鲜度断言 |
| G3 | **样本充足**：样本外触发 ≥ 30 次，且 ≥ 3 个不同年份有触发 | 混淆矩阵 + 年度分布 |
| G4 | **安慰剂通过**：打乱信号后 lift 回落到 1.0±0.2 | 安慰剂检验 |

未过门槛的**可以保留为研究代码**，但必须：①默认关闭 ②UI 标注"实验性/未通过稳健性检验" ③不得进入风险定级与告警 ④不得出现在对外结论中。

### 2. 本轮裁决（基于真实数据实测）

| 候选 | 门槛结果 | 裁决 |
|---|---|---|
| `dimension_dispersion`（风险来源结构） | G1 ✔ 6/7 年 · G2 ✔ 仅依赖 CFSI · G3 ✔ 126 次/3 年 · G4 待补 | **准入**，核心展示能力 |
| `capital_linkage` csi300×sp500 | G1 ✘ 3/6 年（平均 1.72×，近期 1.99×）· G2 ✔ VIX/SP500 新鲜 · G3 ✔ | **有条件准入**：标"同期型"，仅在数据新鲜时可用，必须展示逐年表 |
| `capital_linkage` csi300×northbound | G1 ✘ 2/6 年（平均 0.97×）· G2 ✘ 北向 2024-08-16 停更 · G3 ✔（但集中 2022–2023） | **降级为历史回测**，不得进入实时预警叙事 |
| `capital_linkage` usdcny×vix | G1 ✘ 2/6 年（平均 1.05×）· G2 ✘ USDCNY 2025-09-30 停更 | **降级为历史回测** |
| `tail_dependence`（尾部相依，R2 的 A1） | G1 ✘ 有效年 2/8、2/8、4/8，平均 0.77–1.31× | **不实现为工具**；保留研究记录 |
| `modality_dependence`（分箱 MI，R2 的 A2） | 未达 G1（无稳定预测力；仅作诊断） | **不实现为预测工具**；可作为诊断视图（不参与定级） |
| `modality_conflict` 冲突第四类（R2 的 A4） | 与预测力无关，属**证据分类**能力 | **准入**（不是预测指标，不受 G1–G4 约束），需改 docs/03 §1.3 |
| 文本关键词特征 / 词典情感轨 | `docs/17`：无领先性、情感轨增量显著为负 | **不进入定级**；仅作同期归因 |
| 多角色等级分歧 | `docs/20`：lift 0.94–1.04× | **不计入风险等级与告警**；preference 单独展示 |
| R1 的 MT-01…MT-12 | 多数未实测；MT-02（LLM 情绪轨）受 DeepSeek 密钥失效阻塞 | **待验证**，按 G1–G4 逐条过 |

### 3. 产品叙事约束（据此改写对外表述）

| 原表述 | 修正为 |
|---|---|
| "提前 40 个交易日预警" | "在压力形成期识别跨市场联动结构的异常（条件性，取决于数据新鲜度）" |
| "六维综合指数" | "六维分解 + **结构判读**（哪一维在恶化、哪一维尚未传导）" |
| "多角色交叉验证发现分歧" | "多角色从各自证据子集给出判断；**偏好差异不算错误**，事实与方向分歧才计入" |
| "媒体基调领先预警" | "媒体基调做**同期交叉验证与归因**" |

## 后果

### 正面
- 只有 `dimension_dispersion` 与"同期确认型"的 csi300×sp500 能进主流程；产品不会被一堆无效指标撑胖。
- 每个指标都带**有效区间与数据新鲜度**，用户能判断"这条结论现在还算不算数"。

### 负面 / 必须接受
- 目前**没有一个指标能在"提前预警"这个最强叙事上站住**。必须接受这个事实并如实呈现。
- 数据停更（北向 2024-08、多数序列 2025-09）是根本瓶颈：**补源优先级高于任何算法改进**。
- 研究代码会保留但默认关闭，增加维护面。

## 被否决的方案

- **"headline 数字达标就上线"**：`capital_linkage` 单一切分 2.08× 看起来很好，walk-forward 平均只有 0.97×。单一切分不可作为准入依据。
- **"文献说有效就实现"**：本轮 13 条 R2 建议中，实测能站住的只有 1 条（证据分类类，非预测类）。
- **"为了指标数量好看而保留弱指标"**：弱指标会稀释用户对强指标的信任。
