# 23 · 基准测试协议（Bench Protocol v1）

> 目的：让"这东西真的有用、能洞察别人洞察不到的"这句话**可被证伪**。
> 本文件只定义**协议**（口径、对照组、指标、显著性、报告格式），具体数字由 `tools/bench/run.dart` 实跑后填入 `docs/13-基准测试报告.md`。
> 铁律：**所有指标由独立评分器 `data/seed/score_signals.py` 重算，不采信实现自报**；任何数字必须标注来源、口径与样本量。

## 2. 对照组设计

| 组 | 定义 | 目的 |
|---|---|---|
| **A · 纯 LLM 直答** | 只把数值面板 + 问题给 LLM（DeepSeek），无工具、无证据链、无多角色、**无 PIT 过滤**（按用户实际可得的"最新数据"回答） | 模拟"别人怎么做" |
| **B · 纯数值模型** | 只用确定性数值特征（22 个 `pct_*`）训练/拟合，不接 LLM | 数值基线 |
| **C · CBR-MAW 全流程** | 四角色 R0–R5 + 确定性工具 + 证据链 + 冲突三分类 + PIT 纪律 + 门卫 + 预算 | 本项目方案 |
| **D · CBR-MAW 去掉新工具** | C 但移除 `capital_linkage` 与 `dimension_dispersion` | **消融**：证明新工具的增量 |

> 当前 DeepSeek 密钥失效（`docs/21`）：A 组若无法真跑，报告必须写「A 组未验证：401」，**不得**用桩输出代替。

## 3. 指标（每个都要给样本量与置信区间）

### 3.1 预测类

| 指标 | 定义 | 口径 |
|---|---|---|
| precision / recall / F1 | 正例 = 未来 20 交易日内进入 `high_stress` | 样本外（> train_end），阈值训练期冻结 |
| **lift** | precision ÷ 基准发生率 | 基准发生率 = 样本外正例占比（本数据 **38.13%**） |
| **提前量（lead, 交易日）** | 信号首次触发日 → 压力窗口起点 | 中位数 + 四分位；只在触发过的窗口上统计 |
| lead profile | corr(signal(t), CFSI(t+h))，h∈{0,5,10,20,40,60} | 峰值 h 决定"领先型/同期型" |
| CRPS / DM / PIT 校准 | 概率预测的评分三件套（v2 才要求，v1 只做点值） | — |

### 3.2 过程类（CBR-MAW 特有，A/B 组没有）

| 指标 | 定义 | 为什么重要 |
|---|---|---|
| **证据可溯源率** | 绑定可回指 evidence 的 claim 占比 | 红线的可量化形式 |
| **数值不一致率** | LLM 给的数值与工具重算不一致的条数占比 | 零 Mock 的可量化形式 |
| **泄漏检出数** | 用未来信息回答的次数（A 组预期显著 > 0） | PIT 纪律的可量化形式 |
| **分歧发现数（分类）** | fact / directional / **preference** 分别计数 | preference 单独计数，不得合并（`docs/20`） |
| 成本 / 延迟 | token 数、美元、端到端秒数、首 token 延迟 | 可负担性 |

### 3.3 结构类（新工具专有）

| 指标 | 定义 |
|---|---|
| 维度结构判读准确率 | `dominant_dim` 是否命中压力窗内实际最恶化的维度 |
| 阶段信号命中率 | "信用维度缓解"后是否在 N 日内转为恶化（阶段假设，`docs/20` §2.1） |

## 4. 显著性

- 每项对比给**样本量**；n < 30 时报告必须写"样本不足，不作显著性主张"。
- 成对比较用 Diebold-Mariano（点值预测）或 McNemar（分类）。
- 多重比较用 Holm 校正（`docs/10` MT-07 口径）。
- **安慰剂检验必做**：把信号随机打乱后指标必须回落到基准附近；若安慰剂组也显著，结论作废。

## 4.5 **必须做 walk-forward，单一切分不足以证明**（本轮实测教训）

单一 `train_end=2021-12-31` 切分把"恰好两年有效"包装成了"整体有效"：
- `capital_linkage` csi300×northbound 报出 precision 0.794 / lift 2.08×，但 **81 个 TP 全在 2022–2023**，2024/2025 触发 0 次（北向 2024-08-16 停更）。逐年 lift：0.40 / 1.99 / 1.02 / 1.29 / 1.14 / 0.00，**平均 0.97×**。
- 同一协议下 `dimension_dispersion` 逐年 lift：3.17 / 1.59 / 1.50 / 1.22 / 1.09 / 1.87 / 1.85，**有效 6/7 年**，近期纯样本外 1.55×。

**协议强制条款**：
1. 每个信号必须给**逐年 walk-forward 表**（每年只用该年之前的数据估参数）。
2. 必须报**触发日在年份上的分布**；若某年 0 触发，必须解释是"无信号"还是"数据缺失"。
3. 必须报**每个依赖序列的新鲜度**（最新可用日期与 NaN 率）；依赖已停更序列的指标**不得**用于实时预警叙事。
4. headline 数字若与 walk-forward 平均 lift 差距 > 50%，必须在摘要里并列呈现两者。

## 6. 报告格式（`docs/13-基准测试报告.md` 必须逐节对应）

1. 结论摘要（≤5 条，每条一句）
2. 数据与口径（含样本量与覆盖期）
3. 主表：A / B / C / D 四组的指标对比
4. 消融：C − D = 新工具的增量（含显著性）
5. 安慰剂检验结果
6. 失败与负结果（**必填**：哪些假设被证伪、哪些跑不通）
7. 局限（样本量、数据源、时点、因果）
8. 复现命令（逐条可复制执行）

## 7. 反自欺规则（来自 `docs/17` §4.3 的实测教训）

1. **禁止用 A−B 差值构造背离指标**再与其下游量求相关（构造性负相关）。
2. 跨模态一致性/背离只能用**对称统计量**（秩相关、互信息）或标准化后比较。
3. 任何"有预测力"的结论必须附**安慰剂检验**。
4. **必须同时报 lead profile**：只看同期相关会把领先信号误判为无效（`docs/18` §3.2：W=40 时 h=0 相关为负）。
5. 小样本（触发 < 30 次）的完美 precision **不得**写成结论（`docs/18` §3.8 的 AH 配对案例）。
