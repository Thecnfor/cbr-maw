# 22 · 五分钟上手：首次体验规格

> 目的：把"新用户从装好到看到第一条有证据链的结论"这条路径**逐屏写死**，避免实现期各写各的。
> 依据：docs/07（交互与响应式）、docs/02（功能清单 F1-1/F1-8、F5-5）、docs/09 §9（错误分层）、docs/11 §9（新手岛）。
> 验收口径：每屏都有**正常态 / 空态 / 错误态 / 不可达态**四态，文案按 docs/08 三段式（错在哪 / 怎么改 / 影响什么）。

---

## 0. 一次成功会话的时长目标

| 步骤 | 目标时长 | 用户动作 |
|---|---:|---|
| 填密钥 | ≤60s | 粘贴 key → 点「验证」 |
| 选数据模式 | ≤10s | 点一个卡片 |
| 投喂数据 | ≤20s | 把 CSV 拖进窗口（或点「选择文件」） |
| 首次研判 | ≤90s | 打一句话 → 等结果 |
| **合计** | **≤3 分钟** | |

## 1. 逐屏规格

### 屏 1 · 欢迎 / 填密钥（唯一必答项）

| 项 | 规格 |
|---|---|
| 布局 | 居中单列，最大宽 480dp；侧栏不出现 |
| 内容 | 产品名 + 一句话定位（跨境金融风险多智能体协同预警研究工作台）+ 密钥输入框 + 「验证并继续」 |
| 输入框 | 密码模式；实时脱敏显示 `sk-****abcd`；**永不回显明文**；粘贴后自动 trim（docs/21 的 CRLF 陷阱） |
| 主按钮 | 文本「验证并继续」；未填则禁用并说明原因 |
| 错误文案（401） | 「密钥无效 / 怎么改：确认账号状态与余额，或换一把 key / 影响：无法调用模型，其余功能仍可用（可浏览本地数据与来源台账）」 |
| 错误文案（网络/代理） | 「无法连接模型服务 / 怎么改：检查网络或代理设置（设置 → 网络）/ 影响：仅影响模型调用」 |
| 附带 | 「稍后再说」→ 进入只读模式（可浏览历史结论与本地数据，研判入口置灰并说明原因） |
| 落盘 | Windows 优先 DPAPI；Linux 降级为 `~/.local/share/CBR-MAW/secrets/` 受限权限文件；两者都**不写明文到日志** |

### 屏 2 · 数据模式（3 选 1）

| 卡片 | 说明 | 标注 |
|---|---|---|
| **A 投喂我的数据**（推荐） | 拖入 CSV/Excel/ZIP，自动清洗入库 | 「推荐：真实数据，结论可对外」 |
| B 先看示例 | 载入内置 SYNTHETIC 夹具 | **卡片右上角必须有 `SYNTHETIC` 徽标**，并写明「仿真数据，仅供演示，不可用于投资或监管决策」 |
| C 打开已有工作区 | 选择本机工作区目录 | 显示该工作区的序列数与最后入库时间 |

**红线**：选 B 之后，**任何页面、任何导出物**都必须携带 SYNTHETIC 标记（顶部条 + 图表角标 + 导出水印），不得只在设置页写一次。

### 屏 3 · 投喂（文件投递箱）

| 交互 | 规格 |
|---|---|
| 落点 | **窗口任意处拖拽** + **对话输入框内的附件区**（两者等价，见屏 4） |
| 悬停 | 整个窗口 2dp focus 描边 + 居中提示「松开以加入投递箱」 |
| 支持 | `.csv` `.xlsx` `.zip`（ZIP 递归展开） |
| 反馈 | Toast：「已加入投递箱，正在清洗入库 · <文件名>」 |
| 进度 | 侧栏「投递箱」入口显示待处理条目数角标；点击展开清单 |
| 清洗结果 | 每文件一行：文件名 · 识别到的序列数 · 行数 · 时间范围 · 状态（已入库 / 被拒 / 需人工确认） |
| 被拒文件 | 状态标红 + 原因（编码/表头/列名映射失败/格式不支持）+ 「查看详情」；原文件保留不删除 |
| 列名映射 | 自动映射结果**逐条可改**（下拉选择序列）；未命中的落 `custom.*` 并允许改名 |
| 空态 | 「投递箱是空的。把 CSV/Excel 拖进窗口，或点这里选择文件」+ 一个可点的示例文件说明（**示例必须标注 synthetic**） |

### 屏 4 · 对话式研判

| 区域 | 规格 |
|---|---|
| 左列 | 对话流：用户消息（「你的提问」语义）+ Agent 消息（「智能体回答」语义）+ 流式增量渲染；`Ctrl+Enter` 发送，`Shift+Enter` 换行，`Esc` 停止生成（中断后保留已生成内容并标注「已中断」） |
| 右列 | **Agent 活动流**：当前在做什么（调了哪个工具、搜了什么、发现什么冲突）；与审计流同源，可展开看每次调用的输入摘要与输出 |
| 输入框 | 支持**拖入文件/压缩包**作为附件（与屏 3 同一落点、同一清洗链路） |
| 结论块 | 风险等级（低/中/高/极高）+ 5/10/20 日压力概率 + 关键驱动因子与证据编号 + 跨市场外溢渠道 + 建议关注措施 + **结论局限** |
| 数值 | **一律来自工具重算**；LLM 写的数字若与工具不一致 → 显示工具值并标「以工具重算为准」 |
| 空态 | 「问一个跨境风险问题，例如：当前跨境资金压力处在什么水平？未来两周有哪些风险信号？」+ 3 个可点示例 |

### 屏 5 · 风险卡

| 区块 | 必备 |
|---|---|
| 等级与概率 | 等级 + 5/10/20 日概率 + 定级依据（确定性阈值，不是 LLM 说法） |
| **六维分解** | 股票/债券/信用/汇率/跨境资金/全球 六维条形 + **缺席维度明确写「未计入（需授权 / 不可达）」** |
| **结构判读** | 「当前压力主要来自跨境资金与全球传导；信用维度尚未计入」——来自维度离散度工具（docs/20） |
| 关键指标 | 每条带证据编号 |
| 证据 | 每条 claim 可点进证据详情 |
| **局限** | 系统追加段（≤8 条）+ 每条结论的 provenance（词典/模型版本、as_of、样本量） |
| **声明** | 「相关非因果」；结论有效期区间 |

### 屏 6 · 证据详情（检视区）

- 从任何结论一路点到原文：原文片段 · 发布时间 · 来源 · 定位符 · 时点（as_of）· 工具版本 · **输入哈希**（可复制）
- 证据被质疑/被推翻时的状态与原因可见
- 窄屏为全屏抽屉，宽屏为覆盖式抽屉，≥1440dp 常驻第三栏（docs/07 §1.2）

### 屏 7 · 来源台账（诚实的一屏）

- 每个来源一行：名称 · 模态 · **五态徽标**（已获取 / 需授权 / 需登录 / 反爬受限 / 已过期）· 最后成功时间 · 陈旧度 · 覆盖期
- **不得显示占位数字**；不可达来源显示原因与「申请授权 / 更换来源」两个可点动作
- 「探测可达性」按钮（低频串行、带 UA、遵守 Retry-After）

## 2. 全局体验规则

| 规则 | 落地 |
|---|---|
| 三档自适应 | compact（<600）底部导航 4 项：概览/对话研判/风险卡/时间线；medium/expanded NavigationRail；large+ 侧栏 248dp 可折叠 64–72dp（折叠态存 `ui.nav_collapsed`） |
| 键盘 | `Ctrl+1..9` 切工作台（顺序与侧栏一致）、`Ctrl+K` 命令面板、`Esc` 停止生成 |
| 焦点 | 主导航/主内容/检视区顺序固定；焦点环统一 token，不依赖 hover |
| 状态完备 | 每个交互区块都要有 11 态（docs/07 §6）：含 loading/empty/error/无权限/数据不可得等 |
| 降级可见 | 任何降级（预算耗尽、角色失败、来源不可达）都要在 UI 明示 + 写审计 + 文案说影响 |
| 空态不是零 | 「缺失」与「0」在文案与视觉上必须可区分（图标 + 文案 + 颜色三重编码） |
| 语速 | 本地操作 ≤100ms 响应；模型调用走流式，首 token 目标 ≤3s |

## 3. 验收清单（可直接写成测试）

1. 未填密钥进入 → 停在屏 1；填入并验证成功 → 进入屏 2。
2. 屏 2 选 B → 全局出现 SYNTHETIC 标记；导出物也带。
3. 拖入 `daily_series.csv` → 出现「已加入投递箱」→ 清洗结果列出 22 条序列、时间范围与行数 → 入库后可查。
4. 拖入北向 ZIP → 被正确展开并入库或被拒且**给出可读原因**，不静默丢弃。
5. 提问 → 活动流出现工具调用 → 结论块出现，且**每个数值都有证据编号**。
6. 断开模型服务后提问 → 显式失败并引导设置页；**不得**返回任何编造结论。
7. 缺失维度（如信用）→ 风险卡显示「未计入」，不显示 0。
8. 预算耗尽 → 结论标「部分结论」，列明降级角色。
9. 宽度从 1600 → 800 → 500 → 导航形态依次变为侧栏 → Rail → 底部导航，滚动位置与折叠态保留。
10. 全流程可用键盘完成；焦点环在所有背景上可见。
