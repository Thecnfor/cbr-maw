## 1. 断点与布局矩阵

### 1.1 断点定义 `[已定]`

单位 dp（Flutter 逻辑像素）。断点常量：`Bpx.xs = 600`、`Bpx.sm = 840`、`Bpx.md = 1100`、`Bpx.lg = 1440`、`Bpx.xl = 1920`。

| 档位 | 断点区间 | 典型设备 |
|---|---|---|
| `compact` 紧凑 | `< 600` | Android 手机竖屏 |
| `medium` 中等 | `600 – 839` | Android 手机横屏、小平板 |
| `expanded` 展开 | `840 – 1099` | Android 平板竖屏 / 横屏 |
| `large` 大 | `1100 – 1439` | Windows / macOS 笔记本（1280×800、1366×768） |
| `xlarge` 特大 | `1440 – 1919` | Windows 宽屏（1440×900、1920×1080） |
| `xxlarge` 超大 | `≥ 1920` | 2K/4K 显示器 |

> 断点按**内容宽度**判定（`LayoutBuilder` 的 `constraints.maxWidth`），不按屏幕物理尺寸判定；窗口缩放时实时重算。

### 1.3 折叠规则：什么内容在什么宽度下被折叠 `[已定]`

| 内容 | 折叠阈值 | 折叠后的行为 |
|---|---|---|
| 检视区（证据详情常驻栏） | `< 1440` | 变为覆盖式抽屉（点击证据卡片时滑入，不挤压主区） |
| 第三栏（辅栏 KPI 列表） | `< 1100` | 变为可滚动纵向列表，置于主区之后 |
| 第二栏（辅栏） | `< 840` | 完全折叠，主区之下以"分区标题 + 折叠面板"呈现，默认收起 |
| 侧栏文字标签 | `< 1100` 折叠态 | 仅显示图标；`Tooltip` 显示全名 |
| 侧栏底部"运行状态"明细 | `< 840` | 折叠为单个状态点，详情移入顶栏"系统状态"弹层 |
| 顶栏面包屑 | `< 600` | 只显示当前页名，不显示分组前缀 |
| 顶栏时钟 | `< 840` | 隐藏（状态区已有相对时间） |
| 图表工具栏次要按钮 | `< 840` | 收进「更多」溢出菜单（保留图例切换与数据表切换在可见区） |
| 表格低优先级列（P3） | `< 840` | 隐藏；`expanded` 及以上保留 P1+P2；`large` 及以上全部保留 |
| 表格 P2 列 | `< 1100` | 隐藏（可在列选择器中打开） |
| 对话区活动流（trace） | `< 840` | 变为对话下方的可展开抽屉，不并行显示 |
| Agent 证据卡展开态 | `< 600` | 默认折叠，展开后占满屏宽 |

## 2. 自适应模式

### 2.1 三档模式定义 `[已定]`

```
宽（≥1100）  =  侧栏 248 + 主区 2–3 栏 + 常驻/覆盖检视区
中（840–1099）=  Rail 72 + 主区 2 栏 + 覆盖抽屉
窄（<840）    =  单栏 + 底部导航（<600）/ Rail（600–839）+ 全屏抽屉
```

### 2.2 模式切换的实现约束 `[已定]`

- 状态由 `LayoutBuilder` 的 `maxWidth` 推导，**不得**依赖设备类型枚举（同一 Android 平板可横竖屏切换）。
- 模式切换必须**保留滚动位置与展开状态**（用 `PageStorage` / `RestorationMixin`）。
- 侧栏折叠状态是**用户偏好**（`shared_preferences`，键 `ui.nav_collapsed`），断点只决定"默认是否折叠"，不强制覆盖用户选择。
- 模式切换不做全页重建（避免重建导致滚动跳顶、动画闪烁）；仅布局参数变化。

## 3. 数据密集区的响应式策略

### 3.1 宽表：四段式降级与取舍 `[已定]`

| 手段 | 生效区间 | 实现 | 取舍 |
|---|---|---|---|
| **① 冻结首列** | `≥ 840` | 首列 `TableColumn` 固定，横向滚动时保持可见 | 保留跨行比对能力；代价是首列宽不可随内容压缩，需限宽并截断 |
| **② 横向滚动** | `≥ 600` | 表格容器内 `SingleChildScrollView(horizontal)` + 独立纵向滚动 | 保留全部列；代价是需要滚动提示（边缘渐隐 + 可见滚动条） |
| **③ 列选择器** | 全部 | 工具栏"列"按钮，勾选要显示的列；**持久化**（`ui.table_columns.<tableId>`） | 用户掌控；代价是状态管理复杂，首版只对"证据表""信号表"两处开放 `[建议·待复核]` |
| **④ 转卡片** | `< 600`（自动）或用户手动 | 每行渲染为一张卡：标题行 + 键值网格 | 可读性最好；**代价是丧失横向可比性**（无法一眼比同一列的多个值）——因此卡片模式下必须保留"按某列排序"且在卡内把排序字段置顶 |

**优先级与决策规则：**

1. 先做 ①②（自动、无损）；③ 在用户主动使用时出现；④ 由断点自动触发。
2. **不**因为屏幕窄就隐藏用户显式选中的列（列选择器的显式选择优先于断点裁剪）。
3. 断点裁剪的列（P3）在表头提供"显示更多列"入口，而不是永久消失。

### 3.2 表格密度 `[已定]`

| 密度 | 行高 | 字号 | 使用场景 |
|---|---|---|---|
| 紧凑 | 32dp | `type.numericSmall` 13sp | `xlarge` 以上的信号明细表 |
| 标准 | 36dp | `type.numeric` 16sp 数值 / `type.label` 13sp 文本 | `large` / `expanded` |
| 触控 | 44dp | `type.body` 14sp | `medium` / `compact` |

### 3.3 图表：自适应高度与容器查询 `[已定]`

- **禁止**固定尺寸图表。所有图表通过 `LayoutBuilder` 计算：

```dart
// 伪代码（可落地形态）
final h = (constraints.maxWidth * 0.42).clamp(200.0, 420.0).toDouble();
final chart = ChartCard(child: FlChart(/* ... */), height: h);
```

| 约束 | 值 |
|---|---|
| 高度公式 | `clamp(0.42 × 容器宽度, 下限, 上限)` |
| 上下限 | 下限 200dp（`compact`）/ 220dp（其余）；上限 420dp（`xlarge`）/ 440dp（`xxlarge`） |
| 容器查询 | 以 `LayoutBuilder` 的 `maxWidth` 为准；**不**读 `MediaQuery.sizeOf(context).width`（窗口内嵌视图会取错） |
| 图表库 | `fl_chart`（基线已定）；使用其 `minX/maxX/minY/maxY` 自适应，不设固定 `size` |

### 3.4 图表在手机上的替代形式 `[已定]`

`compact`（< 600dp）下图表**默认不渲染全图**，改为"摘要 + 展开"：

| 层级 | 呈现 |
|---|---|
| 一级（默认） | 关键数值卡（最新值 + 变化箭头/符号 + 迷你走势 120×32dp）+ 一行结论文字 |
| 二级（点击"展开图表"） | 全屏图表页（可横竖切换、可点选数据点、可切换系列） |
| 三级（点击数据表） | 数据表视图（图表的等价非视觉通道，任何宽度都可用） |

多系列图表在 `compact` 下额外要求：**默认只显示第一系列**，其余通过系列切换器（分段控件）单选，不做图例多选。

### 3.5 图表工具栏 `[已定]`

固定顺序：图表类型 ▾ ｜ 图例（可点切换）｜ 坐标设置 ▾ ｜ 配色约定 ▾ ｜ **数据表视图**（眼睛图标）｜ 导出。**数据表视图**按钮在所有断点都可见（不可折叠进"更多"）。

## 4. 触控 vs 鼠标

### 4.1 热区尺寸 `[已定]`

| 控件 | 触控设备最小热区 | 鼠标设备最小热区 |
|---|---|---|
| 图标按钮（工具栏） | **48 × 48 dp** | 32 × 32 dp |
| 文字按钮 | 高度 ≥ 48 dp | 高度 ≥ 32 dp |
| 表格行 | 高度 44 dp | 高度 32–36 dp |
| 列表项 / 导航项 | 高度 ≥ 48 dp | 高度 36 dp（桌面）/ 44dp（触屏 rail） |
| 开关 / 复选 / 单选 | 命中区 ≥ 48dp（控件本体可 20dp） | 同左 |
| 滑块 / 拖拽手柄 | 手柄直径 ≥ 24dp，命中区 ≥ 48dp | 手柄 ≥ 16dp |
| 图表数据点 | 命中半径 ≥ 20dp | ≥ 12dp |

> 视觉尺寸与命中区分离：视觉可保持紧凑（16dp 图标），命中区用 `SizedBox` / `Padding` 扩到 48dp。

### 4.2 hover-only 信息的可触达替代 `[已定]`

**规则：任何在 hover 时才出现的信息，都必须有一条不依赖 hover 的获取路径。**

| hover 内容 | 触屏替代 |
|---|---|
| 图标按钮的说明 | `Tooltip` 在触屏由**长按 500ms** 触发（Flutter `Tooltip` 移动端默认行为）；同时**必须**有 `Semantics(label)` 供读屏 |
| 表格单元格完整值（截断时） | 单元格可**点击/长按**展开为浮层显示完整值；且单元格必须 `Semantics` 朗读完整值而非截断值 |
| 图表数据点详情 | 点击数据点显示详情浮层（不依赖 hover）；`compact` 下用数据表视图 |
| 侧栏折叠态图标含义 | 折叠态 `Tooltip` 常驻提示 + `Semantics` |
| 行操作按钮（hover 才显形） | **触屏下常驻显形**；桌面 hover 显形但**键盘 Tab 也能到达**（不得 `Visibility(visible: false)` 造成不可聚焦） |

**额外规则**：**双击、右键、`Ctrl+点击` 不得作为任何功能的唯一入口。**

### 4.3 手势与滚动冲突 `[已定]`

| 场景 | 规则 |
|---|---|
| 表格内横滑 vs 页面竖滑 | **禁止手写 `GestureDetector` 横向拖拽**。使用原生 `SingleChildScrollView(scrollDirection: Axis.horizontal)`，Flutter 手势竞技场自然让**纵向优先**；横向滚动需在容器**边缘**有 12dp 渐隐提示 + 可见滚动条 |
| 卡片内横向滑动（chip 组） | 同上；且 chip 组必须可用键盘左右方向键移动焦点 |
| 抽屉滑动关闭 | 仅在抽屉**边缘 24dp 区域**启用拖拽关闭，避免与页面滚动冲突；触屏从左边缘右滑 = 返回（仅根路由） |
| 长按菜单 | 触屏长按 **500ms** 打开上下文菜单；桌面右键打开；键盘 `Shift+F10` / 菜单键打开 |
| 长按与滚动区分 | 长按触发后必须**取消**后续滚动；未触发长按时不得产生滚动阻尼 |
| 双指缩放 | 全应用禁用（金融表格缩放会破坏对齐） |
| 系统返回手势 | 见 §10.3 |

### 4.4 指针类型感知 `[已定]`

- 运行时根据 `MediaQuery.pointerKindOf` / 最近一次输入设备切换"指针模式"：
  - **鼠标模式**：hover 显形、行 hover 高亮、`Tooltip` 悬停即显（延迟 400ms）。
  - **触控模式**：hover 效果不生效，相关操作按钮常驻，行不 hover 高亮。
- 模式切换不重建页面树，只切换 `Theme` 的一个 flag。

### 5.3 焦点顺序与可见焦点 `[已定]`

**焦点顺序（与视觉顺序一致）：**

1. 「跳到主内容」按钮（桌面可见，移动端为屏幕阅读器可聚焦的隐藏按钮）
2. 侧栏 / Rail / 底部导航
3. 顶栏（面包屑 → 状态 → 搜索 → 命令 → 主题）
4. 主内容区（自上而下，左到右；网格内按行）
5. 检视区 / 抽屉（打开时焦点移入，关闭时归还）

**可见焦点：**

- 焦点环：`border.focus`（2dp）+ 2dp 偏移 + `surface.base` 打底，任何背景上都可见。
- **焦点样式不得依赖 hover**；`Material` 的默认焦点高亮被替换为本项目统一 token。
- 焦点环在 `surface.sunken`、`surface.inset`、图表底上均需 ≥ 3:1（浅色 `#2563EB` 对 `#F4F5F7` 实测 **4.74:1**）。
- 焦点移动到屏幕外元素时必须 `Scroll.ensureVisible`。

### 5.4 屏幕阅读器语义 `[已定]`

| 元素 | 语义要求 |
|---|---|
| 侧栏 / Rail / 底部导航 | `Semantics(container: true, label: '主导航')`；当前项 `selected: true` |
| 主内容 | `Semantics(container: true, label: '主内容')` |
| 表格 | 表头 `header: true`；单元格朗读含列名；行朗读含"第 n 行，共 m 行" |
| 状态点 | 必须有文字等价（`Semantics(label: '系统就绪')`），**不得**朗读为"圆点" |
| 图标按钮 | `Semantics(button: true, label: '导出研判结果')`；装饰性图标 `excludeFromSemantics: true` |
| 徽章 | 文字自足，如 `Semantics(label: '高风险操作')` |
| 图表 | `Semantics(label: '风险指数折线图，近 30 日，最高 72.4，最低 51.2')` + 必须提供数据表视图 |
| 展开/折叠 | `Semantics(expanded: true/false)` |
| 对话流 | 用户消息 `Semantics(label: '你的提问')`；Agent 消息 `Semantics(label: '智能体回答')` |
| 装饰性元素 | 全部 `ExcludeSemantics` |

**读屏顺序**：`flutter_semantics` 树必须与视觉顺序一致；`MergeSemantics` 只用于确实不可拆分的复合控件（如整行徽章）。

### 5.5 动态内容播报 `[已定]`

用 `SemanticsService.announce(text, TextDirection.ltr)`（中文用 `TextDirection.ltr` 亦可，但**必须**显式传参）。

| 事件 | 播报文案 | 节流 |
|---|---|---|
| 抓取完成 | "抓取完成，新增 128 条记录" | ≥ 1s |
| 抓取失败 | "抓取失败：〈原因〉" | ≥ 1s |
| 研判完成 | "协同研判完成，共 4 个角色，2 条冲突已消解" | ≥ 1s |
| 生成完成 | "回答已生成" | ≥ 1s |
| 流式生成开始 | **不播报**（避免与逐句朗读冲突） | — |
| 连接断开 / 重连 | "连接已断开，正在重连" / "连接已恢复" | ≥ 5s |
| 高风险操作待确认 | "有一项高风险操作待确认" | ≥ 5s |
| 冲突未消解 | "存在 1 处未消解的角色冲突，需要人工裁决" | ≥ 5s |
| 数据不可得 | "〈来源〉数据不可得，需要授权" | ≥ 5s |

**规则**：

- **不逐 token 播报**。
- 相同文案在 10s 内不重复播报。
- 播报是"锦上添花"：所有信息在界面上都有可读的文字，播报失败不阻塞。

### 5.6 不依赖颜色传达信息 `[已定]`

- 涨跌：**箭头 ▲/▼ + 正负号 + 数值**（见 [`06`](06-设计系统与美学规范.md) §2.7）。
- 状态：徽章 = 图标 + 文字 + 颜色（去色后仍可读）。
- 图表系列：颜色 + 线型 + 图例 + 数据表；色相用尽后切换线型。
- 差异高亮（如消融对比）：用 **加粗/下划线 + 箭头**，不只靠底色。

## 6. 状态完备性清单

### 6.1 必备状态矩阵 `[已定]`

**每一个交互区块（工作台、面板、卡片、表格、图表、对话框入口）都必须实现下表全部 11 态。**

| # | 状态 | 视觉表现 | 可用操作 | 文案要求 |
|---|---|---|---|---|
| 1 | **加载中** | 骨架屏（尺寸与真实内容一致）；已知总量时用确定性进度条 | 可取消（长任务） | 「正在加载…」；不显示空容器 |
| 2 | **空** | 空态：图标 + 标题 + 说明 + 主动作 | 主动作必存在 | 见 [`08`](08-文案标准与术语表.md) §6.1；细分「无数据」「筛选后为空」「数据不足（序列缺失）」 |
| 3 | **错误** | 错误态：图标 + 标题 + 原因 + 下一步 + 「重试」 | 重试 / 查看详情 | 三段式（见 [`08`](08-文案标准与术语表.md) §1.3） |
| 4 | **成功** | 正常内容 | 常规操作 | — |
| 5 | **禁用** | 置灰 + `Semantics(enabled: false)`；**必须给原因** | 无 | Tooltip 说明"为什么不能操作" |
| 6 | **无权限** | 权限提示层：图标 + 说明 + 「申请权限」/「切换角色」 | 申请权限 | 与"需授权"**区分**（§6.2） |
| 7 | **断网** | 顶部离线条（非阻塞） + 数据区显示上次成功结果 + 「重试连接」 | 重试 / 继续查看本地 | 「当前处于离线状态，显示的是本地缓存数据」 |
| 8 | **慢网** | 加载态持续 + 超过 5s 显示「仍在加载（已等待 5 秒）」+ 可取消 | 取消 / 继续等待 | 不显示"卡死"式空白 |
| 9 | **数据陈旧** | 内容上加 `StaleBadge`（warn 色 + 文字）+ 顶栏提示 | 「立即重新抓取」 | 「数据已陈旧，上次成功抓取：〈时间〉」 |
| 10 | **筛选后为空** | 空态变体：**说明当前筛选条件** | 「清除筛选」 | 「当前筛选条件下没有匹配结果」+ 复述条件 |
| 11 | **数据不可得（需授权）** | 见 §6.2 | 「前往授权」 | 见 §6.2 |

### 6.2 「数据不可得（需授权）」——CBR 特有状态 `[已定]`

这是本产品**最特殊**的 UI 状态：数据不是"没有"，而是"我没有资格拿"。基线 §4 已定：**无凭证时 UI 显式标注「需授权」，不显示任何数据**。

#### 6.2.1 与相邻状态的区分

| 状态 | 含义 | 数据区显示 | 主动作 |
|---|---|---|---|
| 空 | 确实没有数据 | 空态插画 | 开始抓取 / 调整筛选 |
| **数据不足** | 来源**可达**，但该标的 / 该时点确实无观测值 | 数值位 `—` + 紧邻的原因标签「数据不足」 | 查看可用观测值 |
| 错误 | 尝试了但失败 | 错误态 | 重试 |
| **需授权** | 未提供凭证 | **锁形图标 + 「需授权」标签 + 来源名** | **前往授权** |
| 需登录 | 来源要求登录态 | 锁形图标 + 「需登录」标签 | 前往登录（打开来源登录流程） |
| 反爬受限 | 来源有反爬策略或当前不可达 | 盾牌图标 + 「反爬受限」标签 + **括号附注原因**（触发人机验证 / 目标站点不可达（DNS、连接、5xx）/ 站点禁止自动抓取） | 查看来源台账 / 稍后重试 / 前往人工验证 |
| 无权限 | 当前用户无权查看该工作台 | 权限提示 | 申请权限 / 切换角色 |

> **来源状态的标签集固定为五态**（已获取 / 需授权 / 需登录 / 反爬受限 / 已过期，见 [`08`](08-文案标准与术语表.md) §5.1）。
> 「不可达」**不是**独立标签：它是「反爬受限」的一种原因，必须以括号附注区分（因为可执行的下一步不同）。
> 「数据不足」与「来源不可得」必须严格区分：前者数值位可显示 `—` + 原因，后者**一律不得出现任何占位数值**。

#### 6.2.2 呈现规范 `[已定]`

1. **绝不显示任何占位数值**。禁止 `0`、`--`、`—`、`N/A`、`null`、`暂无`（作为数值占位）。KPI 卡的值区域显示 **「需授权」**（文字），不是数字也不是破折号。
2. **必须写明三件事**：**来源名**（如 Bloomberg）、**原因**（未提供凭证）、**如何解决**（去设置的哪一节）。
3. **单一主动作**：「前往授权」。跳转设置 → 数据源 → 对应来源的凭证输入。
4. **不打断**：这是**内联**状态，不是模态弹窗；不阻断其他工作台的可用性。
5. **可降级**：在未授权状态下，该来源**仍然出现在来源台账里**（基线 §4.3 要求显式列出原因），并显示其"若已授权可提供的数据范围"。
6. **不使用 danger 色**：需授权是"缺权限"而非"出错"，用 `warn.tint` + `warn.ink` + 锁图标。
7. 重新授权成功后，**原地**替换为加载态 → 内容，不弹 toast 打断。

#### 6.2.3 文案模板

```
Bloomberg 未授权
该来源需要有效终端凭证才能获取数据。当前未配置凭证，未显示任何数据。
[前往授权]
```

### 6.3 状态呈现的实现约束 `[已定]`

- 状态切换**不得**使用整页重建（避免滚动跳顶）；使用同一 `Widget` 的状态分支。
- 加载 → 空 → 错误的切换顺序固定：**加载（骨架）→ 内容 / 空 / 错误**，不允许出现"空态闪一下再变错误"。
- **错误态不得自动重试**（除明确的可恢复网络错误），避免无限循环。

## 7. 流式与实时交互

### 7.1 逐 token 渲染 `[已定]`

| 项 | 规则 |
|---|---|
| 渲染节流 | 累积 token 后**每 50ms** 批量刷一次（最多 20 次/秒），避免逐 token `setState` |
| 光标 | 活跃时显示 `▍`（静态实心块），生成结束移除 |
| 光标闪烁 | 是**循环动画**；`prefers-reduced-motion` 开启时改为静态实心块不闪烁（见 [`06`](06-设计系统与美学规范.md) §7.3） |
| 自动滚动 | 用户停留在底部时才自动跟随；用户上滚后**停止自动滚动**并显示「回到底部 ↓」浮标 |
| 停止 | 「停止生成」按钮在生成开始后 **≥ 300ms** 出现（避免误触）；点击后取消底层请求 |
| 停止后 | 已生成内容**保留**，末尾追加标注「已停止生成」 |
| 失败后 | 保留已生成内容，追加错误三段式文案 + 「重试」 |

### 7.2 Agent 活动流 `[已定]`

| 项 | 规则 |
|---|---|
| 事件粒度 | **阶段级 + 工具调用级**，不逐 token（否则噪音淹没信息） |
| 条目类型 | 阶段开始/结束、工具调用、证据写入、冲突产生/消解、错误 |
| 排序 | 最新在上（倒序），可切换为正序时间线 |
| 折叠 | 同一阶段的多条事件默认折叠为一行摘要，点击展开 |
| 实时提示 | 运行中的条目显示 `info` 色 + `glow` 状态点（唯一允许的 glow 场景） |
| 播报 | 按 §5.5 节流播报，不逐条朗读 |
| 性能 | 列表虚拟化；单次会话保留最近 500 条，其余折叠为「查看更早的 N 条」 |

### 7.3 断线续接 `[已定]`

| 项 | 规则 |
|---|---|
| 传输 | 进程内 SSE（Windows 桌面）/ 移动端本地 HTTP；无中央服务器（基线 §2） |
| 重连 | 自动重连 **最多 3 次**，退避 0.5s / 1s / 2s |
| 重连提示 | 顶部细条：「连接已断开，正在重连（第 2 次）」 |
| 续接 | 重连后按 `run_id` + 本地事件游标**补齐**缺失事件（本地进程内可直接续） |
| 失败 | 3 次失败后显示错误态 + 「重试」；**已生成内容保留** |
| 离线 | 检测到无网络时不发起重连风暴；显示离线条（§6.1 #7） |

### 7.4 骨架屏与流式内容的切换（避免闪烁）`[已定]`

1. 骨架屏容器尺寸 = 真实内容尺寸（行数、列数按预估固定），避免切换时页面跳动。
2. 首字节到达后，用 **320ms 交叉淡出**（`motion.slow`）从骨架过渡到内容。
3. **若 300ms 内没有首字节**：保持骨架屏，不切换；改为在骨架下方显示「正在等待模型响应（已 5 秒）」。
4. **禁止**用 spinner 替换骨架屏（spinner 会引起布局跳动与闪烁感）。
5. 若预估行数与实际相差 > 30%，骨架结束后**不做二次跳变**，用容器高度锁定（`AnimatedSize`，320ms）。

## 8. 本地优先体验

### 8.1 冷启动 `[已定]`

| 阶段 | 目标 | 表现 |
|---|---|---|
| T0（进程启动） | < 300ms | 显示品牌页 + 本地库自检 |
| T1（< 1.5s） | 可交互 | 直接渲染**本地库中已有数据**；网络请求在后台发起 |
| T2 | 数据刷新 | 顶部细条：「正在获取最新数据…（已获取 3/12 个来源）」 |

- 冷启动**必须**先渲染本地内容，不等网络。
- 冷启动日志：`首帧 420ms · 可交互 1.1s · 本地库 128,442 条`（可在设置 → 诊断中查看）。

### 8.2 本地库未建 `[已定]`

首次运行（无本地库）显示**引导页**，三步，每步可见进度与预计量：

| 步骤 | 内容 | 可中断 |
|---|---|---|
| 1 | 选择数据目录（默认应用数据目录，可改） | — |
| 2 | 抓取公开源（列出将抓取的来源；**不**抓取未授权的持牌源） | 可暂停 |
| 3 | 建立索引（特征 / 知识索引） | 可暂停 |

- 引导页**不得**用模糊的"正在准备数据…"，必须给出**来源名 + 已完成数 / 总数 + 预计剩余时间**。
- 中途退出后，下次启动**从断点继续**，并提示「上次抓取未完成，已从第 4 个来源继续」。

### 8.3 首次抓取 `[已定]`

- 每个来源独立进度条与状态（排队中 / 抓取中 / 已完成 / 失败 / 跳过（需授权））。
- 单个来源失败**不阻断**其他来源；失败项列出原因（与 §6.2.1 的原因表一致）。
- 抓取产出**实时入库**，用户可以在第一个来源完成后就浏览已入库数据，不必等全部完成。

### 8.4 离线可用范围 `[已定]`

| 功能 | 离线可用 | 说明 |
|---|---|---|
| 浏览已入库数据 | ✅ | 全部工作台 |
| 查看历史研判与证据链 | ✅ | 含已缓存的证据原文片段 |
| 检索本地知识库 | ✅ | BM25 索引本地可用 |
| 查看 / 编辑设置 | ✅ | |
| 本地库管理（建库、统计、导出工作区） | ✅ | |
| 导出已有结果 | ✅ | |
| **发起新的协同研判** | ❌ | 需要 LLM 调用；**明确报错并说明原因**，不得静默降级为 Mock（基线 §7.6） |
| **实时抓取 / 重新抓取** | ❌ | 需要网络；显示离线态 |
| **在线来源校验 / 凭证校验** | ❌ | |
| 行情刷新 | ❌ | |
| Agent 活动流 | ⚠ 部分 | 可查看历史 trace，不能实时生成 |

> **零 Mock 严格模式**（基线 §7.6）：离线时发起研判必须显示「需要联网才能调用模型」并给出「查看历史研判」的替代动作，**绝不能**用假数据顶替。

## 9. Windows 桌面专属交互

### 9.1 托盘 `[已定]`

| 项 | 规则 |
|---|---|
| 常驻 | 关闭主窗口后**保留**托盘图标（默认）；托盘图标带**状态点**（就绪 = 中性点 / 抓取中 = `info` + `glow` / 降级 = `warn`） |
| 图标 | 应用图标 + 状态点叠加；不用动态 GIF |
| 右键菜单 | 「打开主窗口」「新建研判」「立即抓取」「暂停抓取」「开机自启 ✓」「退出 CBR-MAW」 |
| 通知 | 抓取完成 / 高风险待确认时用系统通知（Windows 通知中心），点击通知打开对应工作台 |
| 最小化 | 最小化到任务栏（正常），**不**自动进托盘（避免用户找不到窗口） |

### 9.2 最小化到托盘 / 退出语义 `[已定]`

| 用户动作 | 行为 | 文案 |
|---|---|---|
| 点关闭按钮 | **隐藏到托盘**，进程继续 | Toast 提示：「CBR-MAW 仍在后台运行，可从托盘图标退出」 |
| 托盘 → 退出 | 真正退出进程 | 退出前若有运行中的任务，弹确认：「有 1 个抓取任务正在进行，退出后将中断。仍要退出吗？」[按钮：「继续退出」「返回」] |
| 系统注销 / 关机 | 正常退出，保存状态 | — |

> 「隐藏到托盘」与「退出」必须**在文案上明确区分**（`08` §8 禁用词表收录"最小化=退出"类模糊表述）。

### 9.3 开机自启 `[已定]`

- 设置 → 通用 → 「开机自动启动」开关，**默认关闭**。
- 打开时说明：「开机后 CBR-MAW 会在后台运行并保持数据新鲜，不显示窗口。托盘图标可随时退出。」附「了解 Windows 启动项管理」链接。
- 关闭时不影响手动启动。

### 9.4 拖拽投递箱 `[已定]`

| 项 | 规则 |
|---|---|
| 触发 | 把文件 / 文件夹拖入窗口任意位置 |
| 处理 | 写入本地增量投递箱 `data/inbox/`（基线 §4.2 沿用旧项目语义），随后由 `IngestAgent` 自动清洗入库 |
| 反馈 | Toast：「已加入投递箱，正在清洗入库」+ 文件名；侧栏「投递箱」入口显示**待处理条目数**角标 |
| 失败 | 文件不可读 / 格式不支持 → Toast 失败 + 原因，**保留原文件**，投递箱内标记为「需人工处理」 |
| 不支持 | 不支持的格式**静默忽略是禁止的**，必须显式列出「不支持的文件类型：.xlsx（请导出为 CSV）」 |
| 视觉 | 拖拽悬停时窗口整体出现 2dp `focus.ring` 描边 + 居中提示「松开以加入投递箱」 |

### 9.5 全局快捷键唤起 `[已定]`

- 系统级热键 `Ctrl+Shift+Space`：从任何应用中唤起 CBR-MAW 主窗口并聚焦搜索框。
- 若 CBR-MAW 已在运行 → 激活窗口 + 聚焦搜索；若在托盘 → 从托盘恢复。
- 热键可在设置中禁用（避免与用户其他软件冲突）。
- 全局热键在 Linux 上依赖桌面环境支持，**不可用时降级**为普通应用内快捷键，且在设置中说明（不得假装可用）。

### 9.6 多窗口 / 标签页 `[已定]`

| 场景 | 行为 |
|---|---|
| 主工作台 | **单窗口**；内部用 `go_router` 的分栏视图（主区 + 检视区），不用多标签页 |
| 详情分离 | 证据详情 / 研判详情支持「在新窗口打开」→ 独立窗口（同一进程），可并排比对 |
| 窗口状态 | 记忆窗口尺寸、位置、侧栏折叠状态、当前路由（`window_manager` + `shared_preferences`） |
| 多实例 | **单实例**；第二次启动唤起已有实例（Windows 单实例锁） |

## 10. Android 专属约束

### 10.1 后台抓取受限与降级 `[已定]`

Android 对后台执行有系统级限制（Doze / App Standby / 后台工作限制），**不可能**做到桌面端那样的常驻实时抓取。

| 能力 | Android 实现 | 用户可见提示 |
|---|---|---|
| 周期抓取 | `WorkManager` 周期任务，**最短间隔 15 分钟**（系统限制）；建议 30 分钟 | 「后台抓取已开启。系统限制下最快每 30 分钟唤醒一次，唤醒时会尽量补齐缺口。」 |
| 精确间隔 / 秒级 | ❌ 不可用 | 「Android 不支持分钟级以内的定时抓取。需要即时更新时，请保持应用在前台或使用桌面版。」 |
| 前台实时抓取 | ✅ 前台服务（需用户显式开启 + 通知） | 前台服务常驻通知：「正在持续抓取数据 · 点此停止」 |
| 常驻托盘 | ❌ 无系统托盘 | 用**通知栏**替代；不承诺"后台常驻" |
| 开机自启 | 需引导用户加入**电池优化白名单** | 「允许 CBR-MAW 后台运行以保持数据新鲜」→ 跳转系统设置 |
| 长任务 | 前台服务 + `ForegroundServiceType.dataSync`（Android 14+ 需声明权限） | — |

**降级原则**：**先告知再降级**。任何因系统限制而无法提供的能力，必须在界面上明确说明限制原因，**不得**静默降低数据新鲜度而不提示。

### 10.2 存储与权限 `[已定]`

| 项 | 规则 |
|---|---|
| 存储模型 | Android 10+ 分区存储；**不申请** `MANAGE_EXTERNAL_STORAGE`（全盘访问） |
| 应用数据 | 全部存放在**应用私有目录**（`getApplicationDocumentsDirectory`），无需权限 |
| 用户指定目录 | 通过 **SAF**（`ACTION_OPEN_DOCUMENT_TREE`）让用户选目录，取持久化 URI 授权；**不**要求路径权限 |
| 投递箱 | Android 端不提供系统级拖拽投递箱；改为「分享到 CBR-MAW」（`ACTION_SEND` / `ACTION_SEND_MULTIPLE`）或应用内「导入文件」 |
| 运行时权限 | **用到再申请**（首次打开来源登录 / 通知 / 后台抓取时），不在启动时一次性索取 |
| 通知权限 | Android 13+ 需 `POST_NOTIFICATIONS`；未授权时后台抓取与托盘替代方案不可用 → 引导页说明 |
| 安装包 | 按 ABI 分包（`arm64-v8a` / `armeabi-v7a` / `x86_64`），避免大体积 |
| 导出 | 导出文件走 SAF 写入用户选定位置，不写公共目录 |

### 10.3 返回手势 `[已定]`

采用 **Android 13+ 预测性返回**（`PredictiveBackPageTransitionsBuilder`）。返回的**优先级**（从高到低）：

1. 关闭最上层浮层（对话框 → 菜单 → 抽屉 → 底部面板）
2. 关闭检视区 / 详情页
3. 关闭键盘（系统默认）
4. 路由返回上一层
5. 在**根路由**上：第一次按返回 → 底部弹出「退出 CBR-MAW？」（含「退出」/「取消」）；第二次按返回才退出

- 系统返回**不绕过**确认弹窗：任何未保存的编辑先弹「放弃更改？」。
- 侧栏抽屉与检视抽屉在返回时**关闭**，不触发路由返回。

### 10.4 软键盘避让 `[已定]`

| 项 | 规则 |
|---|---|
| 避让方式 | `Scaffold.resizeToAvoidBottomInset = false`，由输入区用 `AnimatedPadding(padding: EdgeInsets.only(bottom: MediaQuery.viewInsetsOf(context).bottom))` 自行避让 |
| 原因 | 默认行为会让整个页面跳动；自管避让只移动输入区，体验更稳 |
| 对话区 | 键盘弹出时自动滚到底部；用户已上滚则不强制滚动 |
| 表格内搜索 | 搜索框固定在表格顶部栏（不随内容滚动），键盘弹出时该栏保持在可见区 |
| 关闭 | 点击输入框外的空白区域收起键盘；`Esc` / 键盘上的「完成」收起 |

### 10.5 其他 Android 适配 `[已定]`

| 项 | 规则 |
|---|---|
| 触摸目标 | 全应用遵守 §4.1 的 48dp 触控热区 |
| 字体缩放 | 系统字号上限 1.3×；大字号下表格转卡片模式 |
| 深色模式 | 跟随系统（`ThemeMode.system` 默认） |
| 手势导航 | 底部导航栏避开系统手势区（`SafeArea`） |
| 平板与折叠屏 | 按 §1.2 `expanded` 档处理；折叠展开时用 `MediaQuery` 变化触发重排 |
| 电池 | 长任务期间提示用户可在设置中关闭"持续抓取"以省电 |

## 11. 交互验收清单

> 与 [`06`](06-设计系统与美学规范.md) §10 的视觉走查配套，本清单关注**交互与适配**。

### 11.1 布局

- [ ] 六个断点（360 / 600 / 840 / 1100 / 1440 / 1920dp）下**无横向溢出**
- [ ] 侧栏 / Rail / 底部导航切换时，滚动位置与展开状态保留
- [ ] 窄屏下表格自动转卡片，且排序字段置顶
- [ ] 窄屏下图表降级为摘要 + 展开，不出现被压缩到不可读的图表
- [ ] 宽屏下内容最大宽度封顶（`xxlarge` 居中留白），不出现超长行（阅读行长 ≤ 90 中文字符）

### 11.2 交互

- [ ] ★ 触控模式：所有可点元素命中区 ≥ 48dp
- [ ] ★ 所有 hover-only 信息都有触屏可达替代
- [ ] 表格横向滚动不与页面纵向滚动冲突
- [ ] 长按 500ms 打开上下文菜单，且不打断滚动
- [ ] 双击 / 右键 / `Ctrl+点击` 不是任何功能的唯一入口
- [ ] 命令面板：焦点陷阱生效，`Esc` 关闭后焦点归还触发元素
- [ ] 全局快捷键在所有页面生效且不与输入框冲突（文本框内不劫持 `Ctrl+K` 等）

### 11.3 无障碍

- [ ] ★ 11 个状态全部实现，且"需授权"态无任何占位数值
- [ ] ★ 所有图标按钮有 `Semantics(label)`
- [ ] 焦点顺序与视觉顺序一致；焦点环在所有背景上可见
- [ ] 动态播报节流生效，不逐 token 朗读
- [ ] 颜色之外总有第二通道（符号 / 文字 / 线型）
- [ ] 屏幕阅读器可完整走完核心流程（发起研判 → 查看冲突 → 查看证据 → 确认高风险操作）

### 11.4 流式与离线

- [ ] 逐 token 渲染节流到 ≤ 20 次/秒；用户上滚后不强制回底
- [ ] 停止生成保留已有内容
- [ ] 断线自动重连 3 次并提示；重连后补齐事件
- [ ] 骨架屏 → 内容无闪烁、无布局跳动
- [ ] 离线时全部"在线"功能显式报错并给出替代动作，**无 Mock 顶替**

### 11.5 平台

- [ ] Windows：关闭按钮隐藏到托盘并有明确提示；托盘菜单可真正退出
- [ ] Windows：拖拽文件入窗口 → 投递箱 → 入库 → 侧栏角标更新
- [ ] Windows：全局热键唤起可用（不支持的平台明确降级说明）
- [ ] Android：后台抓取降级有明确说明；无"静默降新鲜度"
- [ ] Android：系统返回手势逐级关闭浮层，根路由二次确认退出
- [ ] Android：键盘弹出不引起整页跳动

## 附 · 文件/压缩包投喂（v1 落地，扩展 §9.4）

原 §9.4 只描述单文件拖入。落地版扩展为**两处等价落点 + 压缩包支持**：

| 落点 | 交互 | 说明 |
|---|---|---|
| **窗口任意处拖拽** | 悬停时窗口 2dp focus 描边 + 居中提示「松开以加入投递箱」 | 与 §9.4 一致 |
| **对话输入框附件区** | 输入框旁「+」或直接拖入 | 与窗口拖拽**共用同一清洗链路与同一状态**，不是两套逻辑 |

### 支持格式

`.csv` `.tsv` `.txt` `.json` `.jsonl` `.xlsx` `.xls` `.zip`

- **ZIP 递归展开**：内层 CSV/XLSX 逐个处理；单个文件失败不阻断其它文件。
- 被拒文件：状态标红 + 可读原因（编码/表头/列名映射失败/格式不支持）+ 「查看详情」；**原文件保留不删除**。
- 列名映射结果**逐条可改**（下拉选择序列）；未命中的落 `custom.*` 并允许改名。

### 空态

「投递箱是空的。把 CSV/Excel 拖进窗口，或点这里选择文件」+ 可点示例（**示例文件必须标 synthetic**）。

### 红线

- 不得静默丢弃任何文件（每个文件都要有 accepted / rejected 结论）。
- 缺失单元格**不得**被补成 0 或观测行（北向 2024-08-16 后停更即为真实案例）。
