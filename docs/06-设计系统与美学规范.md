## 1. 美学立意

### 1.1 一句话定位 `[已定]`

> **一个能一眼看清风险的工业级控制台：克制的灰阶骨架，让语义色只在"有话要说"时出现，把全部视觉预算留给数字、证据与时间。**

### 1.2 参考坐标 `[已定·继承旧项目]`

| 维度 | 取向 | 具体含义 |
|---|---|---|
| **工业精确感** | SpaceX Industrial | 1px hairline 分隔代替阴影堆叠；数值对齐严格；不圆润、不亲和；所有单位与量纲显式 |
| **极简留白** | Apple Minimal | 大块中性面 + 极少量色彩；无装饰插画；无渐变；无拟物材质 |
| **信息密度优先** | Linear / Vercel | 桌面端一屏承载尽可能多的可比数据；行高 32–36dp；同屏不超过 3 个视觉焦点 |
| **运行态发光** | Neon（仅一处） | `glow` **只**用于"此刻正在运行"（抓取中 / 流式生成中 / Agent 活动流），且面积 ≤ 32dp 圆点，任何其他场景禁止 |

### 1.3 明确不做什么 `[已定]`

| 禁止 | 判定标准 | 替代做法 |
|---|---|---|
| **拟物 / 材质** | 出现渐变拟物按钮、皮革/金属/玻璃质感、投影模拟立体 | 纯色面 + 1px 描边 + 单一阴影层 |
| **高饱和渐变堆砌** | 同一视图内 ≥2 处彩色渐变，或任一渐变跨越 2 个色相 | 需要区分时用 `surface` 层级或 `viz` 色板离散取色 |
| **装饰性动效** | 循环 / 常驻 / 呼吸 / 视差 / 入场滑入动画（详见 §7.4） | 只保留状态切换与数据流入两类 |
| **大面积语义色** | 单个语义色块面积 > 96dp² 或占据整屏 | 语义色只用于：徽章底色、状态点、图表线、图标 |
| **玻璃拟态 / 背景模糊** | `BackdropFilter` 用于常规卡片 | 仅命令面板遮罩允许 2px 背景模糊（继承旧 `command-palette.tsx` 的 `backdrop-blur-[2px]`） |
| **大圆角卡通感** | 圆角 > 16dp 用于数据容器 | 卡片 12dp、控件 8dp、胶囊仅用于状态徽章与标签 |
| **Emoji 作图标** | 任何位置使用 Emoji 代替图标 | 统一 `lucide_icons` |
| **英文界面** | 出现英文按钮 / 标签 / 空态（§1 基线：纯中文） | 英文只出现在来源名、机构名、代码标识符、论文导出 |
| **纯黑纯白硬切换** | 深色模式用 `#000` 或直接反色 | 语义化双套 token（§8） |
| **用颜色单独传达信息** | 涨跌 / 状态只靠色块区分 | 必须叠加符号或文字（详见 §2.7、§7.2） |

## 2. 色彩体系

### 2.0 底层约定

- **基底**：Flutter Material 3 `ColorScheme`（`useMaterial3: true`），但**所有色板由本文件的 token 覆盖**，Material 默认色仅在开发期出现，不作为设计真源。`[已定]`
- **色值格式**：本文件用十六进制 HEX（Flutter `Color(0xFF…)` 落地），便于跨端核对；旧项目的 OKLCH 值仅作为"中性、无彩偏"的取向参考，不逐值继承。`[建议·待复核]`（Flutter 端统一用 sRGB hex，避免运行时 OKLCH 换算导致两端不一致）
- **对比度基准**：WCAG 2.2 AA
  - 正文与小字（< 18pt / < 14pt 粗体）：**≥ 4.5:1**
  - 大字（≥ 18pt / ≥ 14pt 粗体）、图标、图形、图表线、控件边界：**≥ 3:1**
  - **禁用态文本豁免**（WCAG 1.4.3 例外条款），但仍须 ≥ 3:1 以便可读
- 本文件所有对比度均为**实算值**（WCAG 2.2 相对亮度公式），非估计。

### 2.4 语义色板（状态色）`[已定]`

**每个状态色有三种形态，职责不可混用：**

| 形态 | 名称 | 职责 | 对比度门槛 |
|---|---|---|---|
| `*.solid` | **实心态** | 填充块、图标、图表线、进度条、状态点 | 图形 ≥ 3:1 |
| `*.ink` | **文字态** | 正文、徽章文字、表格内文字 | 文字 ≥ 4.5:1 |
| `*.tint` | **底色态** | 徽章 / 提示条的浅色底 | 与同色 `ink` 组合后 ≥ 4.5:1 |

| 语义 | 浅色 solid | 浅色 ink | 浅色 tint | 浅底实测 ink | 深色 solid | 深色 ink | 深色 tint | 深底实测 ink |

| **warn** 注意 / 陈旧 | `#D97706` | `#B45309` | `#FFFBEB` | **4.84:1** | `#F59E0B` | `#FBBF24` | `rgba(251,191,36,0.14)` | **10.47:1** |
| **danger** 风险 / 失败 | `#DC2626` | `#B91C1C` | `#FEF2F2` | **5.91:1** | `#EF4444` | `#F87171` | `rgba(248,113,113,0.14)` | **6.32:1** |
| **info** 进行中 / 提示 | `#2563EB` | `#1D4ED8` | `#EFF6FF` | **6.16:1** | `#3B82F6` | `#60A5FA` | `rgba(96,165,250,0.14)` | **6.88:1** |
| **idle** 空闲 / 未开始 | `#9CA3AF` | `#656E7B` | `#F1F3F5` | **4.64:1** | `#6B7280` | `#9CA3AF` | `rgba(156,163,175,0.14)` | **6.89:1** |

#### ⚠ 实心态 ≠ 文字态（旧项目踩过的坑）`[已定]`

旧项目把 `--success: #16a34a` 直接当正文色使用，实测：

| 旧做法 | 实测对比度（白底） | 判定 |
|---|---|---|
| `#16A34A` 作正文色 | **3.30:1** | ❌ 不达 AA 正文 4.5:1 |
| `#16A34A` 作图标/图形 | **3.30:1** | ✅ 达 AA 图形 3:1 |
| `#D97706` 作正文色 | **3.19:1** | ❌ 不达 AA 正文 |
| `#DC2626` 作正文色 | **4.83:1** | ✅ 勉强达 AA 正文，但与 `danger.tint` 上的文字混淆 |

**因此本文件强制规定：**

1. **代码层禁止直接引用 `*.solid` 作为文字颜色**。Flutter 侧以 `TextStyle` 扩展/自定义 lint 规则拦截：`solid` 只允许出现在 `Icon`、`Container` 背景、`BoxDecoration`、图表系列、`ProgressIndicator`。
2. **所有文字必须走 `*.ink`**。
3. **实心态上不放文字**。白字在 `ok.solid #16A34A` 上仅 **3.30:1**、在 `warn.solid #D97706` 上仅 **3.19:1**，均不达 AA 正文。徽章一律用 `tint` 底 + `ink` 字；`solid` 只用于图标、进度条、图表线与状态点。
4. 唯一例外：**主按钮**用中性墨色（`accent.primary`），不用状态色做主按钮底。

### 2.7 涨跌色与「红涨绿跌 / 绿涨红跌」冲突 `[已定规则 + 建议·待复核默认值]`

**问题**：本产品面向中国大陆研究员，但研究对象是跨境市场（美股 / 港股 / A 股 / 外汇 / 商品）。中国用户默认 **红涨绿跌**，国际惯例 **绿涨红跌**。同一屏内同时出现两种约定会直接导致误读。

**方案：可配置的三套约定（`marketColorConvention`）**

| 方案 ID | 名称 | 涨 | 跌 | 适用场景 |
|---|---|---|---|---|
| `cn` | 中国惯例 | 红 `#C62828`（浅底 5.62:1 / 深底文字用 `#F87171` 6.32:1） | 绿 `#2E7D32`（浅底 5.13:1 / 深底文字用 `#4ADE80` 10.04:1） | 面向大陆用户的默认视图 |
| `intl` | 国际惯例 | 绿 `#2E7D32` | 红 `#C62828` | 跨境对比视图、论文与报告导出 |
| `mono` | 单色（打印 / 色觉障碍） | 深墨 `#1F2937`（深色模式 `#E8ECF2`） | 中灰 `#6B7280`（深色模式 `#A9B2C0`） | 黑白打印、投影、严格色觉障碍 |

**强制规则：**

1. **颜色永远只是冗余通道**。涨跌必须**同时**呈现 **箭头（▲ / ▼）+ 正负号（+ / −）**；`mono` 方案下也保留箭头与符号。→ 满足 WCAG 1.4.1（不依赖颜色传达信息）。
2. **涨跌色与状态色不在同一视觉容器内混用**。若一张 KPI 卡同时要显示"风险等级"（danger）与"涨跌幅"，则：风险等级用徽章（`danger.tint` 底 + `danger.ink` 字 + 图标），涨跌幅移入副行且**只保留箭头与符号**，不叠加涨跌色块。
3. **默认约定**：`cn`（中国大陆用户优先）。`[建议·待复核]` — 理由：本产品主要使用者是中国研究员；但跨境研究场景建议在"多市场对比"视图中自动切换为 `intl`，并在视图标题下以一行小字标注"本图采用国际惯例（绿涨红跌）"。
4. **配置入口**：
   - 全局：`设置 → 显示与排版 → 涨跌配色`（单选：`中国惯例 / 国际惯例 / 单色`）；
   - 局部：图表工具栏的「配色」图标 → "仅本视图覆盖"；
   - 持久化于 `shared_preferences`，键 `ui.market_color_convention`；
   - 导出报告（PDF/PNG）时**必须**在图注写明所采用的约定，并同步导出当时的色值映射。
5. **涨跌色只用于"数值方向"语义**（涨跌幅、净流入、环比变化），**不用于**任何状态判断。状态判断一律用 §2.4 的 `ok/warn/danger/info/idle`。

### 2.8 对比度验收（自测脚本口径）`[已定]`

- 交付前用同一段 WCAG 2.2 公式脚本扫描 token 表，输出所有 `ink` 组合，断言 ≥ 4.5；所有 `solid`/图表色对 `surface.base` 断言 ≥ 3.0。
- 断言脚本必须包含**跨组合**：`text.tertiary` 对 `surface.sunken`（易漏项，本次实测 4.73:1）。
- 本文件所有"实测"数值即为该脚本的输出，评审时以脚本重跑结果为准。

## 3. 排版与尺度

### 3.1 字体族 `[已定]`

| 用途 | 字体 | 来源 | 回退 |
|---|---|---|---|
| 中文正文 | 系统中文 UI 字体 | Windows `Microsoft YaHei UI` / macOS `PingFang SC` / Linux `Noto Sans CJK SC` / Android `Noto Sans CJK SC` | 系统默认 |
| 拉丁与数字 | **Inter** | `google_fonts`（运行时按需缓存，失败降级系统字体） | `system-ui` → `Roboto` → `Segoe UI` |

| 数值（表格 / KPI） | Inter + **tabular figures** | 同上 | 同上 |

- **不打包中文字体**（体积 + 授权），中文一律走系统字体；`google_fonts` 只用于拉丁与等宽。
- `google_fonts` 在离线环境不可用时**必须**自动降级而非阻塞首屏（`allowRuntimeFetching` 在离线时静默失败）。
- **等宽字体只用于**：代码标识符、trace id / run id、时间戳、日志、原始 JSON、文件路径。**不用于**正文。
- 所有**数值**使用 Inter 的 **tabular figures**（`FontFeature.tabularFigures()`），保证列对齐、滚动时不跳动。

- **行高**：按 §3.2 逐级给定；正文 1.5，密集表格 1.3（`type.numericSmall`）。
- **字重**：仅用 400 / 500 / 600 / 700 四档。

## 5. 图标

### 5.1 图标集选型 `[已定]`

**统一使用 `lucide_icons`**（Flutter 社区移植版）。

**理由**：

1. **风格匹配**：Lucide 是 1.5–2dp 描边、圆角端点的线性图标，与本项目"1px hairline + 中性灰阶"的工业语言一致；Material Icons 的 filled 变体过重，outlined 变体在 16dp 以下笔画会糊。
2. **可枚举**：Lucide 图标名是稳定字符串常量（如 `LucideIcons.shieldAlert`），可作为 **A2UI catalog 的图标白名单**做静态校验——这是 §9 安全边界的前提；Material Symbols 是可变字体，字形名与文件绑定，不利于白名单化。
3. **体积与许可**：ISC 许可，无可变字体二进制。
4. **一致性**：不允许在同一产品内混用第二套图标集。

### 5.2 尺寸阶梯 `[已定]`

| Token | dp | 描边宽 | 用途 |
|---|---|---|---|
| `icon.xs` | 12 | 2.0 | 状态点旁、内联徽章、树形折叠箭头 |
| `icon.sm` | 14 | 2.0 | 侧栏导航项、次要说明前缀 |
| `icon.md` | 16 | 2.0 | 按钮内、菜单项、表格行首、角色标记 |
| `icon.lg` | 20 | 1.75 | 卡片标题图标、工具栏主按钮 |
| `icon.xl` | 24 | 1.75 | 工具栏、空态图标 |
| `icon.2xl` | 32 | 1.5 | 大空态、状态区块 |
| `icon.3xl` | 40 | 1.5 | 页面级空态 / 无权限态 |

> 描边宽度随尺寸递减，避免小图标笔画挤压（Flutter 的 `Icon` 无独立 stroke 参数，需按尺寸选用不同视觉重量的图标集合；建议在 `CbrIcons` 封装层中按尺寸映射并统一视觉重量 `[建议·待复核]`）。

### 5.3 强制规则 `[已定]`

1. **图标按钮必须带语义标签**：`Tooltip` + `Semantics(label: ...)`。禁止无标签的裸图标按钮。
2. 图标**不单独承载含义**（除状态点外）；必须与文字并列，或提供 `Semantics` label。
3. 状态点（圆点）必须配合文字或 `Semantics` 说明，不单独作为"好/坏"传达通道。
4. 图标不作为可点击的唯一入口而缺少 hover/focus 反馈；所有图标按钮须有 `:hover`（桌面）/ `:pressed` 等价态。
5. 禁止手绘 SVG、禁止用字符图标、禁止 Emoji。

| **无权限态** `AccessRequiredState` | **数据不可得（需授权）** | 需授权 / 需登录 / 反爬受限 | 未授权 | 本产品最特殊状态：**不得显示任何占位数字**（不得显示 `0`、`--`、`N/A`）；必须写明来源、原因、单一主动作"前往授权"；见 [`07`](07-交互与响应式规范.md) §6.2 |
| **陈旧态** `StaleBadge` | 数据超过阈值未更新 | 轻度 / 重度 | 陈旧 | 必须写"上次成功抓取：〈时间〉"；重度陈旧同时置 `warn` 色 + 文字 |
| **Toast** `Toast` | 轻量操作反馈 | 成功 / 失败 / 提示 / 撤销 | 出现、消失 | 停留 ≥ 4s；错误 ≥ 8s 且不自动消失（需手动关闭）；`SemanticsService.announce` 一次；可含"撤销"动作 |
| **进度条** `ProgressBar` | 抓取 / 建库进度 | 线性 / 环形 | 进行中 / 停止 / 失败 | 必须给百分比或已完成/总量，不得只给不定进度动画 |
| **提示条** `InlineBanner` | 页内常驻说明 | 提示 / 警告 / 错误 | 静态 / 可关闭 | 不可只靠颜色区分；含"了解更多"链接时链接文字自足 |
| **工具提示** `Tooltip` | 补充说明 | 短文本 | 显示 / 隐藏 | 触屏需长按可达；**不得承载唯一信息** |
| **状态标签** `Tag` | 分类标签 | 中性 / 语义 | 静态 | 文字自足 |

## 7. 动效规范

### 7.1 时长阶梯 `[已定]`

| Token | 时长 | 用途 |
|---|---|---|
| `motion.fast` | 120ms | 悬停反馈、颜色/透明度变化、焦点环 |
| `motion.base` | 200ms | 展开折叠、菜单进出、Toast 进出 |
| `motion.slow` | 320ms | 抽屉进出、对话框、卡片切换、骨架→内容交叉淡出 |
| `motion.slower` | 480ms | 页面级转场、图表首次绘制 |

### 7.2 缓动曲线 `[已定]`

| Token | 曲线 | 用途 |
|---|---|---|
| `motion.easeStandard` | `cubic-bezier(0.2, 0, 0, 1)` | 通用（可逆：出现与消失同曲线） |
| `motion.easeEnter` | `cubic-bezier(0, 0, 0, 1)` | 进入（加速） |
| `motion.easeExit` | `cubic-bezier(0.3, 0, 1, 1)` | 退出（减速） |
| `motion.easeEmphasized` | `cubic-bezier(0.2, 0, 0, 1)` + 12% 缩放起止 | 强调型（确认、抽屉） |

### 7.3 `prefers-reduced-motion` 全局兜底 `[已定]`

**旧项目的已知缺陷**（CSS 动画缺少 `prefers-reduced-motion` 兜底）在本项目必须修复。

**实现方式（Flutter）：**

1. 唯一入口：`Motion.of(context)`（自建 InheritedWidget），**禁止**在业务代码里直接写 `Duration(milliseconds: 200)`。
2. 该扩展读取 `MediaQuery.disableAnimationsOf(context)`（Flutter 已把平台「减少动画」设置映射到 `AccessibilityFeatures.disableAnimations`）。
3. 当其值为 `true`：
   - 所有 `Duration` 一律解析为 `Duration.zero`；
   - 缩放/位移类过渡直接跳变到终态；
   - **骨架屏的微光扫过（shimmer）改为静态灰块**（不得保留循环动画）；
   - KPI 数值滚动改为直接显示最终值；
   - 流式生成的光标闪烁改为静态实心块；
   - 图表首次绘制动画直接呈现终态。
4. 平台映射：Windows「设置 → 辅助功能 → 视觉效果 → 动画效果」关闭 → `disableAnimations = true`；Android「移除动画」/「动画时长 0」→ 同上。
5. **不得**因为 `disableAnimations` 而跳过必要的信息呈现（只是不"动"，不是不"出现"）。

### 7.4 允许 / 禁止的动效 `[已定]`

| ✅ 允许 | 说明 |
|---|---|
| 状态切换 | 展开/折叠、抽屉/菜单进出、Tab 切换、选中态变化 |
| 数据流入 | 骨架 → 内容的交叉淡出（≤ 320ms）、列表新增项淡入（stagger **最多 6 项**、每项间隔 20ms） |
| 确定性进度 | 进度条推进、环形进度（由真实进度驱动） |
| 反馈 | Toast 进出、按钮按下反馈（`motion.fast`） |
| 数值变化 | KPI 首次挂载时的数字滚动（≤ 400ms，reduce-motion 时禁用） |
| 运行态指示 | 抓取中 / 流式生成中的状态点 `glow` 呼吸（唯一允许的循环动画；reduce-motion 时改为常亮） |

| ❌ 禁止 | 说明 |
|---|---|
| 装饰性入场 | 页面/卡片整块滑入、缩放弹入 |
| 循环装饰动画 | 渐变流动背景、彩虹边框、无意义旋转 |
| 视差 / 鼠标跟随 | 3D 翻转、倾斜、跟随光标 |
| 自动轮播 | 公告、指标横幅自动切换 |
| 数字乱跳 | 每个数值变化都重新滚动 |
| 过度转场 | 路由切换使用全屏滑动（仅在移动端允许 120ms 淡入） |

### 7.5 流式内容的动效约束 `[已定]`

- 逐 token 渲染**不伴随**逐字动画；文本直接追加。
- 骨架屏 → 流式内容：容器尺寸保持一致（预留与真实内容相同的高度），交叉淡出 320ms，避免页面跳动。
- 新到的证据条目在活动流中**从顶部插入**并淡入 120ms；不做滑动。

## 8. 深色模式

### 8.1 原则 `[已定]`

- **语义化，不是反色**：浅色 `#FFFFFF` → 深色 `#131A24`，不是 `#000000`；语义色独立取值。
- 深色模式**不是**把浅色值做 `invert`。
- **跟随系统**为默认；同时提供「浅色 / 深色 / 跟随系统」三态（`设置 → 显示与排版`），键 `ui.theme_mode`。

### 8.2 深色下的关键差异

| 项 | 浅色 | 深色 | 原因 |
|---|---|---|---|
| 页面底 | `#F4F5F7` | `#0B0F17` | 深色下不用纯黑，避免与系统边界糊在一起 |
| 卡片面 | `#FFFFFF` | `#131A24` | 卡片需与底有可见差 |
| 浮层面 | `#FFFFFF` | `#1A2230` | 三层 surface 层级保持 |
| 描边 | 实色 | 保持实色（**不**用白色透明度叠加） | 避免半透明描边在深色下发灰 |
| 阴影 | 明显 | **弱化至 25% 不透明度** | 深色下阴影几乎不可见，层级改由 surface 明度差承担 |
| 焦点环 | `#2563EB` | `#60A5FA` | 深色下需更亮才达 3:1 |
| 图表底 | `surface.base` | `surface.base`（**不是纯黑**） | 图表与卡片同面，避免"浮岛" |
| 图表网格线 | `#E5E7EB` | `#232C39` | 深色下网格线需比描边更弱 |

### 8.3 图表在深色下的独立取值 `[已定]`

- 深色模式**不使用**浅色图表色板的反相版本，而是使用 §2.5 表中的**深色列**（8 个独立色值，全部实测 ≥ 6.2:1）。
- 图表系列的**顺序**在两种模式下保持一致（`viz.1` 永远是对应的同一系列），避免切换主题后需要重新学习。
- 深色下图表网格线 `#232C39`、轴线 `#2E3947`、轴标签 `#A9B2C0`（8.17:1）。
- 涨跌色深色取值见 §2.7。
- 深色下的 `glow`（运行态）不透明度降至 60%，避免晕开。

## 9. A2UI catalog 的视觉契约

> 基线 §3 已定：**catalog 是安全边界**，Agent 只能渲染登记过的组件。本节把"安全边界"从"组件白名单"扩展为"**视觉白名单**"——Agent 不仅不能自造组件，**也不能自造视觉**。

### 9.1 契约条款 `[已定]`

| 编号 | 条款 |
|---|---|
| **VC-1** | catalog 中的每个组件**必须**是 §6 自建组件的**同一份实现**（同一 widget 类），不得为 Agent 另写一套皮肤或简化版。 |
| **VC-2** | Agent 只能传**语义参数**（`label` / `value` / `variant` / `state` / `trend` / `level` / `items` 等白名单字段）。**禁止**传：颜色值、字号、字重、字间距、间距、圆角、阴影、字体、图标字形、透明度、z-index、任意 `style`/`BoxDecoration`。 |
| **VC-3** | 所有 catalog 组件必须实现 §6 规定的完整状态集合（loading / empty / error / disabled / 无权限），Agent 不得自行跳过状态渲染。 |
| **VC-4** | Agent 生成的**文案**必须遵循 [`08-文案标准与术语表.md`](08-文案标准与术语表.md)（术语表、语气、错误三段式）。渲染层对违反术语表的专有名词做**提示而非阻断**（记录到 trace）。 |
| **VC-5** | 未登记的组件 / `strict` 校验失败 → **该 surface 不下发**，写 `renderError{surfaceId}`（`03-多智能体架构.md` §10.3）；在对话流追加一条**纯文本摘要（不含任何未经核验的数值）**。**不得**用未校验内容渲染，**不得**抛异常中断整个会话。 |
| **VC-6** | catalog 组件带**版本号**（`catalog_version`）。升级 catalog 必须同步更新 Agent 系统提示中的组件清单，并记录变更日志。 |
| **VC-7** | catalog 组件的可用**图标**限定在 §5.1 的 Lucide 子集白名单内（编译期枚举），Agent 只能引用图标**名**，不得上传 SVG/位图。 |
| **VC-8** | Agent 生成界面中**不得**出现：Emoji、渐变、自定义 SVG、外链图片、Markdown 表格（表格必须用 §6 的 `DataTableVirtual`）、代码块（用 `type.code` 样式 + 等宽字体）。 |

### 9.3 安全边界的执行点 `[已定]`

```

       └ dataRef 必须能在 dataModel 中解析
  → A2UI 消息（createSurface / updateComponents / updateDataModel）
  → genui SurfaceController + Conversation + A2uiTransportAdapter
```

`SurfaceBridge`（路径 `lib/genui/bridge/surface_bridge.dart`，视觉校验子层 `lib/genui/bridge/visual_guard.dart` `[已定]`，与 [04 §4.2](04-动态UI与Agent-Native设计.md) 一致）是**唯一**的渲染入口；任何绕过它的渲染路径在代码评审中一律驳回。

- 窄屏不溢出：每页在 360 / 600 / 840 / 1100 / 1440 / 1920dp 六档宽度下截图走查，溢出即失败。
