# CBR-MAW v1.0.0 发布说明

发布日期：2026-10-20 ｜ 仓库：<https://github.com/Thecnfor/cbr-maw> ｜ 许可证：MIT

> **定位**：跨境金融风险多智能体协同预警的**研究性原型**正式版。默认使用 SYNTHETIC
> 仿真数据（离线可复现）；真实数据已接入但需本地重建，且不构成投资或监管建议。

## 亮点

1. **多智能体协同预警闭环**：监管 / 投资 / 融资三类主体智能体 + 协调者/核验器，
   R0 独立分析 → R1 证据共享 → R2 交叉验证 → R3 分歧识别 → R4 冲突仲裁 → R5 决策卡；
   所有数值由 7 个确定性工具计算，所有结论可溯源，全链路审计 trace。
2. **AI-native 驾驶台**：React 19 + Vite + Tailwind v4；SSE 流式运行（RunProgress /
   活动流 / 取消）、⌘K 命令面板、对话流式与打字机、上下文追问（智能体卡/证据/冲突
   一键跳转）、协同过程时间线、light/dark 与 reduced-motion；FastAPI `/ui` 免构建托管。
3. **真实数据接入（v1.0 新增）**：用户提供的汇率/利率/股债/全球因子/宏观数据 +
   飞书 Base「07 沪深港通资金流」+ 飞书文本语料（9,758 篇）+ 公开接口补齐 14 条序列；
   快照 2015-01-05~2025-09-30、2,615 交易日 / 27 序列 / 57,421 观测 / 9,758 文本。
4. **可复现实验**：P1 模态消融、P2 工具/知识消融、P3 三模式协同；默认 Mock LLM 离线
   跑通，配置 DeepSeek key 后自动切换真实模型。
5. **工程质量**：249 项 pytest、ruff 门禁、仓库卫生与链接检查、CI（Python + Web）、
   DOCX 技术文档第四章 v1.0 与完整文档体系。

## 升级与安装

```powershell
git clone https://github.com/Thecnfor/cbr-maw.git
cd cbr-maw
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install -e . --no-deps
.venv\Scripts\python.exe -m pytest -q          # 可选
.venv\Scripts\python.exe -m uvicorn cbr.api.main:app --host 127.0.0.1 --port 8000
# 打开 http://127.0.0.1:8000/ui/
```

默认数据为仓库自带 SYNTHETIC 样例；真实数据需按
[真实数据接入](../data/real_data_integration.md) 在本地重建
（原始数据与 `data/custom/` 不入库）。配置 `DEEPSEEK_API_KEY`（或 `secrets/deepseek.key`）
后自动使用真实 DeepSeek；否则使用确定性 Mock LLM。

## 已知限制

- 真实数据部分序列为明示代理口径：SHIBOR 1W→7 天回购、AAA 中票→AA 信用利差、
  累计净流入→北向持仓、12 个月滚动增量→社融存量同比；北向 2024-08-16 停披露、
  CPI 2015–2020 缺失。
- 真实数据 P1 文本增益与 P3 协同决策收益均未达显著，属 pilot 级结果，不能过度外推。
- 预测模型仅在的历史窗口上验证；正式论文实验需全窗口、更多标签稳健性与更均衡文本语料。
- 研究性原型：输出不构成投资建议或监管决定。
