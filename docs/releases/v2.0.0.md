# CBR-MAW v2.0.0 发布说明

发布日期：2026-10-27 ｜ 仓库：<https://github.com/Thecnfor/cbr-maw> ｜ 许可证：MIT

> **定位**：跨境金融风险多智能体协同预警的**研究性原型**实时化版本。在 v1.0.0 的
> 「历史/批数据 + 多智能体协同」基础上，把数据侧升级为「**实时智能抓取 → 增量落 PIT →
> 派生序列实时重算 → provider 热刷新**」，并补齐可选基础设施、RAG 与执行 Harness。
> 默认仍为 SYNTHETIC 仿真数据；实时抓取只使用公开免 key 来源，不构成投资或监管建议。

## 相对 v1.0.0 的变化

### 新增：实时智能抓取（L1.5 数据接入层）
- 声明式数据源 `configs/sources.yaml`（`http_csv` / `http_json` / `akshare` / `rss`）。
- 确定性缺口/陈旧度分析（`gaps.py`）：规划「该抓什么」，日频/月频分级陈旧阈值。
- **多源回退**：同一序列可声明多个来源，主源失败自动切备源（实测东财不可达时自动切腾讯/官方/akshare）。
- 增量写 PIT：`PitStore.upsert_observations/upsert_documents/touch_coverage`（幂等，不重建全库）。
- 派生序列实时重算（`term_spread` / `cn_us_spread` / `cgb_index`）。
- provider 热刷新：`PitStoreDataProvider.detach()/reload()`（写前释放只读连接、写后重开），新增 `data.dataset=pit` 模式。
- API：`GET /api/ingest/{status,sources,freshness,plan}`、`POST /api/ingest/refresh`；`/api/health` 增补 `ingest` 状态块；lifespan 按配置启停后台调度器。

### 新增：可选基础设施与 RAG
- `docker-compose.yml`：postgres+pgvector(55432) / redis(56379) / mongo(57017) / qdrant(56333)。
- `src/cbr/infra/`：socket 健康探测 + 可选客户端，全部可降级（缺驱动或不可达返回 `None`，不影响启动与测试）。
- `src/cbr/knowledge/vector.py`：可插拔向量化（默认离线 `HashingEmbedding`）+ 向量库（Numpy/Qdrant/pgvector）
  + BM25·向量加权 RRF 混合检索（时点/标签/来源过滤）。

### 新增：执行 Harness
- `src/cbr/harness/`：稳定契约（`AgentHarness`/`TaskSpec`/`RunResult`）+ 进程内实现
  + 远程适配器（OpenHands / Python+TS 二开预留）。选型见 [ADR](../architecture/adr-2026-10-27-agent-harness.md)。

  httpx `>=0.27`→`>=0.28.1`、xgboost `>=2.1`→`>=3.2.0`、`web/` minor/patch 组。

## 升级与安装

```bash
git clone https://github.com/Thecnfor/cbr-maw.git && cd cbr-maw
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e . --no-deps
# 可选：基础设施 / RAG / 实时抓取额外依赖（不装则自动降级）
pip install -r requirements-optional.txt           # 可选
# 可选：一键起停 postgres+pgvector / redis / mongo / qdrant
docker compose up -d
pytest -q                                          # 可选
python -m uvicorn cbr.api.main:app --host 127.0.0.1 --port 8000
```

实时抓取默认关闭；启用见 [实时智能抓取指南](../guides/realtime-ingestion.md)
（`ingest.enabled: true`，或按需调用 `POST /api/ingest/refresh`）。
若要决策即时消费实时数据，将 `data.dataset` 设为 `pit`。

## 长时测试（soak）

本次发布配套 `scripts/soak_test.py`：以可配置时长/周期反复触发抓取（后台调度器路径），
采集每次运行的耗时、成功率、观测/文档数、陈旧序列与进程内存，落盘到 `artifacts/soak/`，
用于长时稳定性与资源趋势观察。用法见 [长时测试指南](../guides/long-running-tests.md)。

## 已知限制

- 部分公开来源可能被限流/不可达（如本环境 `push2his.eastmoney.com` 不可达），依赖多源回退；
  无备源的序列（如 `ah_premium`）会保持陈旧并在 `/api/ingest/status` 标注。
- `akshare`、向量库/基础设施驱动为**可选依赖**，未安装时相关功能自动 `skipped`/降级。
- pgvector 需 PG 安装 `vector` 扩展（`pgvector/pgvector` 镜像已内置）。
- 研究性原型：输出不构成投资建议或监管决定。
