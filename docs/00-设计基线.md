## 2. 运行时拓扑与语言分工

> 原始约束：「没有中央服务器，一个安装包 + 配个 api 密钥就可以快速使用，一键即用最重要」

- `[已定]` **纯客户端本地多进程（无中央服务器）**：见 [ADR-006](adr/ADR-006-多语言本地内核分层.md) 与 [01-架构设计.md](01-架构设计.md)。
  - **Dart / Flutter 壳**：UI、动态界面、Agent 编排与能力槽位路由、权限门卫、密钥与审计；
  - **Go `collector`**：来源台账、可达性探测、并发抓取、Inbox 脏表清洗、自更新；
  - **Rust `kernel`**：**DuckDB**（时序/PIT/统计）+ **嵌入式 LanceDB**（`MI/LLR/HLR` 三库记忆与跨模态证据检索）双引擎，共驻同一工作区目录且为唯一写入者；预留契约化高阶科研计算插件槽。
- `[已定]` **无对外监听端口、无独立部署服务**：sidecar 随安装包分发，只走 `stdio NDJSON`（JSON-RPC 2.0），按需懒启动、随应用退出终止。
- `[已定]` **去 Python 化**：旧 `src/cbr`（Python）不进入产品安装包，仅作为本地黄金向量参考源；运行时配置统一用 **JSON + JSON Schema**（旧 yaml 对照件留存在 [docs/legacy-configs/](legacy-configs/)）。
- `[已定]` **工作区导出/导入**：支持以工作区为单位打包迁移（含本地库、配置、审计轨迹，**不含明文密钥**）。

## 3. 技术选型与动态 UI 基线（激进现成库路线）

- `[已定]` **废弃 SDUI**：旧 `AppManifest` / `PageSpec` / `dashboard-kit` 全部废弃。
- `[已定]` **Agent 编排与模型层**：全面采用 Google **Genkit for Dart**（`1.x`，含 `agents` 中间件与多厂商插件），通过确定性钩子强守三条红线；JEV 裁判（`jev-1.14.0`）保持 `dio` 薄封装；支持能力槽位路由并**默认回落到单个默认密钥**（见 [ADR-003](adr/ADR-003-多智能体运行时采用Genkit.md)、[ADR-011](adr/ADR-011-三主体升维与异构模型槽位路由及计算插件边界.md)）。
- `[已定]` **动态 UI**：采用 **A2UI 协议 + Flutter 官方 `package:genui`**，我方只保留 [packages/a2ui_catalog](file:///home/xrak/Desktop/Shared/recently/CBR/packages/a2ui_catalog) 作为白名单安全边界；**OpenUI 归档仅作研究对照，不实现**（[ADR-002](adr/ADR-002-动态UI采用A2UI.md)）。
- `[已定]` **应用基础设施**：状态管理用 `flutter_riverpod`；密钥存储用 `flutter_secure_storage`（OS 原生安全存储，禁止自写 DPAPI FFI）；JSON-RPC 传输评估采用官方 `json_rpc_2`。
- 说明：v1 现有代码与上述选型基线之间的差距（如手写编排/状态/明文密钥临时方案）统一登记在 [12-v1架构与工程收口清单.md](12-v1架构与工程收口清单.md)。

## 4. 数据获取、清洗铁律与零 Mock 红线

- `[已定]` **绝对禁止内嵌来源数据、禁止为任何来源写 mock/假数据**。拿不到即显式标注「需授权 / 需登录 / 反爬受限 / 不可达 / 已过期」，界面永不出现伪造数值（[ADR-004](adr/ADR-004-数据抓取原则.md)）。
- `[已定]` **零 Mock 严格模式**：生成模型不可用时必须显式报错并引导到设置页；JEV 裁判不可用时回退规则门卫，但强制 `judge_available=false`、**不产出置信度**并明示「未使用模型判断」。
- `[已定]` **合成数据使用边界（D6）**：
  - **v1 真实数据验收（M1–M3）严禁使用合成数据**；
  - 合成数据只允许用于 ① **v2 新手岛沙盒教程**（[ADR-007](adr/ADR-007-新手岛沙盒教程.md)，`data/tutorial/`）、② **单元测试夹具**（`data/samples/`，产品代码不得读取）、③ **显式 `SIMULATION` 隔离的计算实验沙盒**（[ADR-010](adr/ADR-010-X-AlertAgent双核嵌套与LanceDB三库记忆架构.md)），所有导出物必须携带 `SYNTHETIC` / `SIMULATION` 标记。
- `[已定]` **CFSI 缺维与数据新鲜度口径**：见 [ADR-008](adr/ADR-008-CFSI缺维降级口径.md)（缺席维度不参与、禁止 0/均值填充、`τ` 不冻结、强制追加 `limitations`，`dead` 序列不得用于实时预警叙事）。
- `[已定]` **四条数据清洗硬铁律**（1 组 1028 交付实证）：删周六复制行（16.5%）、港股通按交易日+标准代码去重合并（43%）、停牌行缺失禁 `fillna(0)`、港股代码复用以 `SecurityID` 为实体键且北向日频/季末不混频（[ADR-011](adr/ADR-011-三主体升维与异构模型槽位路由及计算插件边界.md)）。
- `[已定]` **三级 PIT 时点纪律**：内地当日 18:00 (+08:00)、隔夜海外次日 09:00 (+08:00)、月频按发布日，四级强制 `available_at <= as_of`。

## 7. 不可丢的核心继承语义

1. **风险分级**：`L0`（只读导航）、`L1`（一般写）、`L2`（高风险写），缺确认处理器时 **fail-closed**。
2. **证据链强制绑定**：numeric 绑工具重算并覆盖 LLM 数值；text 绑 KB 证据；directional 绑信号；无证据不进入结论卡。
3. **三级哈希逐字节一致**：`evidence_id` / `inputs_hash` / `evidence.hash` 严格复刻 Python 浮点序列化语义。
4. **白名单与权限矩阵**：`default_deny=true`，越权在 Dart 门卫拦截，绝不发 RPC。
5. **协同成本折算**：`J = L + μ·C`，硬预算熔断只产标注「部分结论」，不产 Mock。
6. **人在环（HITL）**：高风险、未决冲突、越权、核验失败、超预算必须留痕触发人工确认。
