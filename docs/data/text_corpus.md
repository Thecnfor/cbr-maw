# 真实文本语料（飞书「文本数据 8.2」）

本文件记录 CBR-MAW 文本模态真实语料的来源、筛选、时点化与已知偏差。产物由
`scripts/build_text_corpus.py` 生成，供 `data/custom/policy_news.csv` 接入
`CustomDatasetAdapter` 的 `documents` 映射。

## 1. 来源与规模

飞书云盘文件 `文本数据8.2.zip`（197.6 MB，9 个 JSONL，解压约 590 MB）：

| 来源 | 原始行数 | 入区间候选 | 最终保留 | 说明 |
|---|---|---|---|---|
| 人民日报 | 38,308 | 17,812 | 3,833 | 仅 2021+；按关键词分层抽样 |
| 光明日报 | 28,610 | 18,582 | 3,092 | 2014+；2017–2020 的主要中文日报来源 |
| 中国政府网 | 985 | 912 | 912 | 仅 2021+；政策文本，全部保留 |
| 跨境 | 1,987 | 1,715 | 844 | 实为跨境通等上市公司公告（PDF 结构化正文） |

- 最终 **9,758 篇**，日期范围 **2017-01-01 ~ 2025-09-30**，每日中位数 2 篇（最多 16 篇），

- 输出 `data/custom/policy_news.csv`（UTF-8-SIG，29.4 MB）：
  `doc_id,publish_time,title,content,source,url`；正文截断至 1500 字符
  （中位数 1,384，均值 1,122）。

## 2. 筛选与抽样规则

1. **时点**：`publish_time` 必须是可解析日期（只保留日期，原始数据无可靠时分）；
   严格按日期入样，异常/缺失日期丢弃（676 篇）。
2. **区间**：2017-01-01 ~ 2025-09-30；区间外丢弃 35,267 篇。
3. **分层配额**：政府/证券媒体全保留（每日上限 20 篇）；跨境/黄金按字节预算配额；
   人民日报/光明日报按「关键词优先 + 每日 ≤80 篇/来源」抽样；英文源每日 ≤1 篇。
4. **每日保底**：强制每日至少 1 篇，保证交易日历上的文本特征不出现长段空窗。
5. **去重**：`doc_id` 唯一；`title+date` 去重（1,722 篇）。
6. **预算**：CSV 目标 ≤30 MB，通过两轮「字节水位填充」把 48,617 篇候选压缩到 9,758 篇。

## 3. 已知偏差与风险（必读）

- **日内前视（轻微）**：`publish_time` 只有日期，系统按 00:00 处理；媒体/政策文档在
  当日 15:00 切点前即被视为可得。若需严格，可把「中国政府网」加入
  `src/cbr/features/text.py` 的 `POLICY_SOURCES`（本次未改源码）。
- **来源时间不均衡**：人民日报/中国政府网仅 2021+；2017–2020 主要由光明日报 +
  跨境公告 + 英文源覆盖；2018–2020 的政策文本密度显著低于 2021+。
- **公告非新闻**：「跨境」「黄金」是单一上市公司公告语料，主题偏融资/再融资，
  不代表宏观跨境政策；已在数据卡 notes 与偏差表标注。
- **英文语料**：BIS/IMF 中文关键词命中为 0，可能稀释 `text_risk_ratio`；已限流。
- **截断**：黄金/跨境长公告平均 1.6 万字符，截断到 1500 字会损失信息。
- **合成标签风险**：真实文本只进入特征层；标签仍由市场压力复合指标构造，
  文本不进入标签定义，避免循环。

## 4. 复现

```powershell
# 解压（首次）
Expand-Archive docs/金融数据.zip data/raw/financial_data -Force  # 注：金融数据 zip 与文本 zip 不同
# 文本语料（zip 已在飞书下载并放在 data/raw/feishu/文本数据8.2.zip）
.venv\Scripts\python.exe scripts/build_text_corpus.py `
  --zip data/raw/feishu/文本数据8.2.zip --output data/custom/policy_news.csv
```

如需更大规模（例如 3 万篇、正文 350 字）：

```powershell
.venv\Scripts\python.exe scripts/build_text_corpus.py --content-chars 350 --max-file-mb 0
```

产物统计见 `data/custom/text_manifest.json`；哈希与行数写入其中，可用于复现核对。
