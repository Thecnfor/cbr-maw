# 09 · 工程化规范

> 面向**实现阶段**的落地规范：目录、命名、依赖、测试、CI、发布、诊断。
> 当前仓库处于**设计期**，本文描述的是「落地时必须遵守的约定」，不是「已经完成的事」。

## 1. 工程基线

| 项 | 值 | 说明 |

## 3. 依赖与分层（强制）

见 [01-架构设计.md §4](01-架构设计.md)。工程上落实为：

1. `lib/core/` 不得 `import` 任何 `lib/` 其他目录。
2. `lib/data/` 不得 `import` `lib/agents/`、`lib/ui/`、`lib/app/`、`lib/features/`。
3. `lib/ui/` 不得 `import` `lib/data/`、`lib/agents/`、`lib/features/`。
4. `lib/agents/` 不得 `import` `lib/features/`、`lib/app/`。
5. **`lib/genui/adapter/` 是唯一允许 `import 'package:genui/...'` 的地方**；其余代码只依赖我方接口。
6. **`lib/agents/` 是唯一允许 `import 'package:genkit/...'` 的地方**。
7. 依赖倒置：`data` 通过注入的 getter 回调读取上层提供的数据视图（对应旧项目 `register_provider_getter`），**不得反向 import**。

**CI 检查**：用 `dart run tools/check_layers.dart` 扫描 import 图并在违规时失败。

## 4. 类型与契约

- **所有外部边界必须有显式契约**：API 响应、配置文件、来源台账、A2UI 消息、工具结果、Agent 输出。
- 优先用 Dart `sealed class` + `final class` + 工厂构造做**解析即校验**（parse-then-use），而不是「拿到就信」。
- 配置文件用 JSON Schema 校验（`configs/schema/*.schema.json`），启动时校验，非法即报错并指出字段。
- **禁止 `dynamic` / `noSuchMethod` / 隐式类型转换**；`analysis_options.yaml` 中把 `avoid_dynamic_calls` 设为 error。
- 数值计算显式标注单位与时区语义。

## 5. 测试

| 层 | 范围 | 工具 | 门槛 |
|---|---|---|---|
| 单元 | 纯函数、工具算法、哈希规范、PIT 过滤、清洗规则、状态机 | `flutter test` | 新增逻辑必须有测试 |
| 契约 | A2UI 消息、配置 Schema、来源台账 | `flutter test` | 协议变更必须同步 |
| 集成 | 一次完整研判链路（打桩 LLM）、抓取落库、Inbox 清洗 | `integration_test` | 主链路必须覆盖 |
| 黄金样本 | 哈希规范与旧系统对齐 | `flutter test` + 固定向量 | **逐字节一致** |

**必须被测的高风险逻辑**：
1. `inputs_hash` / `evidence_id` / `evidence.hash` 的规范化哈希（黄金向量）。
2. PIT 过滤：知识库层、工具层、Agent 层、核验层四级各自的行为。
3. Inbox 清洗：编码探测、表头提升、脏行剔除、长宽表语料识别、序列映射优先级。
4. 动作风险分级与白名单：越权必须**不执行**。
5. 冲突三分类，尤其「偏好差异不算错误」。
6. 成本预算熔断路径。
7. A2UI catalog 拒绝未登记组件。
8. 时空扩展窗口样本外无泄漏。

**禁止**：用固定数值 fixture 冒充来源数据；任何测试中出现「看起来像真实行情」的常量而无 `synthetic` 标记。

## 7. CI / CD

### 必过门禁（PR 合并前）

| 阶段 | 动作 |
|---|---|
| 静态 | `dart format --set-exit-if-changed .` → `flutter analyze`（零 error 零 warning） |
| 层级 | `dart run tools/check_layers.dart`（依赖方向） |
| 单测 | `flutter test --coverage`（覆盖率报告上传） |
| 契约 | `dart run tools/validate_contract.dart`（配置 Schema + A2UI catalog + 来源台账自检） |
| 集成 | `flutter test integration_test -d windows`（桌面） |
| 构建 | `flutter build windows --release`（**必须能出包，否则桌面端不可用**） |

### 发布

- 触发：打 `v*` tag。
- 产物：Windows 安装包（Inno Setup）+ 便携 zip + Android APK；macOS/Linux 出可运行构建。
- 版本号单一真源在 `pubspec.yaml`，打包脚本读取，不手工同步。
- 每个产物附 **SBOM** 与许可清单。

### 依赖治理

- Dependabot/Renovate 覆盖 `pubspec.yaml` 与 GitHub Actions。
- **许可体检**：任何引入商业许可组件（如 `syncfusion_flutter_charts`）必须走 ADR。

## 8. 配置

- 格式：**JSON**（Dart 生态无 YAML 一等公民地位），`configs/` 下按域分文件。
- 每个配置文件配一份 JSON Schema；启动时校验。
- 敏感值（密钥）**只在** `secrets/` 与环境变量，不进配置文件。
- 环境变量覆盖顺序：**环境变量 > `secrets/*.key` > `configs/*.json` 默认值**（与旧系统一致）。
- 接口地址与模型可覆盖（供用户接兼容网关）。

---

## 9. 错误处理与可观测性

- 错误分层：**预期错误**（Result/失败类型，带中文文案与修复建议） / **编程错误**（Bug，抛异常） / **外部失败**（网络/模型/来源，带重试与降级策略）。
- **禁止静默降级为 Mock**。所有降级路径必须：①降级事实写入审计 ②UI 明示 ③文案说明原因与影响。
- 日志分级：用户可感知提示（中文、说人话）与开发排查日志（技术细节）分离。
- 崩溃报告本地落盘可导出（含去敏后的堆栈与环境信息）。
- 所有外部调用带超时与重试；重试必须幂等或带幂等键。

---

## 10. 安全

- 密钥：Windows 优先 DPAPI；不可用时降级明文并**清理旧明文**；界面永不回显明文。
- 外部 URL 拼接：拒绝 `javascript:` / `data:` 协议头；用户/来源可控 URL 必须校验。
- 抓取：遵守 robots 或按白名单豁免并记录；带可识别 UA；遵守 `Retry-After`；不做高频压测式抓取。
- 导出的数据若含 SYNTHETIC 标记，**导出物必须携带该标记**。
- 依赖漏洞扫描纳入 CI。

## 11. 性能预算

| 项 | 预算 |
|---|---|
| 冷启动到可交互（Windows） | ≤ 3s |
| 页面切换 | ≤ 100ms |
| 图表首帧 | ≤ 500ms（数据已在内存） |
| 单次 Agent 编排（无模型延迟） | ≤ 2s |
| 抓取单源超时 | 20s（可配） |
| 模型调用超时 | 60s（可配） |
| A2UI 首 surface 渲染 | ≤ 100ms |

> 性能优化按**实测热点**做，不预防性加缓存。
