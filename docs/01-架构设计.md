## 1. 一句话架构与三进程拓扑

> **纯客户端三进程本地内核**：由 **Flutter/Dart 桌面外壳**承担 UI（`genui` A2UI）、`X-AlertAgent` × `R0–R5` 编排（`genkit`）、权限门卫与密钥；**Go `collector`** 承担 35 源抓取、Inbox 脏表清洗与自更新；**Rust `kernel`** 作为单一写入者，以 **DuckDB + 嵌入式 LanceDB** 双引擎承载 PIT 时序、三库记忆（`MI/LLR/HLR`）、确定性数值工具与黄金哈希——三者通过 `stdio NDJSON`（JSON-RPC 2.0）通信，**无中央服务器、无对外端口、填一个默认密钥即可使用**。

## 2. 核心引擎：`X-AlertAgent` 外环 × `R0–R5` 内环（[ADR-010](adr/ADR-010-X-AlertAgent双核嵌套与LanceDB三库记忆架构.md)）

系统采用**双核嵌套 + 全模块消融开关**架构，兼顾认知反思前沿性与金融审计确定性：

### 2.1 外环：`X-AlertAgent` 跨时点认知闭环

1. **感知（MI · 市场情报）**：采集并对齐截至 `as_of` 的 5 模态融合事件流，按三主体视角并行摘要，产出当期 `MI` 记忆。
2. **三库记忆（LanceDB，强 `available_at <= as_of` 前过滤）**：
   - **MI 库**：市场情报与跨模态事件证据包；
   - **LLR 库**：浅层反思（短/中/长期风险变动模式归因 + 历史相似案例 TopK 多样化检索）；
   - **HLR 库**：深层反思（回看过去 $T$ 天主体行动推理与事后实际风险走势/预警效能曲线复盘）。
3. **增强工具与辅助智能体**：调用 Rust 确定性工具库（+ 可选科研插件槽）与辅助风险测度模型取证。
4. **预警三件套输出**：`风险值（0–100 或条件概率）` + `四级预警等级（蓝/黄/橙/红，由确定性阈值判定）` + `三主体离散行动与附证据链方案`。

### 2.2 内环：`R0–R5` 可审计协同核验

每次认知决策内部必须走 `R0–R5` 确定性护栏：
- **R0 独立分析**：三主体在各自工具/信息白名单内独立出草稿 → 确定性定级 → 形成初始风险卡；
- **R1 证据共享**：汇总到证据黑板（三级去重 + 别名解析）；
- **R2 交叉验证**：双轨复核（工具确定性重算 + 同侪/JEV 语义互评）；
- **R3 分歧识别**：归一化为 `fact`（事实）/ `directional`（方向）/ `preference`（偏好，不算错误）+ `modality_conflict`（跨模态冲突，[ADR-009](adr/ADR-009-研究增强准入标准与当前裁决.md)）；
- **R4 冲突仲裁**：按「工具重算 > 证据等级 > HITL」裁决，**仲裁结果与降级状态接入决策损失函数**；
- **R5 交付核验**：六类核验（引文、PIT 泄漏、数值覆盖、权限、冲突、预算）+ **JEV 语义核验写入决策卡** + 强制追加系统 `limitations`。

### 2.3 全模块消融开关（支撑图 5 三情景与论文消融）

同一套主代码通过统一 `AblationFlags` 控制开关，保证对照组之间无实现偏差：
- **协作情景开关**：`traditional_dispersed`（情景一：无 LLM/仅工具基线）/ `independent`（情景二：LLM 辅助独立决策）/ `collaborative`（情景三：完整 `R0–R5` 协同与策略互动反馈）/ `single`（单通用代理对照）；
- **认知与证据开关**：`enable_mi_memory` / `enable_llr_reflection` / `enable_hlr_reflection` / `enable_multimodal_aux` / `evidence_strength`（`full` / `weak_evidence`，用于在不触发权限拦截的前提下精确测量幻觉率）。

## 3. 三主体升维与异构模型能力槽位路由（[ADR-011](adr/ADR-011-三主体升维与异构模型槽位路由及计算插件边界.md)）

### 3.1 三主体与离散行动枚举

| 主体 ID | 名称 | 核心目标 | 离散行动枚举 | 能力需求 |
|---|---|---|---|---|
| `regulator` | 监管智能体（政府） | 系统性风险最小化 | `In` / `Watch` / `Out` | 长上下文因果推断 |
| `institution`（兼容别名 `financing`） | 机构智能体（跨境金融机构及企业） | 风险–收益均衡定价 | `Discount` / `Hedge` / `Equilibrium` | 零容错工具调用 |
| `investor` | 投资者智能体 | 收益最大化 / 风险最小化 | `Buy` / `Hold` / `Sell` | 多模态对齐与高频推理 |

另设专职 **交叉验证角色**（`crossValidator`，只出 `confirmed / refuted / uncertain`，不出主风险卡）。

### 3.2 Genkit 能力槽位路由

基于 `package:genkit` 插件抽象以下能力槽位：`long_context_causal`、`strict_tool_call`、`multimodal_fast`、`reflection`、`embedding`、`judge`（固定直连 TypeSafe `jev-1.14.0`）。
- **默认单密钥兜底**：用户只填一个默认兼容密钥，所有生成槽位自动回落至该默认模型（一键即用）；
- **高级异构路由**：允许按槽位配置不同厂商/模型（含本地可配网关）；
- **实验锁定模式**：跑论文对照实验时可一键锁死所有生成槽位为同一模型，消除模型差异混杂变量。

## 4. 数据架构：5 模态归并、双嵌入式引擎与双路径测度

### 4.1 5 模态事件级归并（表 7 / 表 9）

- **文本 / 数值**：Go `collector` 真实抓取与 Inbox 清洗，严格落实 **4 条清洗铁律**（删周六复制行 16.5%、港股通按日+代码去重 43%、停牌行缺失禁 `fillna(0)`、港股复用代码以 `SecurityID` 为主键且北向日频/季末不混频）。
- **语音 / 图像 / 视频**：默认调配置化云端多模态 API 解析（转写/OCR/VLM），同时通过 Inbox 开放离线科研特征包导入（Wav2Vec/VideoMAE/夜光遥感按需缓存）。
- **分层摘要与矛盾保留**：清洗分段 → 段落摘要 → 事件摘要 → 语义去重（合并重复但**显式保留相互矛盾的来源证据**）→ 原文核验；全量记录 **表 7 质量指标**（F1 / WER / DER / CER / 同步时差 / 缺失率 / 跨模态覆盖率）。

### 4.2 Rust `kernel` 双嵌入式引擎

- **DuckDB**：PIT 时序表、分析面板、结构化风险事件、特征与测度计算输入；
- **嵌入式 LanceDB**：`MI / LLR / HLR` 三库记忆与跨模态证据包（原生 ANN + FTS + MMR 多样性重排；标量前过滤强锁 `available_at <= as_of`）；
- **Embedding 诚实降级**：Embedding API 无密钥或不可达时，显式降级为 LanceDB FTS / BM25 并写审计与 UI 提示。

### 4.3 双路径动态测度（[ADR-009](adr/ADR-009-研究增强准入标准与当前裁决.md) · [ADR-011](adr/ADR-011-三主体升维与异构模型槽位路由及计算插件边界.md)）

- **路径 A（主路径 · 确定性数值）**：
  - **Rust 必选内置**：CFSI（含 [ADR-008](adr/ADR-008-CFSI缺维降级口径.md) 缺维降级与新鲜度四态）、历史模拟 VaR/ES、EMP 汇率压力、ΔCoVaR、DY 定向溢出、双边媒体基调三渠道（M1 情绪 / M2 资本流动 `FLOW = ΔWH - TR - FDI` / M3 BIS 银行债权）、HMM/DTW/AW-LP、黄金哈希；
  - **契约化研究计算插件槽（`plugin.compute`）**：为 `GARCH-t` / `Copula-VaR` / `XGBoost+SHAP` 预留 JSON-RPC 插件槽，输出同走 `inputs_hash` + `evidence_id` 核验；默认零外部依赖。
- **路径 B（研究对照 · `LLM-VaR / LLM-ES`）**：通过 Genkit 通道在时间窗隔离防前瞻偏差约束下运行，**绝不覆盖路径 A 数值**，准入主定级须过 ADR-009 G1–G4。

## 5. 双轨市场反馈与评估闭环（物理隔离）

| 轨道 | 作用域 | 机制与红线 |
|---|---|---|
| **真实历史回放** | 默认工作区 | $t+1$ 市场状态严格读取真实 PIT 数据；事后走势仅用于计算误报/漏报/决策损失与预警效能曲线并驱动 `HLR` 反思；零合成数据 |

## 7. Monorepo 包边界与依赖方向

```
packages/
  contracts_dart/     ← contracts/ 生成的强类型与工具常量（零业务逻辑）
  design_system/      ← 唯一视觉 token / 主题 / 共享组件真源（废除 lib/ui/）
  a2ui_catalog/       ← 唯一 A2UI 组件白名单目录（安全边界）
apps/desktop/lib/
  core/               ← 配置校验、OS 密钥封装、错误分层、时间/as_of（不依赖业务层）
  data/               ← SidecarSupervisor、JSON-RPC 客户端、工作区仓库（不依赖 agents/features，不承载权限决策）
  agents/             ← X-AlertAgent 编排、R0–R5、gate/（唯一门卫落点）、黑板、核验、预算、llm/（不依赖 features/app）
  genui/              ← genui 适配层与动作分发（依赖 a2ui_catalog、design_system、core）
  features/           ← 业务页面与 Riverpod providers（依赖 core/data/agents/genui/design_system）
  experiments/        ← 消融运行器、显著性检验、增量检验与实验沙盒调度
  app/                ← 唯一组合根（go_router、外壳、bootstrap）
```

**强制规则**（由 `tools/check_layers.dart` 静态检查）：
1. `packages/*` 不得反向依赖 `apps/desktop`；`apps/desktop` 禁止复制 `design_system` 或 `a2ui_catalog` 源码（消除孤岛包）。
2. Prompt 唯一真源为仓库根 [configs/prompts/](../configs/prompts/)，禁止在 `apps/desktop/lib/agents/prompts/` 维护第二份副本。
3. 权限门卫统一归属 `apps/desktop/lib/agents/gate/`，`lib/data/` 不得做权限决策；鉴权未通过绝不发 RPC。
4. `package:genui/` 仅限 `lib/genui/adapter/`；`package:genkit/` 仅限 `lib/agents/`。

## 8. 关键横切机制

- **密钥**：环境变量 > `.env` > `flutter_secure_storage`（OS 原生加密），回显一律脱敏 `sk-****abcd`；无密钥禁 Mock。
- **四级 PIT**：Collector 推导、DuckDB/LanceDB 查询前过滤、Agent 上下文、核验层各自强制 `available_at <= as_of`；`leakage_events > 0` 为硬错误。
- **可重算证据链**：`evidence_id` / `inputs_hash` / `evidence.hash` 在 Rust 侧逐字节复刻 Python 浮点规范；数值 claim 一律以工具结果覆盖。
- **动作风险与幂等**：L0/L1/L2 白名单 + `Idempotency-Key` + 操作日志/回收站回滚。
- **预算与审计**：`J = L + μ·C`，每步写入 `<workspace>/traces/<run_id>.jsonl`；预算耗尽标 `partial=true` 并输出已验证部分结论。
