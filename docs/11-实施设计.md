## 2. 交付里程碑与当前进度

### v1（M0–M3）·「真实数据 + 可审计研判主链」（✅ 主体已落地）

- **已验证成果**：24 方法契约（`contracts/` `1.0.0`）、9 工具注册表、4 份黄金向量、Flutter 桌面端、Go `collector`（12 包绿）、Rust `kernel`（43 单测 + 3 黄金测试全绿）、真实 `daily_series.csv` 入库与 JEV 真实联网通过。
- **已知受阻项**：DeepSeek 密钥 401 失效导致生成侧与 bench A/C 组待复验；部分公开序列停更按 [ADR-008](adr/ADR-008-CFSI缺维降级口径.md) 口径披露 `limitations`。

### v1.5（收口期）·「架构规范与工程债清零」（⬜ 下一步优先）

完整整改条目、代码锚点与验收命令见 **[12-v1架构与工程收口清单.md](12-v1架构与工程收口清单.md)**，核心包括：
1. **P0 安全与可靠性修复**：密钥迁至 `flutter_secure_storage`、建立根 `VERSION` 与修正 `build.sh` 版本混用、修复 `SidecarSupervisor` 启动忙轮询与心跳误杀、禁止 Linux 交叉编译 Windows 发布包并补齐 PowerShell 门禁脚本。
2. **P1 现成库迁移与单一真源收口**：落地 `genkit`（槽位路由与红线钩子）、`genui` 真渲染、`flutter_riverpod`、`json_rpc_2` 评估；消除 `packages/design_system` 与 `a2ui_catalog` 孤岛副本、统一 Prompt 至 `configs/prompts/`、门卫迁回 `lib/agents/gate/`。
3. **P2 门禁补盲**：`check_layers` 覆盖 `packages/*`、校验 Rust 工具表与生成代码防漂移、固化 4 条数据清洗铁律单测、配置 `.github/workflows/ci.yml`。

## 4. 出口标准与待用户拍板事项

### 出口判据
- 每条里程碑出口标准必须对应一条可执行命令或测试名称；无命令覆盖视为未定义。
- 实证与学术口径受 [ADR-009](adr/ADR-009-研究增强准入标准与当前裁决.md) 约束：不显著不得写成显著，试点与正式配对检验分开报告，未过 G1–G4 门槛的能力默认关闭。

### 明确留给用户后续拍板的事项（延续自基线 §6）

| # | 事项 | 影响 | 何时需要 |
|---|---|---|---|
| U2 | 合成教学数据集三个情景的具体数值 | 避免「看起来像真实行情」 | v2 启动前 |
| U3 | 是否需要远程执行 gRPC 扩展 | 契约层已保持语言中立 | v2 结束前 |
| U4 | 目标用户形态（单人研究 vs 团队共用） | 影响导出与工作区权限粒度 | v2 结束前 |
| U5 | `update-manifest.json` 托管位置（对象存储 / Releases） | 自更新通道发布地址 | v3 启动前 |
