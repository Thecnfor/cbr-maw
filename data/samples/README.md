## 文件说明

- `market_daily.parquet` / `.csv`：日频宽表（行=交易日，列=序列 ID）
- `macro_monthly.parquet` / `.csv`：月频指标（行=观测月末）
- `documents.parquet` / `.csv`：政策/新闻语料（含 publish_time）
- `data_cards.json`：每个序列的数据卡（口径/单位/来源/时点评级）
- `series_catalog.json`：序列目录（ID/域/单位/频率/发布时滞）
- `MANIFEST.json`：数据集清单与声明

## 仿真数据的已知内嵌结构（非真实市场规律）

- 压力事件前存在 8~18 个交易日的可观测累积期（波动抬升、信用利差走阔、资金流出），
  使未来 h 日高压力标签可由历史特征学习；
- 文本语料内嵌约 5~8 个交易日的领先风险语义（用于检验文本模态增量价值）；
- 北向资金/持仓在 2024-08-16 后停止披露（模拟真实数据口径断点）。
